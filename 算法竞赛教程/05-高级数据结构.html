第 5 章 高级数据结构

“修改一个元素、查询一个区间”是最常见的题目骨架。朴素写法 O(n) 查询、O(1) 修改，m 次操作就是 O(nm)； n、m 上 105 就必然超时。线段树和树状数组把两个操作都压到 O(log n)。 并查集则是另一类问题的答案：动态合并集合。

学完本章，你应该能做到

  • 写出带路径压缩的并查集，并解释它为什么接近 O(1)；
  • 独立写出线段树的建树、单点修改、区间查询，并能加上懒标记做区间修改；
  • 解释线段树为什么开 4n 空间；
  • 写出树状数组的 add 与 sum，并知道它为什么只能做“前缀可减”的信息；
  • 知道 Treap / Splay 解决的是什么问题（有序集合的第 k 大、区间翻转）。

5.1 并查集：动态合并集合

城市里有 n 个人，分成不同帮派。给出“1 号和 2 号是朋友”“1 号和 3 号是朋友”这类关系， 问最后有多少帮派、每个人属于哪个帮派。n 可以到 105。

并查集（Disjoint Set）为每个集合选一个“代表”，只维护“谁的代表是谁”。三个操作： 初始化（每人自成一个集合）、合并（把两个集合的代表连起来）、查找（找某人的代表）。 

// 朴素实现：s[i] 表示 i 所属集合的代表
int s[MAXN];
void init(int n) { for (int i = 1; i <= n; i++) s[i] = i; }

int find(int x) {                 // 找 x 所在集合的代表
    while (s[x] != x) x = s[x];   // 一路往上爬
    return x;
}

void merge(int x, int y) {        // 合并两个集合
    s[find(x)] = find(y);         // 把 x 的代表挂到 y 的代表下
}

朴素版本在极端情况下会退化成一串很长的链，find 变成 O(n)。两个优化让它几乎变成 O(1)：

1
路径压缩。查找时把路径上所有节点直接挂到代表下面，下次再查就是一步。
2
按秩合并。合并时把“矮的树”挂到“高的树”下面，避免树变高。用 rank 或集合大小记录高度。
// 竞赛标准版：路径压缩 + 按秩合并
int s[MAXN], rk[MAXN];

void init(int n) {
    for (int i = 1; i <= n; i++) { s[i] = i; rk[i] = 0; }
}

int find(int x) {                       // 递归写法，压缩路径
    return s[x] == x ? x : s[x] = find(s[x]);
}

void merge(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return;                 // 已经在同一个集合
    if (rk[x] < rk[y]) s[x] = y;
    else if (rk[x] > rk[y]) s[y] = x;
    else { s[y] = x; rk[x]++; }         // 高度相同，合并后高度 +1
}
复杂度：只用路径压缩，均摊 O(log n)；两者都用，均摊 O(α(n))，其中 α 是反阿克曼函数， 在 n ≤ 109 时不超过 5。可以当作常数。

并查集的典型应用：连通子图计数、Kruskal 最小生成树（第 10 章）、最近公共祖先（LCA）。 注意它只能合并，不能拆分——需要“删除”操作的题要用可持久化并查集或换数据结构。

5.2 二叉树：从存储到平衡

5.2.1 二叉树的存储

两种存法：数组（堆式，节点 i 的左右儿子是 2i、2i+1，适合完全二叉树）和链式（每个节点存左右指针，适合任意形态）。 线段树用的是数组存法，因为它本身就是一棵“结构固定的完全二叉树”。

5.2.2 遍历

void preorder(int u)  { if (!u) return; cout << u; preorder(lc[u]); preorder(rc[u]); }  // 根左右
void inorder(int u)   { if (!u) return; inorder(lc[u]); cout << u; inorder(rc[u]); }   // 左根右
void postorder(int u) { if (!u) return; postorder(lc[u]); postorder(rc[u]); cout << u; } // 左右根

中序遍历二叉搜索树会得到有序序列，这条性质是后面所有平衡树的基础。

5.2.3 二叉搜索树与它的退化

BST 的性质：左子树所有值小于根，右子树所有值大于根。查找、插入、删除平均 O(log n)。 但如果按 1、2、3、4、5 的顺序插入，树会退化成一条链，所有操作变成 O(n)。这就是需要平衡树的原因。

5.2.4 Treap 与 Splay

平衡树的目标是：在保持 BST 性质的同时，把树高控制在 O(log n)。竞赛里最常用的两种：

TreapSplay
平衡方式给每个节点一个随机优先级，按堆性质旋转每次访问后把节点旋转到根（自适应）
实现难度较简单，代码短较复杂，但能做区间操作
均摊复杂度O(log n)（期望）O(log n)（均摊）
擅长第 k 大、前驱后继、排名区间翻转、区间分裂合并、可持久化
 
// Treap 核心：旋转 + 插入（带随机优先级）
struct Node { int l, r, val, pri, cnt, siz; } t[MAXN];
int tot = 0;

void pushup(int u) { t[u].siz = t[t[u].l].siz + t[t[u].r].siz + t[u].cnt; }

void rotate_right(int& u) {          // 右旋
    int v = t[u].l;
    t[u].l = t[v].r;
    t[v].r = u;
    pushup(u); pushup(v);
    u = v;
}

void rotate_left(int& u) {           // 左旋
    int v = t[u].r;
    t[u].r = t[v].l;
    t[v].l = u;
    pushup(u); pushup(v);
    u = v;
}

void insert(int& u, int x) {
    if (!u) {                        // 新建节点
        u = ++tot;
        t[u] = {0, 0, x, rand(), 1, 1};
        return;
    }
    if (x == t[u].val) { t[u].cnt++; pushup(u); return; }
    if (x < t[u].val) {
        insert(t[u].l, x);
        if (t[t[u].l].pri > t[u].pri) rotate_right(u);   // 维护大根堆性质
    } else {
        insert(t[u].r, x);
        if (t[t[u].r].pri > t[u].pri) rotate_left(u);
    }
    pushup(u);
}
不要用 rand() 直接当优先级。部分平台的 rand() 周期短、低位规律明显， 会被构造数据卡成链。用 mt19937 或者手写 xorshift。

Splay 的核心是 splay(x)：把节点 x 一路双旋到根。它把“最近访问的节点”放到最容易访问的位置， 因此适合处理有局部性的访问序列。区间操作时，把区间左右端点分别 splay 到根和根的右儿子，中间那棵子树就是目标区间。

5.3 线段树

5.3.1 它解决什么问题

有一类 RMQ（Range Minimum/Maximum Query）问题：给定长度 n 的数列，需要①查询区间 [i, j] 的最值；②修改某个元素。

做法单次查询单次修改m 次操作总计
朴素数组O(n)O(1)O(nm)，n=m=105 时 1010
线段树O(log n)O(log n)O(m log n)，约 1.7×106

线段树是一棵二叉树，每个节点代表一条线段（区间）[L, R]：

  • 若 L = R，此节点是叶子，对应数列中的一个点；
  • 若 L < R，取中点 M = (L + R) / 2，左儿子代表 [L, M]，右儿子代表 [M+1, R]。

每次区间对半拆分，所以树高 log2 n，查找一个点或查询一个区间最多走 log2 n 层—— 这就是它高效的原因：把“扫一遍区间”换成了“折半定位”。

5.3.2 建树与单点修改

#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100005;
int a[MAXN];
long long sum[MAXN * 4];             // 4 倍空间：见下文说明

void build(int u, int l, int r) {
    if (l == r) { sum[u] = a[l]; return; }
    int mid = (l + r) >> 1;
    build(u << 1, l, mid);
    build(u << 1 | 1, mid + 1, r);
    sum[u] = sum[u << 1] + sum[u << 1 | 1];   // 区间和 = 左右儿子之和
}

void update(int u, int l, int r, int pos, int val) {   // 把 a[pos] 改成 val
    if (l == r) { sum[u] = val; return; }
    int mid = (l + r) >> 1;
    if (pos <= mid) update(u << 1, l, mid, pos, val);
    else            update(u << 1 | 1, mid + 1, r, pos, val);
    sum[u] = sum[u << 1] + sum[u << 1 | 1];   // 回溯时更新父亲
}

long long query(int u, int l, int r, int ql, int qr) { // 查询 [ql, qr] 的和
    if (ql <= l && r <= qr) return sum[u];      // 完全覆盖，直接返回
    int mid = (l + r) >> 1;
    long long ans = 0;
    if (ql <= mid)     ans += query(u << 1, l, mid, ql, qr);
    if (qr > mid)      ans += query(u << 1 | 1, mid + 1, r, ql, qr);
    return ans;
}
为什么开 4n？线段树的节点数不是恰好 2n−1。当 n 不是 2 的幂时，树的最后一层会有空洞， 最坏情况下编号会超过 2n。取 4n 是为了让编号 u << 1 | 1 永远不越界。 这个结论原书在程序注释里也点了名——面试常考。

5.3.3 区间修改与懒标记

如果要把 [a, b] 中每个元素都加上 c，不能逐个点更新（那是 O(n log n)）。 做法是：给整段被打上“懒标记”lazy，表示“这个区间的每个元素都还没实际加上 c”， 只有真正需要访问子区间时才把标记下推。 

long long sum[MAXN * 4], lazy[MAXN * 4];

void push_down(int u, int len) {      // len 是当前区间长度
    if (!lazy[u]) return;
    lazy[u << 1] += lazy[u];
    lazy[u << 1 | 1] += lazy[u];
    sum[u << 1] += lazy[u] * (len - len / 2);
    sum[u << 1 | 1] += lazy[u] * (len / 2);
    lazy[u] = 0;
}

void update_range(int u, int l, int r, int ql, int qr, long long c) {
    if (ql <= l && r <= qr) {        // 完全覆盖，打标记就返回
        sum[u] += c * (r - l + 1);
        lazy[u] += c;
        return;
    }
    push_down(u, r - l + 1);
    int mid = (l + r) >> 1;
    if (ql <= mid) update_range(u << 1, l, mid, ql, qr, c);
    if (qr > mid)  update_range(u << 1 | 1, mid + 1, r, ql, qr, c);
    sum[u] = sum[u << 1] + sum[u << 1 | 1];
}

long long query_range(int u, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return sum[u];
    push_down(u, r - l + 1);          // 查询前必须下推，否则子节点的 sum 是旧的
    int mid = (l + r) >> 1;
    long long ans = 0;
    if (ql <= mid) ans += query_range(u << 1, l, mid, ql, qr);
    if (qr > mid)  ans += query_range(u << 1 | 1, mid + 1, r, ql, qr);
    return ans;
}
懒标记最容易错的两处： ① query 时忘了先 push_down，读到的是没有被加过的旧值； ② 下推时左右儿子的长度算错（左儿子长度是 len − len/2，不是 len/2）。

5.3.4 离散化

如果坐标范围是 109，线段树开不下。做法是把所有会用到的坐标收集起来排序去重， 用下标代替原值——这样 n 个坐标就压进 [1, n]。 

vector<int> xs;
// 收集所有坐标后：
sort(xs.begin(), xs.end());
xs.erase(unique(xs.begin(), xs.end()), xs.end());
int id = lower_bound(xs.begin(), xs.end(), x) - xs.begin() + 1;   // 原值 → 下标

5.4 树状数组

树状数组（Binary Indexed Tree，BIT）利用整数的二进制特征做检索，代码极短，常数极小。

它支持两个操作：add(k, x) 把 ak 加上 x；sum(x) 求 a1+…+ax。 区间和 ai+…+aj = sum(j) − sum(i−1)。 

int n, bit[MAXN];

inline int lowbit(int x) { return x & -x; }   // 取出最低位的 1

void add(int k, int x) {                       // 单点加
    for (; k <= n; k += lowbit(k)) bit[k] += x;
}

int sum(int x) {                               // 前缀和
    int s = 0;
    for (; x > 0; x -= lowbit(x)) s += bit[x];
    return s;
}

int range_sum(int l, int r) { return sum(r) - sum(l - 1); }
为什么它能工作？下标 k 的节点维护的是“以 k 结尾、长度为 lowbit(k)”的那一段和。 查询时每次减去 lowbit，正好把前缀拆成 log n 段；更新时每次加上 lowbit，正好把所有覆盖它的节点都更新。 两边的步数都是 O(log n)。

树状数组的局限很明确：它只适合可减、可结合的信息（和、异或、计数）。 区间最值这种“不可减”的信息，必须用线段树。需要区间加 + 区间求和时，要用两个树状数组（差分）。
