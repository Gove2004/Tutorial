08 - 函数与基数

本章目标：从关系视角理解函数；掌握单射/满射/双射的判定与计数；理解复合函数与反函数存在的条件；掌握等势、可数与不可数，会做对角线论证。

8.1 函数：一种特殊的二元关系

定义 8.1（函数）

从 A 到 B 的函数 f 是一个二元关系，满足：单值性——若 <x,y>∈f 且 <x,z>∈f，则 y = z；处处定义——每个 x∈A 都有像。记作 f: A → B。

所以函数 = 关系 + 两条纪律。|A × B| 中挑出的关系有 2|A|·|B| 个，但合法函数只有 |B||A| 个（每个 x 独立选一个像）。这个计数后面立刻用到。

8.2 单射、满射、双射

定义 8.2（三类函数）

类型定义直观图示特征
单射（入射）x ≠ y ⇒ f(x) ≠ f(y)（不同输入必给不同输出）箭头不汇聚；要求 |A| ≤ |B|
满射∀y∈B, ∃x∈A, f(x) = y（每个输出都被打到）右列无闲置点；要求 |A| ≥ |B|
双射既单又满（一一对应）完美配对；要求 |A| = |B|（有限时）

例 8.1 判定四个经典函数

  • f: ℤ → ℤ, f(n) = 2n。单而不满（奇数无原像）。
  • f: ℤ → ℤ, f(n) = n mod 2。满而不单（0 和 1 各收了一堆）。
  • f: ℤ → ℤ, f(n) = n²。既不单（±1 撞车）也不满（负数无原像）。
  • f: ℝ → ℝ, f(x) = 2x + 1。双射（反函数 (y−1)/2 总能解出）。

定理 8.1（有限集上的计数）

|A| = m, |B| = n 时：A 到 B 的函数共 nm 个；单射只有 m ≤ n 时才存在，共 n(n−1)…(n−m+1) 个；双射仅当 m = n 时存在，共 n! 个。这把函数计数和第 15 章的排列直接挂钩：双射 = 全排列。

8.3 复合与反函数

定义 8.3

复合 g∘f(x) = g(f(x))（f 先作用）。反函数 f⁻¹ 是把 f 的序偶全部倒过来——但它要成为函数，必须 f 是双射。

为什么双射才有反函数：f⁻¹ 要满足函数的两条纪律。"处处定义"要求 f 满射（每个 y 都有原像）；"单值"要求 f 单射（原像唯一）。缺一条就崩。所以"求反函数前先证双射"不是仪式，是必要条件。

定理 8.2（复合的双射保持）

f、g 双射 ⇒ g∘f 双射，且 (g∘f)⁻¹ = f⁻¹∘g⁻¹（"穿鞋脱袜"律）。另外单射与满射在复合下各自保持：f、g 单 ⇒ g∘f 单；f、g 满 ⇒ g∘f 满。逆否版本同样常用：g∘f 单 ⇒ f 单（g 可以不单）；g∘f 满 ⇒ g 满（f 可以不满）。这两个"由复合反推因子"的结论是考试证明题的标准弹药。

8.4 等势：无限集的"数数"革命

定义 8.4（等势）

若存在从 A 到 B 的双射，则称 A 与 B 等势，记 A ≈ B。有限集等势 ⇔ 元素个数相同；无限集等势是"无穷也能比较大小"的关键工具。

例 8.2 颠覆直觉：ℕ ≈ ℤ ≈ 偶数集

偶数"显然只有一半多"，但 f(n) = 2n 给出 ℕ → 偶数集的双射——自然数和偶数一样多！ℤ 与 ℕ 等势：蛇形编号 0, 1, −1, 2, −2, … 就是一个双射。无限集的怪事全来自"部分可以等于整体"（这是无限集的定义性特征：Dedekind 无限）。

定义 8.5（可数与不可数）

A ≈ ℕ（或 A 的元素能排成一列）则称 A 为可数集；有限集也算可数（有限可数）。不能与 ℕ 建立双射的无限集是不可数集。

例 8.3 ℚ 可数：对角线扫描

把正分数按"分子 + 分母"排成二维表格，沿反对角线蛇形扫描并跳过重复（2/4 与 1/2 重复），即可把全部正有理数排成一列。所以看似"稠密得多"的有理数与自然数一样多。可数性的本质：能设计一个"无遗漏、无重复"的编号方案。

定理 8.3（Cantor 对角线论证）

(0,1) 内实数不可数。证明思路（必须会复述）：反设能排成一列 r₁, r₂, r₃, …。构造新数 x：第 i 位取与 ri 的第 i 位不同的数字。则 x 与列表中每一个 ri 都在第 i 位不同——x 不在列表里，矛盾。∎

对角线法为何如此有力：它不依赖任何具体构造，而是"用敌方列表自身的第 i 项打第 i 项"。这个论证模式后来催生了图灵的停机问题不可判定性、哥德尔不完备定理——离散数学里最深刻的三个结果共用同一个招式。

定理 8.4（Cantor 定理与无穷的层级）

对任何集合 A（包括无限集），|P(A)| > |A|，即 A 与 P(A) 不等势（证明仍是对角线：任给 A→P(A) 的映射 f，取 B = { x | x ∉ f(x) }，B 不在任何 f 的像里）。于是无穷不止一种：
|ℕ| = |ℤ| = |ℚ| < |ℝ| = |P(ℕ)| < |P(P(ℕ))| < …
康托尔为此造了记号 ℵ₀（可数无穷）与 𝔠（连续统）。连续统假设（是否存在介于两者之间的无穷）在 ZFC 公理体系内既不能证真也不能证伪——1963 年 Cohen 证明的独立性结果。

基数的三大直觉陷阱
  • "有理数比自然数多" ✗ —— 都是 ℵ₀。
  • "无理数比有理数多一点点" ✗ —— 有理数可数、无理数不可数，"多"整整一个层级。
  • "两个无穷没法比较" ✗ —— 双射/单射就是尺子：A ≈ B 或 |A| ≤ |B|（存在单射）都有精确定义。

8.5 自测题

  1. A = {1,2,3}，B = {a,b}。A 到 B 的函数共多少个？其中单射几个？双射存在吗？
  2. f: ℝ → ℝ，f(x) = x³ − x。判断单射、满射。
  3. 证明：若 g∘f 是满射，则 g 是满射（写出完整证明）。
  4. 证明 (0,1) 与 ℝ 等势（给出一个双射即可）。
  5. 用对角线法证明：从 ℕ 到 {0,1} 的全体函数（即全体 0-1 无穷序列）不可数。
参考答案（先做再看）
  1. 函数共 2³ = 8 个。单射要求 3 个不同输入给 3 个不同输出，但 |B| = 2 < 3，0 个。双射需 |A| = |B|，不存在。
  2. 不单：f(−1) = f(0) = f(1) = 0。满：f 连续，且 x → ±∞ 时 f(x) → ±∞，由介值定理任何 y ∈ ℝ 都有原像 ✓。所以满而不单。
  3. 任取 y∈C。g∘f 满射 ⇒ ∃x∈A，g(f(x)) = y。令 b = f(x) ∈ B，则 g(b) = y。y 是任意的，故 g 满射。∎（注意结论里只保证了 g，f 可以不满——比如 f 把 A 全打到 B 的一个点上。）
  4. tan(π(x − 1/2)) 把 (0,1) 双射到 ℝ（x→0+ 时 → −∞，x→1− 时 → +∞，严格递增）。或 f(x) = (2x−1)/(x² − x) 的变形版本。写出一个并说明严格单调/可逆即可。
  5. 反设全体 0-1 序列可排成 s₁, s₂, s₃, …。构造 s*：第 i 位 = 1 − si 的第 i 位。则 s* 与每个 si 在第 i 位不同，s* 不在列表中，矛盾。故不可数。（这正是 |P(ℕ)| = 𝔠 的论证。）
本章小结：函数 = 单值 + 处处定义的关系；单/满/双射对应"不汇聚/全覆盖/一一配对"；只有双射可逆；等势用双射定义"多少"，ℕ ≈ ℤ ≈ ℚ 但 ℕ ≉ ℝ；对角线法与 Cantor 定理打开了无穷层级。集合论至此完成，下一部分进入代数结构——给集合装上运算。
