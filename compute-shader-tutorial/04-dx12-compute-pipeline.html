DX12 Compute Pipeline 搭建

理论铺垫了这么多，本章开始动手。我们将创建一个完整的、可运行的DX12 Compute Pipeline 最小示例：从创建 Device 到 Dispatch 再到读取结果。每一步都会解释为什么需要这样做。

关于代码：本章代码基于 Microsoft 的 DX12 Graphics Samples，做了精简和注释。完整项目可以在教程仓库中找到。

整体架构概览

D3D12 的 API 是显式的（explicit）——你需要手动管理几乎所有东西。这与 DX11 的隐式管理完全不同：

DX11:                              DX12:
┌──────────────┐                   ┌──────────────────┐
│  Driver      │                   │  Application     │
│  (隐式管理)  │                   │  (手动管理)      │
│              │                   │                  │
│  GPU ←────── │                   │  Command List →  │
│              │                   │  Fences →        │
│              │                   │  Descriptor      │
└──────────────┘                   └──────────────────┘
                                   ↕
                              ┌──────────┐
                              │  GPU     │
                              └──────────┘

第一步：创建 DX12 Device

#include <d3d12.h>
#include <dxgi1_4.h>

// 创建 DXGI Factory
Microsoft::WRL::ComPtr<IDXGIFactory4> factory;
CreateDXGIFactory1(IID_PPV_ARGS(&factory));

// 选择 GPU（集成显卡 / 独立显卡 / 软件渲染器）
Microsoft::WRL::ComPtr<IDXGIAdapter1> adapter;
factory->EnumAdapters1(0, &adapter);  // 0 = 第一个适配器

// 创建 DX12 Device
Microsoft::WRL::ComPtr<ID3D12Device> device;
D3D12CreateDevice(adapter.Get(), D3D_FEATURE_LEVEL_12_0,
                  IID_PPV_ARGS(&device));

// 创建 Command Allocator（命令分配器）
Microsoft::WRL::ComPtr<ID3D12CommandAllocator> commandAllocator;
device->CreateCommandAllocator(D3D12_COMMAND_LIST_TYPE_COMPUTE,
                               IID_PPV_ARGS(&commandAllocator));

// 创建 Command Queue（命令队列）
D3D12_COMMAND_QUEUE_DESC queueDesc = {};
queueDesc.Type = D3D12_COMMAND_LIST_TYPE_COMPUTE;
queueDesc.Flags = D3D12_COMMAND_QUEUE_FLAG_NONE;
Microsoft::WRL::ComPtr<ID3D12CommandQueue> commandQueue;
device->CreateCommandQueue(&queueDesc, IID_PPV_ARGS(&commandQueue));

Command List vs Command Queue

这是 DX12 最容易混淆的概念：

Command List（命令列表）

记录 GPU 操作的"录像带"。你在 CPU 端录制一系列命令（绑定资源、设置管线、Dispatch），然后回放给 GPU。Command List 可以被录制（Recording）和执行（Execution）分离——这是 DX12 高性能的关键。

Command Queue（命令队列）

GPU 端的"播放列表"。Command List 录制完成后，提交到 Command Queue，GPU 按顺序执行。

类比：Command List 是你写的"菜谱"（记录每一步操作），Command Queue 是厨房的"出菜口"（GPU 按顺序执行）。你可以在休息时写菜谱（录制），然后统一交给厨师（提交执行）。

第二步：创建 Shader

首先需要编译 HLSL Shader 为 .cso（Compiled Shader Object）：

// MyComputeShader.hlsl
StructuredBuffer<float> inputBuffer : register(t0);
RWStructuredBuffer<float> outputBuffer : register(u0);

[numthreads(256, 1, 1)]
void CSMain(uint3 tid : SV_DispatchThreadID)
{
    uint index = tid.x;
    // 简单的平方运算
    outputBuffer[index] = inputBuffer[index] * inputBuffer[index];
}

编译（在构建脚本中）：

dxc -T cs_6_0 -E CSMain myshader.hlsl -Fo myshader.cso

在 C++ 中加载编译好的 Shader：

// 读取 .cso 文件
Microsoft::WRL::ComPtr<ID3DBlob> shaderBlob;
LoadFileToString(L"myshader.cso", &shaderBlob);

// 创建 Compute Pipeline State
Microsoft::WRL::ComPtr<ID3D12PipelineState> computePSO;
D3D12_COMPUTE_PIPELINE_STATE_DESC psoDesc = {};
psoDesc.pRootSignature = rootSignature.Get();
psoDesc.CS = reinterpret_cast<BYTE*>(shaderBlob->GetBufferPointer());
psoDesc.CS->BufferSize = shaderBlob->GetBufferSize();
device->CreateComputePipelineState(&psoDesc,
                                    IID_PPV_ARGS(&computePSO));

第三步：Root Signature

Root Signature 是 Shader 和资源之间的"契约"。它告诉 DX12："这个 Shader 需要哪些资源，在哪里找"。

// 定义描述符表（Descriptor Table）
CD3DX12_DESCRIPTOR_RANGE srvRange(D3D12_DESCRIPTOR_RANGE_TYPE_SRV, 1, 0);
CD3DX12_DESCRIPTOR_RANGE uavRange(D3D12_DESCRIPTOR_RANGE_TYPE_UAV, 1, 0);

// 定义根参数（Root Parameters）
CD3DX12_ROOT_PARAMETER rp[2];
rp[0].InitAsDescriptorTable(1, &srvRange, D3D12_SHADER_VISIBILITY_COMPUTE);
rp[1].InitAsDescriptorTable(1, &uavRange, D3D12_SHADER_VISIBILITY_COMPUTE);

// 创建 Root Signature
CD3DX12_ROOT_SIGNATURE_DESC rootSigDesc(_countof(rp), rp, 0, nullptr,
                                        D3D12_ROOT_SIGNATURE_FLAG_NONE);

Microsoft::WRL::ComPtr<ID3DBlob> signature;
Microsoft::WRL::ComPtr<ID3DBlob> error;
D3D12SerializeRootSignature(&rootSigDesc, D3D_ROOT_SIGNATURE_VERSION_1_0,
                            &signature, &error);

device->CreateRootSignature(0, signature->GetBufferPointer(),
                            signature->GetBufferSize(),
                            IID_PPV_ARGS(&rootSignature));

第四步：创建资源缓冲区

我们需要两个缓冲区：一个只读输入（SRV），一个可读写输出（UAV）。

const UINT bufferCount = 1024;
const SIZE_T bufferSize = bufferCount * sizeof(float);

// 创建 GPU 缓冲区（Default 堆——GPU 可读写）
D3D12_RESOURCE_DESC bufferDesc = {};
bufferDesc.Dimension = D3D12_RESOURCE_DIMENSION_BUFFER;
bufferDesc.Alignment = 0;
bufferDesc.Width = bufferSize;
bufferDesc.Height = 1;
bufferDesc.DepthOrArraySize = 1;
bufferDesc.MipLevels = 1;
bufferDesc.Format = nullptr;  // 缓冲区无 Format
bufferDesc.SampleDesc.Count = 1;
bufferDesc.Layout = D3D12_TEXTURE_LAYOUT_ROW_MAJOR;

Microsoft::WRL::ComPtr<ID3D12Resource> inputBuffer;
device->CreateResource(&D3D12_RESOURCE_DESC::Buffer(bufferSize),
                       D3D12_RESOURCE_STATE_COMMON, nullptr,
                       IID_PPV_ARGS(&inputBuffer));

Microsoft::WRL::ComPtr<ID3D12Resource> outputBuffer;
device->CreateResource(&bufferDesc,
                       D3D12_RESOURCE_STATE_COMMON, nullptr,
                       IID_PPV_ARGS(&outputBuffer));

Resource State：DX12 的状态机

DX12 中每个资源都有一个当前状态，不同状态支持的操作不同。在使用资源前，必须将其 Transition 到正确的状态：

状态可用操作
D3D12_RESOURCE_STATE_COMMON无（初始状态）
D3D12_RESOURCE_STATE_COPY_DEST仅 Copy Dest（接收数据）
D3D12_RESOURCE_STATE_COPY_SOURCE仅 Copy Src（发送数据）
D3D12_RESOURCE_STATE_NON_PIXEL_SHADER_RESOURCESRV 读取
D3D12_RESOURCE_STATE_UNORDERED_ACCESSUAV 读写
D3D12_RESOURCE_STATE_PIXEL_SHADER_RESOURCEPS 读取（纹理）

Transition 通过 Barrier 实现：

// 将 inputBuffer 从 COMMON → COPY_DEST（准备接收主机端数据）
D3D12_RESOURCE_BARRIER inputBarrier = {};
inputBarrier.Type = D3D12_RESOURCE_BARRIER_TYPE_TRANSITION;
inputBarrier.Flags = D3D12_RESOURCE_BARRIER_FLAG_NONE;
inputBarrier.Transition.pResource = inputBuffer.Get();
inputBarrier.Transition.StateBefore = D3D12_RESOURCE_STATE_COMMON;
inputBarrier.Transition.StateAfter = D3D12_RESOURCE_STATE_COPY_DEST;
inputBarrier.Transition.Subresource = D3D12_RESOURCE_BARRIER_ALL_SUBRESOURCES;
commandList->ResourceBarrier(1, &inputBarrier);

// 写入数据
commandList->CopyBufferRegion(outputBuffer.Get(), 0, inputBuffer.Get(), 0, bufferSize);

// 将 inputBuffer 从 COPY_DEST → NON_PIXEL_SHADER_RESOURCE（供 Shader 读取）
D3D12_RESOURCE_BARRIER srvBarrier = {};
srvBarrier.Type = D3D12_RESOURCE_BARRIER_TYPE_TRANSITION;
srvBarrier.Transition.pResource = inputBuffer.Get();
srvBarrier.Transition.StateBefore = D3D12_RESOURCE_STATE_COPY_DEST;
srvBarrier.Transition.StateAfter = D3D12_RESOURCE_STATE_NON_PIXEL_SHADER_RESOURCE;
commandList->ResourceBarrier(1, &srvBarrier);

// 将 outputBuffer 从 COMMON → UNORDERED_ACCESS（供 Shader 写入）
D3D12_RESOURCE_BARRIER uavBarrier = {};
uavBarrier.Type = D3D12_RESOURCE_BARRIER_TYPE_TRANSITION;
uavBarrier.Transition.pResource = outputBuffer.Get();
uavBarrier.Transition.StateBefore = D3D12_RESOURCE_STATE_COMMON;
uavBarrier.Transition.StateAfter = D3D12_RESOURCE_STATE_UNORDERED_ACCESS;
commandList->ResourceBarrier(1, &uavBarrier);
Barrier 是 DX12 最常见的 Bug 来源：忘记 Barrier → GPU 在错误的资源状态下执行 → 驱动崩溃或结果错误。每个资源状态变化都需要 Barrier。如果不确定，查 官方 Resource States 文档。

第五步：Descriptor Heap

Descriptor Heap 是存放资源描述符（Descriptor）的容器。Descriptor 告诉 GPU："这个 SRV 指向哪个 GPU 虚拟地址"。

// 创建 Descriptor Heap
D3D12_DESCRIPTOR_HEAP_DESC heapDesc = {};
heapDesc.NumDescriptors = 4;  // SRV × 1 + UAV × 1 + CBV × 2
heapDesc.Type = D3D12_DESCRIPTOR_HEAP_TYPE_CBV_SRV_UAV;
heapDesc.Flags = D3D12_DESCRIPTOR_HEAP_FLAG_SHADER_VISIBLE;  // Shader 可访问
Microsoft::WRL::ComPtr<ID3D12DescriptorHeap> descriptorHeap;
device->CreateDescriptorHeap(&heapDesc, IID_PPV_ARGS(&descriptorHeap));

// 获取 Descriptor 大小（不同 GPU 可能不同！）
UINT descriptorSize = device->GetDescriptorHandleIncrementSize(
    D3D12_DESCRIPTOR_HEAP_TYPE_CBV_SRV_UAV);

// 创建 SRV Descriptor
D3D12_SHADER_RESOURCE_VIEW_DESC srvDesc = {};
srvDesc.Shader4ComponentMapping = D3D12_DEFAULT_SHADER_4_COMPONENT_MAPPING;
srvDesc.Format = DXGI_FORMAT_R32_FLOAT;
srvDesc.ViewDimension = D3D12_SRV_DIMENSION_BUFFER;
srvDesc.Buffer.NumElements = bufferCount;

CD3DX12_CPU_DESCRIPTOR_HANDLE srvHandle(cpuHandle);
device->CreateShaderResourceView(inputBuffer.Get(), &srvDesc, srvHandle);

// 创建 UAV Descriptor
D3D12_UNORDERED_ACCESS_VIEW_DESC uavDesc = {};
uavDesc.Format = DXGI_FORMAT_R32_FLOAT;
uavDesc.ViewDimension = D3D12_UAV_DIMENSION_BUFFER;
uavDesc.Buffer.NumElements = bufferCount;
uavDesc.Buffer.FirstElement = 0;
uavDesc.Buffer.Flags = D3D12_UAV_FLAG_NONE;

CD3DX12_CPU_DESCRIPTOR_HANDLE uavHandle(cpuHandle);
uavHandle.Offset(1, descriptorSize);  // 移到下一个 Descriptor
device->CreateUnorderedAccessView(outputBuffer.Get(), nullptr, &uavDesc, uavHandle);

第六步：录制 Command List

现在把所有东西串起来，录制完整的命令序列：

// 1. 重置 Command List
commandList->Reset(commandAllocator.Get(), computePSO.Get());

// 2. Barrier：Transition 资源到正确状态
// （见上文第四步）

// 3. 绑定 Root Signature 和 PSO
commandList->SetGraphicsRootSignature(rootSignature.Get());
commandList->SetPipelineState(computePSO.Get());

// 4. 绑定 Descriptor Table
commandList->SetDescriptorHeaps(1, descriptorHeap.Get());
CD3DX12_GPU_DESCRIPTOR_HANDLE gpuSrvHandle(gpuHandle);
CD3DX12_GPU_DESCRIPTOR_HANDLE gpuUavHandle(gpuHandle);
gpuUavHandle.Offset(1, descriptorSize);
commandList->SetGraphicsRootDescriptorTable(0, gpuSrvHandle);
commandList->SetGraphicsRootDescriptorTable(1, gpuUavHandle);

// 5. Dispatch：发射 1024 / 256 = 4 个 Group
commandList->Dispatch(4, 1, 1);

// 6. Barrier：Transition outputBuffer 到 READ_SOURCE（准备拷回 CPU）
D3D12_RESOURCE_BARRIER readBarrier = {};
readBarrier.Type = D3D12_RESOURCE_BARRIER_TYPE_TRANSITION;
readBarrier.Transition.pResource = outputBuffer.Get();
readBarrier.Transition.StateBefore = D3D12_RESOURCE_STATE_UNORDERED_ACCESS;
readBarrier.Transition.StateAfter = D3D12_RESOURCE_STATE_COPY_SOURCE;
commandList->ResourceBarrier(1, &readBarrier);

// 7. 关闭 Command List
commandList->Close();

第七步：执行与同步

// 提交到 Command Queue
commandQueue->ExecuteCommandLists(1, reinterpret_cast<ID3D12CommandList* const*>(&commandList));

// 等待 GPU 完成
_fenceEvent = CreateEvent(nullptr, FALSE, FALSE, nullptr);
commandQueue->Signal(fence.Get(), fenceValue);
if (fence->GetCompletedValue() < fenceValue)
{
    fence->SetEventOnCompletion(fenceValue, _fenceEvent);
    WaitForSingleObject(_fenceEvent, INFINITE);
}
fenceValue++;

第八步：读取结果

GPU 写入 outputBuffer 后，需要将结果拷回到 CPU 可读的 Readback Buffer：

// 创建 Readback Buffer（Upload Heap —— CPU 可 Map）
Microsoft::WRL::ComPtr<ID3D12Resource> readbackBuffer;
D3D12_RESOURCE_DESC rbDesc = CD3DX12_RESOURCE_DESC::Buffer(bufferSize);
device->CreateResource(&rbDesc, D3D12_RESOURCE_STATE_COPY_DEST,
                       nullptr, IID_PPV_ARGS(&readbackBuffer));

// 录制拷贝命令
commandList->CopyResource(readbackBuffer.Get(), outputBuffer.Get());

// 执行并等待（同上）

// Map 读取
void* mappedData;
readbackBuffer->Map(0, nullptr, &mappedData);
float* results = reinterpret_cast<float*>(mappedData);
for (int i = 0; i < 10; i++)
{
    printf("%.2f^2 = %.2f\n", results[i], results[i]);
}
readbackBuffer->Unmap(0, nullptr);

完整的最小示例结构

将所有步骤整合为一个完整的 main.cpp 骨架：

#include <d3d12.h>
#include <dxgi1_4.h>
#include <wrl.h>
#include <dxerr.h>
#include <fstream>

#pragma comment(lib, "d3d12.lib")
#pragma comment(lib, "dxgi.lib")

using namespace Microsoft::WRL;

int main()
{
    // 1. 创建 Device 和 Queue
    ComPtr<IDXGIFactory4> factory;
    CreateDXGIFactory1(IID_PPV_ARGS(&factory));
    ComPtr<IDXGIAdapter1> adapter;
    factory->EnumAdapters1(0, &adapter);
    ComPtr<ID3D12Device> device;
    D3D12CreateDevice(adapter.Get(), D3D_FEATURE_LEVEL_12_0,
                      IID_PPV_ARGS(&device));

    ComPtr<ID3D12CommandQueue> commandQueue;
    D3D12_COMMAND_QUEUE_DESC qd = {};
    qd.Type = D3D12_COMMAND_LIST_TYPE_COMPUTE;
    device->CreateCommandQueue(&qd, IID_PPV_ARGS(&commandQueue));

    // 2. 创建 Allocator 和 Command List
    ComPtr<ID3D12CommandAllocator> commandAllocator;
    device->CreateCommandAllocator(D3D12_COMMAND_LIST_TYPE_COMPUTE,
                                    IID_PPV_ARGS(&commandAllocator));
    ComPtr<ID3D12GraphicsCommandList> commandList;
    device->CreateCommandList(0, D3D12_COMMAND_LIST_TYPE_COMPUTE,
                               commandAllocator.Get(), nullptr,
                               IID_PPV_ARGS(&commandList));

    // 3. 编译并加载 Shader
    ComPtr<ID3DBlob> shaderBlob;
    LoadFileToString(L"myshader.cso", &shaderBlob);

    // 4. 创建 Root Signature
    //    （见上文第三步）
    ComPtr<ID3D12RootSignature> rootSignature;
    // ...

    // 5. 创建 PSO
    ComPtr<ID3D12PipelineState> computePSO;
    D3D12_COMPUTE_PIPELINE_STATE_DESC psoDesc = {};
    psoDesc.pRootSignature = rootSignature.Get();
    psoDesc.CS = reinterpret_cast<BYTE*>(shaderBlob->GetBufferPointer());
    psoDesc.CS->BufferSize = shaderBlob->GetBufferSize();
    device->CreateComputePipelineState(&psoDesc, IID_PPV_ARGS(&computePSO));

    // 6. 创建资源缓冲区
    //    （见上文第四步）
    ComPtr<ID3D12Resource> inputBuffer, outputBuffer;
    // ...

    // 7. 创建 Descriptor Heap
    //    （见上文第五步）
    ComPtr<ID3D12DescriptorHeap> descriptorHeap;
    // ...

    // 8. 录制 Command List
    //    （见上文第六步）

    // 9. 执行并等待
    //    （见上文第七步）

    // 10. 读取结果
    //     （见上文第八步）

    return 0;
}

常见错误排查

点击展开：DX12 Debug Layer 报错

启用 DX12 Debug Layer 可以获得详细的错误信息：

#ifdef _DEBUG
{
    ComPtr<ID3D12Debug> debug;
    if (SUCCEEDED(device->QueryInterface(IID_PPV_ARGS(&debug))))
    {
        debug->EnableDebugLayer();
    }
}
#endif

运行后，错误信息会出现在 Visual Studio 的输出窗口和 Event Viewer 中。常见错误：

  • "Resource barrier referenced is invalid" → Barrier 的目标资源不存在或状态非法
  • "Descriptor not found" → Descriptor Table 索引超出范围
  • "Wrong resource state" → 忘记 Transition 或 Barrier
点击展开：Dispatch 后结果全为 0

最常见的原因是 Barrier 顺序错误。检查：

  1. inputBuffer 是否正确 Transition 到 NON_PIXEL_SHADER_RESOURCE 后再 Dispatch？
  2. outputBuffer 是否正确 Transition 到 UNORDERED_ACCESS 后再 Dispatch？
  3. Dispatch 后是否正确 Transition outputBuffer 到 COPY_SOURCE 再 CopyResource？

另一个原因：Dispatch 参数不对。如果 numthreads(256, 1, 1)，Dispatch(4, 1, 1) = 1024 个线程。如果 Dispatch(1, 1, 1) = 只有 256 个线程。

本章小结

  • DX12 是显式 API——你需要手动管理 Device、Command List、Descriptor Heap、Resource State
  • Resource Barrier 是 DX12 最核心的概念之一，每个状态变化都需要 Barrier
  • Root Signature 是 Shader 和资源之间的契约
  • Descriptor Heap 存放资源的 GPU 虚拟地址描述符
  • 完整流程：Device → Shader → RootSig → PSO → Resources → Descriptors → CommandList → Execute → Readback
