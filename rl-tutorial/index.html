动手做强化学习

从「智能体为什么会学习」的直觉出发，一步步推到你能亲手做出一个能跑、能调、能讲清楚的强化学习案例。

思想优先 从零推导 完整可运行代码 真实工程经验 毕业项目实战

这套教程不追求让你"听说过"很多算法，而是让你真正建立强化学习的思维方式：懂得如何把一个现实问题描述成"智能体与环境的交互"，懂得奖励、价值、策略之间如何相互推导，并能在代码里把这套循环跑通、调好。学完之后，你应当能独立完成一个强化学习案例。

这套教程适合谁
  • 会 Python 基础语法（函数、类、循环、列表/字典），不要求你懂人工智能
  • 希望系统掌握而非零散了解，愿意动手敲代码、做练习
  • 前半部分（第 0–5 章）只依赖 Python 标准库，零安装即可运行；后半部分进入深度学习时再安装 NumPy / PyTorch（附录有详细指引，也提供浏览器免安装方案）

怎样使用这套教程效果最好

1

动手，而不是只看

每段代码都自己敲一遍并运行；强化学习的理解几乎全部来自"改一个参数、看到现象变化"。

2

讲给自己听

每学完一个算法，用一页纸向"完全不懂的人"复述；卡住的地方就是你的知识漏洞。

3

写训练日志

记录每次实验的超参、奖励曲线、现象与假设。这是强化学习工程师最核心的习惯。
