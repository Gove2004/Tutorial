A 题：乘积不小于长度的区间计数

题目描述

B 级 · 选手回忆 总决赛算法日 A

给定长度为 n 的正整数序列 a[0..n−1]， 求满足 ∏i=be−1 a[i] ≥ e − b（b < e ≤ n）的区间个数。

数据范围：n ≤ 5×105，ai ≤ 103；10% 全为 1，10% 每个数 ∈ {1,2}。

观察

长度最多是 n。乘积一旦超过 n，因为每个数 ≥ 1，继续往左扩展只会让乘积更大、长度也更大， 而乘积已经 > n ≥ 长度，所以更靠左的所有起点都必然满足。

对每个右端点 e，从 e−1 往左扫，遇到 1 就跳过（1 不增大乘积，只让长度变大，条件更难）， 只累乘非 1 的数。每乘一个 ≥2 的数乘积翻倍，最多约 19 次就超过 n。

结算规则

当前乘积为 p，当前非 1 位置为 i，左边最近的非 1 位置为 prev。 起点 b ∈ (prev, i] 的乘积都等于 p，条件化为 b ≥ e − p， 该段贡献 max(0, i − max(prev+1, e−p) + 1) 个区间。

另外，每个右端点都至少有「长度为 1」的区间 [e−1, e) 成立（乘积 ≥ 1，长度 1）。 如果 a[e−1] = 1，它不属于任何非 1 段，要单独补上。 

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n);
    for (auto& x : a) cin >> x;

    // prevNonOne[i] = 下标 <= i 中最后一个非 1 的位置，没有则 -1
    vector<int> prevNonOne(n, -1);
    for (int i = 0; i < n; ++i) {
        if (a[i] > 1) prevNonOne[i] = i;
        else if (i > 0) prevNonOne[i] = prevNonOne[i - 1];
    }

    auto getPrev = [&](int idx) -> int {
        return idx >= 0 ? prevNonOne[idx] : -1;
    };

    ll ans = 0;
    for (int e = 1; e <= n; ++e) {              // 区间为 [b, e)
        int i = getPrev(e - 1);
        if (i < e - 1) ++ans;                   // b = e-1，长度 1 必成立
        if (i < 0) continue;                    // 左侧全是 1，无其他可能

        ll p = 1;
        while (i >= 0) {
            p = min(p * a[i], (ll)n + 1);
            int lo = getPrev(i - 1) + 1;        // 本段最小起点
            int minB = (int)max((ll)lo, (ll)e - p);
            if (minB <= i) ans += i - minB + 1;
            if (p > n) {                        // 更靠左的起点全部成立
                ans += lo;
                break;
            }
            i = getPrev(i - 1);
        }
    }

    cout << ans << '\n';
    return 0;
}

复杂度 O(n log n)：每个右端点最多累乘约 19 次就触发跳出。

选手踩过的坑：把「跳过 1」写成「遇到 1 就 break」

最初版本遇到 1 直接停止扫描，与暴力对拍得到 53 vs 72。1 只是不改变乘积，它左侧的区间仍可能成立， break 会全部丢掉。正确做法是用 prevNonOne 跳到前一个非 1，而不是停止。

B 题：数轴上互不重叠的半径之和

题目描述

B 级 · 选手回忆 总决赛算法日 B

数轴上有 n 个点 x_1 < x_2 < … < x_n。为每个点选非负半径 r_i，要求

ri + ri+1 ≤ di = xi+1 − xi

求 Σ r_i 的最大值。

数据范围：2 ≤ n ≤ 106，xn ≤ 109。

样例：[0,1,5] → 5（取 [1,0,4]）；[0,3,7,10] → 6（取 [3,0,3,0]）。

转成对偶：最小权边覆盖

直接在实数上贪心定半径，容易陷入「当前点取多少」的连续取值困境。这个问题是线性规划，它的对偶是：

对偶问题

在 n−1 条边（边 i 的权为 di）上选一个集合，使每个点都被至少一条选中的边覆盖， 最小化选中边的权值和。由强对偶，其最优值等于原问题的最大 Σri。

路径上的边覆盖有标准 DP：dp0 表示当前点已被覆盖的最小代价，dp1 表示当前点尚未被覆盖 （等右边那条边来盖）的最小代价。

转移

new0 = min(dp0, dp1) + d new1 = dp0 
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll INF = (ll)4e18;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<ll> x(n);
    for (auto& v : x) cin >> v;

    // 第 1 个点只能被边 1 覆盖，此刻还没选边，所以 dp0 = INF
    ll dp0 = INF, dp1 = 0;

    for (int i = 1; i < n; ++i) {
        ll d = x[i] - x[i - 1];
        ll n0 = min(dp0, dp1) + d;   // 选这条边，覆盖当前点与前一个
        ll n1 = dp0;                 // 不选这条边，当前点未覆盖，前一个必须已覆盖
        dp0 = n0;
        dp1 = n1;
    }

    cout << dp0 << '\n';           // 最后一个点必须已被覆盖
    return 0;
}

验证：[0,1,5] → 5；[0,3,7,10] → 6。

不要凭直觉「从外向内」

选手原文提到最初以为最优是「从两端向中间尽量给外侧」。它在小例子上能蒙对，但最优解不唯一 （[3,0,3,0] 与 [0,3,1,3] 并列），贪心没有可证的交换性。 看到线性约束 + 最大化，先问「对偶是不是经典问题」。

C 题：子树并集上的同色果子

题目描述

B 级 · 选手回忆 总决赛算法日 C

以 0 为根的有根树，t(v) 为 v 的子树（含 v）。m 次操作，第 i 次给 t(a_i) ∪ t(b_i) 的每个点放一颗颜色为 i 的果子。

对每个点 u，求有多少个点 v，使 u 与 v 的篮子中存在同色果子。

数据范围：2 ≤ n ≤ 2×105，m ≤ 105。

翻译成集合

颜色 i 出现的点集是 S_i = t(a_i) ∪ t(b_i)，于是：

answer[u] = | ∪i : u ∈ S_i S_i |

u 自己一定在并集里，所以答案至少为 1。

50 分：bitset

给每个点一个 bitset，第 i 位表示「有没有颜色 i」。对每次操作，把两个子树内所有点的第 i 位置 1 （Euler 序下子树是连续区间，可用差分/树状数组批量标记）。 然后对每个 u，把「与 u 有共同颜色」的所有点并入一个 bitset，统计 1 的个数。

点对之间的 bitset 交是 O(m/64)，枚举所有点对是 O(n²/64)，只能过 n 较小的数据。 选手的记录正是「bitset 暴力 50 分」。 

// 50 分思路（伪代码）
// dfn[v] 为 Euler 序，子树对应 [dfn[v], dfn[v] + sz[v])
for (int i = 1; i <= m; ++i) {
    for (int v : subtree(a[i])) hasColor[v].set(i);
    for (int v : subtree(b[i])) hasColor[v].set(i);
}
for (int u = 0; u < n; ++u) {
    bitset<MAXM> uni;
    for (int v = 0; v < n; ++v)
        if ((hasColor[u] & hasColor[v]).any()) uni.set(v);
    cout << uni.count() << '\n';
}

满分方向

  • 子树并 = 两个区间：Euler 序下每个子树是连续区间，t(a) ∪ t(b) 是两个区间的并（相交则合并）。
  • 离线扫描线：把「颜色 i 覆盖区间 I_i」看作区间染色，按右端点扫描，用线段树维护每个左端点的贡献。
  • 按颜色聚合：answer[u] = Σ_i |S_i| [u ∈ S_i] 减去重复计数，重复部分来自多个颜色覆盖同一批点，可用容斥或合并 dfs 序处理。

公开资料没有给出 C 题的完整正解，本章不编造。bitset 版本足够拿 50 分，剩余部分建议沿「区间并 + 扫描线」自己推。

D 题：抽卡次数的期望

题目描述

B 级 · 选手回忆 总决赛算法日 D

有 m 张 A 类卡，价值 a_1…a_m；n 张 B 类卡，价值 b_1…b_n。 所有卡混在一起，每次不放回抽一张，抽到某张的概率正比于它的价值。 一直抽到 A 类卡全部抽完为止，求总抽卡次数的期望，模 998244353。

数据范围：1 ≤ m ≤ 1000，0 ≤ n ≤ 100，ai ≤ 500，bi ≤ 108；n = 0 时答案为 m。

第一步：线性期望

A 类卡一定会被全部抽完，所以总次数 = m + 抽到的 B 类卡数：

E = m + Σj P(Bj 在最后一张 A 之前被抽到)

P(B_j 在最后一张 A 之前) = 1 − P(B_j 排在所有 A 之后)。 于是只需对每张 B 卡求「它排在全部 A 之后」的概率。

第二步：指数时钟

「按价值比例不放回抽」等价于给每张卡 k 一个速率 w_k 的指数时钟，每次抽最先响的那张 （Plackett–Luce 表示）。Bj 排在所有 A 之后 ⟺ T_j > max_i T_i，概率为：

Pj = ∫0∞ bje−bjt ∏i(1 − e−ait) dt

令 u = e−t，化为 Beta 型积分：

Pj = bj ∫01 ubj−1 ∏i(1 − uai) du

把 Q(u) = ∏(1 − uai) = Σ qkuk 展开，则：

Pj = bj Σk qk / (bj + k)

Q 的度数最大为 Σa_i ≤ 5×105。分治 + NTT 可以在 O(D log2D) 内求出所有 qk，再对每张 B 卡做一次 O(D) 求和。 模数选 998244353 正是因为它是 NTT 友好模数——这个信号本身就提示了正解方向。

为什么不能对每个 B 卡单独跑 DP

直接按「A 的子集」做状态是 2m。而 Q(u) 只和 A 的价值有关， 算一次就能给所有 B 卡复用——这是本题的降维点。

小数据实现（多项式乘法用朴素双重循环）

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) { if (e & 1) r = r * a % MOD; a = a * a % MOD; e >>= 1; }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int m, n;
    cin >> m >> n;
    vector<int> a(m), b(n);
    for (auto& v : a) cin >> v;
    for (auto& v : b) cin >> v;

    // Q(u) = Π (1 - u^{a_i})，朴素卷积，仅适合小数据
    vector<ll> q(1, 1);
    int deg = 0;
    for (int ai : a) {
        vector<ll> nq(deg + ai + 1, 0);
        for (int k = 0; k <= deg; ++k) {
            nq[k] = (nq[k] + q[k]) % MOD;
            nq[k + ai] = (nq[k + ai] - q[k] + MOD) % MOD;
        }
        q = nq;
        deg += ai;
    }

    ll ans = m % MOD;
    for (int bj : b) {
        ll p = 0;
        for (int k = 0; k <= deg; ++k) {
            p = (p + q[k] * modpow((ll)bj + k, MOD - 2)) % MOD;
        }
        p = p * bj % MOD;                 // P_j
        ans = (ans + 1 - p + MOD) % MOD;  // 加上「在最后一张 A 之前」的概率
    }

    cout << ans % MOD << '\n';
    return 0;
}

这段代码能验证公式，但 Σa 到 5×105 时既跑不动卷积，也跑不动 n × D 次 modpow。大数据需要：分治 NTT 求 Q；再用线性递推预处理逆元或做多点评值， 把每张 B 卡的求和降到可接受范围。

n = 0 是独立分支

没有 B 卡时，抽卡次数恒为 m，直接输出 m。不要让它走进「n 张卡求和」的循环（会得到 m，但大量数据下 白跑一遍）。

E 题：优化 Satlike-w 局部搜索

题目描述

B 级 · 选手回忆 总决赛算法日 E 300 分

赛题给出一份 Satlike-w（加权 MaxSAT 局部搜索算法）的代码，要求你实现或优化三个函数：

  • void flip(int flipvar)：翻转一个变量，并增量更新所有相关子句的满足状态与权重；
  • void local_search(std::vector<int>& init_solution)：从初始解出发做局部搜索；
  • int pick_var()：选择下一个要翻转的变量。

按最终解的质量（满足的加权子句总权重）给分，总分 300。评分不是「通过/不通过」， 而是按结果好坏分档。

选手记录的现场情况：官方给的代码有下标越界、编辑器频繁崩溃、只能用 gdb 命令行调试； 本地自测 60–70 分（满分 300 的分数段）、给 local_search 加「跳出局部最优」后反而只有 27 分。

这类题在考什么

它不考「你会不会 MaxSAT」，考的是在别人写好的代码上把指标做上去： 读懂增量维护的数据结构、找到瓶颈、做可控的改动、用评测分数验证改动是否有效。 这正是工程岗的日常。

可改的地方常见做法风险
pick_var打分函数改成「make − break」的加权组合、加 tabu 或年龄项改坏后陷入循环，分数暴跌
flip增量更新 score、make、break，避免重算子句漏更新一个数组，静默错误
local_search加扰动、重启、自适应权重、按时间预算提前退出扰动过强会破坏收敛，效果可能比不改更差

增量维护的核心

MaxSAT 局部搜索的每一次 flip(v) 只影响包含 v 的子句。对每个子句维护「当前满足的字面数」， 翻转 v 时： 

// 伪代码：翻转变量 v
void flip(int v) {
    for (int c : clausesContaining[v]) {
        bool wasSat = (satCount[c] > 0);
        // v 在子句 c 中可能是正文字或负文字
        satCount[c] += (v 以正文字出现 ? -1 : +1);
        bool nowSat = (satCount[c] > 0);
        if (wasSat && !nowSat) {
            // 从满足变不满足：该子句权重从得分中扣除，并更新相关变量的 break
            curScore -= weight[c];
            for (int u : varsInClause[c]) breakScore[u] += weight[c];
        } else if (!wasSat && nowSat) {
            curScore += weight[c];
            for (int u : varsInClause[c]) breakScore[u] -= weight[c];
        }
    }
    curSolution[v] ^= 1;
}

这段代码的关键不是「写得对」，而是每改一处都要验证： 修改前后用同一组初始解跑，比较最终分数；如果分数下降，先怀疑增量更新漏了一个数组，而不是怀疑算法。

选手的 27 分教训

他给 local_search 加了「跳出局部最优」的机制，本地测试 60–70 分，正式评测只有 27 分。 可能原因有两类：一是新逻辑改变了搜索的时间预算，导致大部分实例还没收敛就被截断； 二是扰动参数在正式数据分布下过强。这类改动必须在小样本上先验证「改动前后同一初始解」的分数差， 而不是只看「跑完了感觉不错」。

工程环境上的坑

  • 下标越界：官方代码本身有越界，开 -fsanitize=address 先定位，再决定是修还是绕。
  • 编辑器崩溃：文件大、补全插件拖慢时，用 vim/nano 直接改，别在 IDE 里反复重载。
  • 只能用 gdb：提前练会 break、print、bt、watch 四个命令，比现场查文档快。
  • 时间预算：300 分的题通常按「解的质量 + 运行时间」综合给分，先把「不超时」的版本跑通，再谈质量。
可迁移的能力

优化题的本质是「指标驱动开发」：定义指标 → 建立基线 → 做单点改动 → 对比指标 → 保留或回滚。 这套方法同样适用于虚拟机装箱（T5）、模型量化（AI 日）和任何工程题。

本章小结

  • A 题：乘积超过 n 后全部成立，用 prevNonOne 跳过 1，O(n log n)。
  • B 题：最大化问题和「最小权边覆盖」对偶，路径上 O(n) DP。
  • C 题：答案 = 覆盖 u 的所有颜色点集的并；bitset 拿 50 分，满分靠区间并 + 扫描线。
  • D 题：线性期望 → 指数时钟积分 → 多项式 ∏(1−u^{a_i}) → NTT，模数已经给了提示。
  • E 题：在既有代码上调指标，增量更新的正确性优先于花哨的扰动。

这五题里，A、B 是「想到就写完」，C、D 是「想到也写不完」，E 是「写完了也不一定分高」。 总决赛的分数分布，往往取决于你在 C、D 上愿意投入多少时间，以及 E 题能不能稳定跑完。
