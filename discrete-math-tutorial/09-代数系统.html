09 - 代数系统

本章目标：掌握二元运算的封闭性及六条运算性质（交换、结合、幂等、分配、吸收、可逆）；会求幺元、零元、逆元；理解子代数与同态同构，会用运算表读出全部性质。

9.1 代数系统：集合 + 运算

定义 9.1（二元运算与代数系统）

设 S 为集合，函数 f: S × S → S 称为 S 上的二元运算（注意陪域就是 S 本身——这就是封闭性）。集合连同其上若干运算合称代数系统，如 <ℤ, +>、<P(A), ∪, ∩, ~>、<ℤₙ, ⊕ₙ>。

前八章研究"集合里有什么"，接下来三章研究"集合上的运算有什么规律"。加法、乘法、交并、矩阵乘法、函数复合——表面五花八门，背后的代数骨架却惊人地一致。找出骨架、按骨架分类，就是抽象代数的野心，而离散数学负责打前哨。

封闭性是"入场券"：减法在 ℕ 上不封闭（2 − 5 ∉ ℕ），所以 <ℕ, −>连合格代数系统都算不上；除法在 ℤ 上不封闭（1 ÷ 2）。谈任何性质之前，先确认封闭。

9.2 二元运算的性质

定义 9.2（运算性质一览）

性质定义（∀x, y, z ∈ S）正例反例
交换律x * y = y * x+, ×, ∪, ∩−（数）、矩阵乘
结合律(x * y) * z = x * (y * z)+, ×, ∪, 函数复合−、幂运算
幂等律x * x = x∪, ∩, max, min+（2x ≠ x）
分配律x * (y ⊙ z) = (x*y) ⊙ (x*z)×对+，∩对∪，∪对∩+ 对 × 不成立！
吸收律x * (y ⊙ x) = x∪/∩ 互相吸收+
结合律是运算表读不出来的"全局"性质：交换律看运算表是否沿主对角线对称即可；结合律却要对所有三元组验证——4 元运算就要 64 次。所以大多数题目让你证明结合律（恒等变形）而不是从表上"看出来"。

9.3 特殊元素：幺元、零元、逆元

定义 9.3（三件套）

  • 幺元（单位元）e：∀x, e * x = x * e = x。左幺元与右幺元若都存在则相等且唯一。
  • 零元 θ：∀x, θ * x = x * θ = θ。"运算黑洞"，吸走一切。
  • 逆元：若 x * y = y * x = e，称 x 与 y 互逆，记 y = x⁻¹。逆元只在有幺元时才谈得上。

定理 9.1（唯一性）

若幺元存在则唯一；若零元存在则唯一；若运算可结合且 x 有逆元，则逆元唯一。

以幺元为例：设 e、e' 都是幺元，则 e = e * e'（e' 是幺元）= e'（e 是幺元）。一行解决——"两个候选人互相作用"是代数唯一性证明的标准起手式。∎

例 9.1 各系统的"身份档案"

系统幺元零元谁的逆元是谁
<ℤ, +>0无x⁻¹ = −x，人人可逆
<ℤ, ×>10仅 ±1 可逆
<P(A), ∪>∅A仅 ∅ 自身可逆（x∪y=∅ ⇒ x=y=∅）
<P(A), ⊕>（对称差）∅无人人可逆：x⁻¹ = x（自己逆自己！）
<实矩阵, ×>IO行列式非零者可逆

注意第三行与第四行的对比：对称差 ⊕ 是把幂等律换成 x⊕x = ∅ 的"加法型"运算，这一换让全员可逆——它是第 10 章群论中阿贝尔群的完整样本，也是 CRC 校验、差分算法背后的运算。

零元与幺元不可能并存（|S| ≥ 2 时）：若 e ≠ θ，则 θ * e = θ（θ 是零元）但 θ * e = e（e 是幺元），矛盾。所以"有零元就别指望人手一个逆元"——<ℤ, ×> 永远成不了群（第 10 章伏笔）。

9.5 子代数、同态与同构

定义 9.4（子代数）

B ⊆ S 且对运算封闭，则 <B, *> 是 <S, *> 的子代数。子代数继承父系统的全部"恒等式性质"（交换、结合等），但可能丢失特殊元素：<偶数, +> 是 <ℤ, +> 的子代数，保留了结合交换，却把幺元 0 丢了？不——0 是偶数，幺元还在；但 <正偶数, +> 就真丢幺元了。

定义 9.5（同态与同构）

设 <S, *> 与 <T, ○> 为两个代数系统。映射 h: S → T 若满足 h(x * y) = h(x) ○ h(y)（像的运算 = 运算的像），则 h 是同态映射。h 双射时称为同构，两系统记作 S ≅ T。

例 9.3 经典同态

  • 取对数：h: <ℝ⁺, ×> → <ℝ, +>，h(x) = ln x。h(xy) = ln x + ln y ✓。乘法世界的难题被搬进加法世界解决——对数表就是最早的"同态加速器"，纳皮尔 1614 年的发明。
  • 取绝对值？h(x) = |x| 对 <ℤ, +>：|1 + (−1)| = 0 而 |1| + |−1| = 2，不保运算，不是同态。反例也要会举。
  • 模映射：h: <ℤ, +> → <ℤₙ, ⊕ₙ>，h(x) = x mod n。h(x+y) = h(x)⊕h(y) ✓。这是"投影同态"，第 10 章拉格朗日定理的商结构就是它的推广。
同构的哲学：两个系统同构 = 它们只是同一结构的两套记号（把运算表重命名即可互换）。"数学里没有第二个抽象群，只有同一个抽象群的无数件外衣。"判断两系统同构，先比基数，再试构造保运算的双射，最后可用特殊元素当"指纹"（幺元必须映到幺元、零元映到零元、逆元映到逆元——同态的必然后果）。

9.6 自测题

  1. <ℤ, −>（减法）是否封闭？是否交换？是否结合？有无幺元？
  2. 在 <P({a,b}), ∪, ∩, ~> 中求 ∅ 与 {a,b} 在 ∪ 运算下的角色（幺元还是零元？）。
  3. 证明：若 * 可结合且 x 有左逆 y 与右逆 z（y*x = x*z = e），则 y = z。
  4. 判断 h(x) = x² 是否为 <ℝ, +> 到 <ℝ, +> 的同态。
  5. <ℤ, +> 与 <2ℤ（全体偶数）, +> 同构吗？构造映射或说明理由。
参考答案（先做再看）
  1. ℤ 上封闭 ✓；不交换（1−2 ≠ 2−1）；不结合（(1−2)−3 = −4 而 1−(2−3) = 2）；无幺元（若有 e，则 x − e = x 对一切 x 要求 e = 0，但 0 − x ≠ x）。
  2. ∅ 是 ∪ 的幺元（∅∪X = X）；{a,b}（全集）是 ∪ 的零元（{a,b}∪X = {a,b}）。
  3. y = y*e = y*(x*z) = (y*x)*z = e*z = z。中间一步用了结合律——再次证明"没有结合律就没有代数"。∎
  4. 不是。反例：h(1+1) = 4 而 h(1)+h(1) = 2。加法不"平方分配"。
  5. 同构。h(x) = 2x 是双射，且 h(x+y) = 2(x+y) = 2x + 2y = h(x)+h(y) ✓。两系统结构完全一样——ℤ 和它的"偶数复本"在代数上无法区分。
本章小结：封闭性是入场券；六性质 + 三特殊元素（幺零逆）是代数系统的"体检表"；运算表能读出交换、幺元、逆元、消去律；同态保运算、同构是换皮。满足"结合 + 幺元 + 人人可逆"的系统叫群——下一章的主角。
