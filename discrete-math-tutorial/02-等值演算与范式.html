02 - 等值演算与范式

本章目标：掌握 24 条基本等值式并会用它们做等值演算；会判别重言式、矛盾式、可满足式；会求公式的析取/合取范式与主范式，并理解主范式与真值表的对应关系。

2.1 等值式：形式不同，本质相同

定义 2.1（等值）

设 A、B 是两个命题公式。若 A ↔ B 是重言式（在任何指派下都为真），则称 A 与 B 等值，记作 A ⇔ B。

判断等值有两条路：真值表法（把所有指派列出来，简单但变元一多就爆炸）和等值演算法（用已知的等值式一步步变形，这是主力工具）。先把基本等值式集齐：

基本等值式（必须背熟）

名称形式
双否定A ⇔ ¬¬A
幂等律A ⇔ A ∧ A；A ⇔ A ∨ A
交换律A ∧ B ⇔ B ∧ A；∨ 同理
结合律(A ∧ B) ∧ C ⇔ A ∧ (B ∧ C)；∨ 同理
分配律A ∧ (B ∨ C) ⇔ (A ∧ B) ∨ (A ∧ C)；∧ ∨ 互换同理（注意：∧ 对 ∨ 也分配，比初等代数强）
德摩根律¬(A ∧ B) ⇔ ¬A ∨ ¬B；¬(A ∨ B) ⇔ ¬A ∧ ¬B
吸收律A ∨ (A ∧ B) ⇔ A；A ∧ (A ∨ B) ⇔ A
零律 / 律A ∨ 1 ⇔ 1；A ∧ 0 ⇔ 0
同一律A ∨ 0 ⇔ A；A ∧ 1 ⇔ A
排中律 / 矛盾律A ∨ ¬A ⇔ 1；A ∧ ¬A ⇔ 0
蕴含展开A → B ⇔ ¬A ∨ B（最高频！）
等价展开A ↔ B ⇔ (A → B) ∧ (B → A)
假言三段论（可推导式）(A → B) ∧ (B → C) ⇔ (A → C)
逆否律A → B ⇔ ¬B → ¬A
归谬式(A → B) ∧ (A → ¬B) ⇔ ¬A
两条变形规则（初学者最容易越界）
  • 置换规则：等值式中可以把子公式整体换成等值的子公式——它保持等值，任何时候都能用。
  • 代入规则：把等值式中的变元统一替换成任意公式——用于生成新等值式。
  • 但注意：等值演算中不能使用"A → B 且 A 为真 ⇒ 得 B"这类推理（那是第 3 章的规则）。等值链每一环都必须是 ⇔，一旦写成 →，整条演算就作废。

例 2.1 化简 p ∨ (¬p ∧ (p ∨ q))

p ∨ (¬p ∧ (p ∨ q))
⇔ (p ∨ ¬p) ∧ (p ∨ p ∨ q)　　（分配律）
⇔ 1 ∧ (p ∨ q)　　（排中律、幂等律）
⇔ p ∨ q　　（同一律）

每一步右侧括号注明用的规则，这是标准答题格式——不写依据会被扣分。

2.2 重言式、矛盾式与可满足式

定义 2.2（公式类型）

  • 重言式（永真式）：一切指派下均为真。如 p ∨ ¬p。
  • 矛盾式（永假式）：一切指派下均为假。如 p ∧ ¬p。
  • 可满足式：至少存在一组指派使其为真。重言式是特殊的可满足式。
快速判别技巧：化简结果为 1 ⇒ 重言式；为 0 ⇒ 矛盾式；否则看极小项数量（见下）。注意一个事实：A 是矛盾式 ⇔ ¬A 是重言式。"A ⇔ B"与"A ↔ B 是重言式"是同一件事的两种说法。

2.3 析取范式与合取范式

定义 2.3（文字与范式）

  • 文字：命题变元或它的否定，如 p、¬q。
  • 析取范式：若干"文字的合取"（称为合取子式）的析取，形如 (p ∧ ¬q) ∨ (¬p ∧ r)。
  • 合取范式：若干"文字的析取"（析取子式）的合取，形如 (p ∨ ¬q) ∧ (¬p ∨ r)。

任何公式都能化成这两种范式，流程固定三步：

1
消去 → 与 ↔：用 A → B ⇔ ¬A ∨ B 和等价展开式。
2
让否定号只出现在变元前：反复使用双否定律和德摩根律。
3
分配：往析取范式方向用 ∧ 对 ∨ 的分配律；往合取范式方向用 ∨ 对 ∧ 的分配律。
经典错误：从 (p ∧ q) ∨ r 化合取范式时写成 p ∧ q ∨ r 或 ( p ∨ r ) ∧ q。正确做法是 ∨ 对 ∧ 分配：( p ∨ r ) ∧ ( q ∨ r )。分配律方向一错，整题全错。

2.4 主范式：给公式发"身份证"

普通范式不唯一（(p ∧ q) 和 (p ∧ q) ∨ (p ∧ q) 都是析取范式），要唯一化就需要主范式。

定义 2.4（极小项与主析取范式）

  • 极小项：每个变元（带否定或不带）恰好出现一次的合取子式。两个变元有 4 个极小项：p ∧ q、p ∧ ¬q、¬p ∧ q、¬p ∧ ¬q。
  • 编码约定：变元取 1 时以正身出现、取 0 时以否定出现。于是极小项 ↔ 使它为真的唯一指派一一对应：¬p ∧ q 记作 m01（即 m1）。
  • 主析取范式：由极小项构成的析取范式，按编码升序书写。每个非矛盾公式的主析取范式唯一。

定理 2.1（主范式与真值表的对应）

公式 A 的主析取范式 = 所有使 A 为真的指派对应的极小项之析取。极小项的个数就是公式为真的指派个数。对偶地，主合取范式 = 所有使 A 为假的指派对应的极大项之合取。

例 2.2 求 (p → q) ∧ q 的主析取范式

(p → q) ∧ q ⇔ (¬p ∨ q) ∧ q　　（蕴含展开）
⇔ (¬p ∧ q) ∨ (q ∧ q)　　（分配）
⇔ (¬p ∧ q) ∨ q　　（幂等）
⇔ (¬p ∧ q) ∨ ((p ∨ ¬p) ∧ q)　　（补上缺的变元！）
⇔ (¬p ∧ q) ∨ (p ∧ q) ∨ (¬p ∧ q)
⇔ (p ∧ q) ∨ (¬p ∧ q) ⇔ m11 ∨ m01 ⇔ Σ(1, 3)

关键一步是"补变元"：q 里缺 p，就乘上 (p ∨ ¬p) 拆开——这一步叫配项。真值表交叉验证：p=0,q=1 与 p=1,q=1 两行公式为真，恰好 2 个极小项，吻合 ✓。

2.5 主范式的三个应用

2.5.1 判断两公式是否等值

两公式等值 ⇔ 主析取范式完全相同（包括缺项情况）。这比列 2n 行真值表更适合变元多的场合。

2.5.2 判断公式类型

  • 主析取范式含全部 2n 个极小项 ⇒ 重言式。
  • 主析取范式一个极小项都没有（记作 0）⇒ 矛盾式。
  • 其余 ⇒ 非重言的可满足式。

2.5.3 从真值表反推公式（逻辑电路设计）

给定一个真值函数（比如"过半数表决器"：三人投票，至少两人同意才通过），把每个输出为 1 的行写成极小项再析取起来即可。表决器 = (p ∧ q) ∨ (p ∧ r) ∨ (q ∧ r)。这就是数字电路中"组合逻辑设计"的数学原型——真值表自动生成电路，再用卡诺图或第 15 章之外的化简工具压缩门数。

极大项怎么写？与极小项对偶：变元取 0 时以正身出现、取 1 时以否定出现（"0 正 1 反"，和极小项正好相反，容易记混）。主合取范式中的极大项个数 = 公式为假的指派个数，且 主析取范式与主合取范式的编码互补：Σ(1,3) 对应 Π(0,2)。

2.6 自测题

  1. 用等值演算法化简 ¬(p → q) ∨ (¬p ∧ ¬q)，指出其类型。
  2. 求 p ∧ (p → q) 的主析取范式。
  3. 已知两公式主析取范式分别为 Σ(0,2) 与 ¬(p ∧ q)，判断它们是否等值。
  4. "A ⇔ B"和"A ↔ B"有何区别？
  5. 设计一个"两位二进制数相等检测器"：输入两位 p1p0 与 q1q0（只需比较 p1 与 q1、p0 与 q0 两对即可），写出相等时为 1 的表达式。
参考答案（先做再看）
  1. ¬(p → q) ⇔ ¬(¬p ∨ q) ⇔ p ∧ ¬q；原式 ⇔ (p ∧ ¬q) ∨ (¬p ∧ ¬q) ⇔ ( (p ∨ ¬p) ∧ ¬q ) ⇔ ¬q。既非重言也非矛盾，是可满足式。
  2. p ∧ (¬p ∨ q) ⇔ (p ∧ ¬p) ∨ (p ∧ q) ⇔ p ∧ q ⇔ m11 ⇔ Σ(3)。真值表验证：只有 p=1, q=1 时为真。
  3. ¬(p ∧ q) ⇔ ¬p ∨ ¬q（德摩根），真值为真的指派是 (0,0),(0,1),(1,0)，即 Σ(0,1,2) ≠ Σ(0,2)。不等值。
  4. A ↔ B 是一个命题公式，真值可真可假；"A ⇔ B"是断言 A ↔ B 恒为真（即它是重言式），是关于两个公式关系的元级陈述。
  5. 相等 ⇔ 每一位都相同：(p1 ↔ q1) ∧ (p0 ↔ q0)。展开为极小项即 Σ(5, 10, 15)（位对相同时的指派 0101, 1010, 1111 —— 视约定顺序而定）。
本章小结：等值 ⇔ 双蕴含是重言式；等值演算的每一步都要写依据；主析取范式 = 为真指派的极小项之析取，唯一且与真值表一一对应；主范式是"判断等值 / 判型 / 反推公式"三合一的利器。下一步：从"变形"走向"推理"。
