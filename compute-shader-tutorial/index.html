Compute Shader 入门到精通

从零开始系统掌握 GPU 并行计算编程，涵盖 DirectX 12 和 Vulkan 两种 API，通过三个完整实战项目（图像滤镜、粒子系统、GPU 加速算法）深入理解 Compute Shader 的核心机制与性能优化。

关于本教程：
  • 前置知识：C++ 基础、线性代数（矩阵/向量运算）、基本的图形学概念（坐标系、纹理）
  • 学习深度：系统掌握 — 核心概念 + 实战项目 + 性能优化 + 最佳实践
  • 支持 API：DirectX 12（主要）、Vulkan（对比）、OpenGL Compute Shader（附录）
  • 主题风格：技术蓝（适合编程/图形类教程）

版本：v1.0 | 更新日期：2026-07-02

适用环境：DX12 (SDK 2021+) / Vulkan 1.3 / HLSL 6.x

课程目录

基础

01 - 初识 GPU 并行计算

为什么需要 GPU 计算？CPU 与 GPU 架构的本质差异，SIMT 模型，以及 Compute Shader 相比传统渲染管线的革命性意义。

基础

02 - HLSL/GLSL 语言基础

Shader 编程语言入门：数据类型、内置函数、精度修饰符。HLSL 与 GLSL 的异同对比，Shader Model 版本演进。

基础

03 - Compute Shader 核心概念

Thread Group、Dispatch、Rendezvous Barrier 三大核心概念。全局线程模型、内存层级结构、Resource Binding 机制。

进阶

04 - DX12 Compute Pipeline 搭建

从零创建 DX12 Compute Pipeline：Descriptor Heap、Root Signature、Pipeline State、Command Queue 完整流程。附可运行的最小示例。

进阶

05 - 内存模型与同步机制

Shared Memory、Texture SRV/UAV、Constant Buffer 的延迟与一致性。Barrier 语义、Memory Model 限定符、Sync Group 的精确含义。

进阶

06 - 实战一：GPU 图像滤镜

实现高斯模糊、Sobel 边缘检测、色调映射。Texture UAV 读写、采样器状态、像素坐标映射。从单通道到 HDR 管线。

进阶

07 - 实战二：百万级粒子系统

Compute Shader 驱动粒子模拟：Velocity Verlet 积分、碰撞检测、GPU Instancing 渲染。Structured Buffer 与 Append/Consume Buffer。

高级

08 - 实战三：GPU 加速算法

Prefix Sum（扫描算法）、Radix Sort、并行 Reduce。算法映射到 SIMT 模型的思维转换，Work Reduction 范式。

高级

09 - 性能优化实战

Warp/Wavefront 分析、Bank Conflict 消除、指令级优化、Occupancy 调优。使用 PIX / RenderDoc / Nsight 进行 Profiling。

高级

10 - 进阶：Ray Tracing 与 Mesh Shader

DXR 光线追踪管线、Acceleration Structure、Mesh Shader (SM5.0)。Compute Shader 在现代图形管线中的角色演变。

学习路线建议

1

第一阶段：打基础（第 1-3 章）

理解 GPU 架构本质和 Compute Shader 的核心抽象。不需要写代码，但要能解释清楚 Thread Group、Dispatch、Shared Memory 的概念。

2

第二阶段：动手实践（第 4-7 章）

搭建 DX12 环境，完成三个实战项目。每个项目都应该是可运行的独立程序，建议配合 Git 管理版本。

3

第三阶段：深入优化（第 8-10 章）

掌握算法级优化和硬件级优化。学会使用 Profiler 定位瓶颈，理解每条指令在 GPU 上的实际代价。

开发环境推荐

  • 操作系统：Windows 10/11（DX12 最佳支持）
  • GPU：NVIDIA / AMD / Intel Arc 均可，不同厂商的 Warp Size 可能不同（NVIDIA 32，AMD 64）
  • SDK：Windows SDK 10.0.19041+（DX12）、Vulkan SDK 1.3+
  • IDE：Visual Studio 2022（推荐）或 VS Code + CMake
  • 调试工具：PIX in Windows（DX12）、RenderDoc（跨平台）、Nsight Graphics（NVIDIA）
