第 1 章：导论：强化学习与 PyTorch 配置

1.1 强化学习是什么

强化学习（Reinforcement Learning, RL）是机器学习的三大范式之一，与监督学习、无监督学习并列。它的核心思想可以用一句话概括：

强化学习的定义

强化学习研究的是智能体（Agent）如何在环境（Environment）中通过与环境的持续交互，学习出最优行为策略，以最大化累积奖励。

与监督学习的关键区别在于：

维度监督学习强化学习
学习方式 从标注数据中学映射 从试错交互中学策略
反馈信号 明确的正确答案 延迟的标量奖励（Reward）
数据独立性 样本独立同分布（i.i.d.） 样本序列相关（非 i.i.d.）
时间维度 无时间概念 关键维度：当前动作影响未来状态
直觉类比：想象一只狗学指令。你不可能每次都告诉它"左边转 30 度、然后前进两步"，而是通过零食（正奖励）和斥责（负奖励）来引导。狗需要通过多次试错，自己发现"坐下→得到零食"的因果关联。这就是强化学习的本质。

1.2 环境交互循环

强化学习的核心是一个循环过程，如下所示：

# 强化学习交互循环（伪代码）
# 初始化环境
state = env.reset()

for episode in range(num_episodes):
    done = False
    while not done:
        # Agent 根据当前状态选择动作
        action = agent.select_action(state)

        # 执行动作，获取新状态和奖励
        next_state, reward, done, info = env.step(action)

        # Agent 学习：存储经验并更新策略
        agent.learn(state, action, reward, next_state, done)

        # 状态转移
        state = next_state

这个循环看似简单，但它蕴含了强化学习的所有核心问题：

  • Agent 如何选择动作？ —— 这是 agent.select_action 要解决的问题（探索 vs 利用）
  • 奖励如何设计？ —— 这是任务建模的核心，奖励信号直接决定了 Agent 学到什么
  • Agent 如何学习？ —— 这是算法的核心，如何将经验转化为更好的策略
  • 状态如何表示？ —— 输入空间的结构决定了神经网络的设计和泛化能力

1.3 环境类型：离散 vs 连续

Gymnasium（OpenAI Gym 的继任者）提供了丰富的环境，按动作空间可分为：

离散动作空间：动作集合有限且可枚举。

import gymnasium as gym
env = gym.make("CartPole-v1")
print(f"动作空间: {env.action_space}")
print(f"动作数: {env.action_space.n}")  # 输出: 2 (左移 / 右移)

适用算法：DQN、REINFORCE、PPO（多项式分布）

连续动作空间：动作是连续向量。

env = gym.make("Pendulum-v1")
print(f"动作空间: {env.action_space}")
# Box(1,) 表示 1 维连续空间，范围 [-2, 2]
print(f"动作范围: [{env.action_space.low}, {env.action_space.high}]")

适用算法：PPO（高斯分布）、DDPG、SAC（不适用 DQN）

混合动作空间：同时包含离散和连续维度。

# 例如：选择移动方向（离散）+ 施加力度（连续）
# Gymnasium 支持 MultiDiscrete 和 MultiBinary 空间
from gymnasium.spaces import MultiDiscrete, MultiBinary

适用算法：专用网络结构（分别输出离散和连续部分），通常使用 PPO 变体

1.5 第一个强化学习程序

在深入算法之前，我们先写一个最简单的强化学习循环——随机策略（Random Policy），作为后续比较的基线：

import gymnasium as gym
import numpy as np
import matplotlib.pyplot as plt

# 创建环境
env = gym.make("CartPole-v1")

# 随机策略运行 100 个 episode
rewards = []
for episode in range(100):
    state, info = env.reset()
    total_reward = 0
    done = False
    truncated = False

    while not done and not truncated:
        # 随机选择动作
        action = env.action_space.sample()
        state, reward, done, truncated, info = env.step(action)
        total_reward += reward

    rewards.append(total_reward)
    if (episode + 1) % 10 == 0:
        print(f"Episode {episode + 1}: 总奖励 = {total_reward}")

env.close()

# 统计结果
print(f"\n随机策略 - 平均奖励: {np.mean(rewards):.2f}")
print(f"随机策略 - 最佳奖励: {np.max(rewards)}")

# 绘制奖励分布
plt.figure(figsize=(10, 4))
plt.subplot(1, 2, 1)
plt.hist(rewards, bins=20, edgecolor='black', alpha=0.7)
plt.xlabel('总奖励')
plt.ylabel('Episode 数')
plt.title('随机策略奖励分布')
plt.axvline(np.mean(rewards), color='r', linestyle='--', label=f'均值: {np.mean(rewards):.1f}')
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(rewards)
plt.xlabel('Episode')
plt.ylabel('总奖励')
plt.title('100 个 Episode 的奖励曲线')
plt.tight_layout()
plt.savefig('random-baseline.png', dpi=150)
plt.show()

运行这个程序后，你会观察到随机策略的 CartPole 通常只能维持几秒（奖励约 20 左右，而满分是 500）。接下来的章节将逐步教你如何让 Agent 学会完美平衡杆子。

1.6 本章小结

  • 强化学习 = Agent 通过与环境交互试错来学习最优策略
  • 核心循环：观察状态 → 选择动作 → 执行动作 → 获得奖励 → 更新策略
  • 离散动作 vs 连续动作决定了算法的选择方向
  • 使用 Gymnasium 而非已停更的 gym 库
  • 随机策略是重要的基线，用于验证算法确实学到了东西
