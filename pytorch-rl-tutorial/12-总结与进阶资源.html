12.2 算法选型决策树

面对一个新任务，如何选择算法？以下是决策参考：

"""
算法选型速查表
"""
def select_algorithm(task_info):
    """
    task_info: dict with keys:
        - action_space: 'discrete' | 'continuous' | 'mixed'
        - observation: 'low_dim' | 'image' | 'text'
        - reward_sparse: bool
        - episode_length: 'short' | 'medium' | 'long'
        - compute_budget: 'low' | 'medium' | 'high'
    """
    # 第一步：动作空间决定算法大类
    if task_info['action_space'] == 'discrete':
        # 离散动作：Q-Learning 系或 PPO
        if task_info['episode_length'] == 'short':
            return "DQN"  # 简单快速
        else:
            return "PPO"  # 稳定高效

    elif task_info['action_space'] == 'continuous':
        # 连续动作：只能选策略梯度系
        if task_info['reward_sparse']:
            return "SAC"  # 稀疏奖励友好
        else:
            return "PPO"  # 通用首选

    elif task_info['action_space'] == 'mixed':
        return "PPO"  # 最灵活

    # 第二步：资源限制
    if task_info['compute_budget'] == 'low':
        return "REINFORCE"  # 实现最简单
    elif task_info['compute_budget'] == 'high':
        return "PPO"  # 充分利用资源

    # 第三步：特殊场景
    if task_info['observation'] == 'image':
        return "DQN" if task_info['action_space'] == 'discrete' else "PPO"
    if task_info['reward_sparse']:
        return "SAC" if task_info['action_space'] == 'continuous' else "PPO"

    return "PPO"  # 默认兜底

2.3 常见失败模式与解决方案

问题症状排查方向
训练不收敛 奖励曲线持续波动，无上升趋势 降低学习率、增大 batch_size、检查 reward 缩放
策略退化 熵迅速降至 0，策略变得确定性 增大 entropy_coef、降低 lr、检查是否 reward hacking
Overshooting Q 值爆炸式增长 启用 Double DQN、检查目标网络更新频率
探索不足 Agent 卡在局部最优 增大 epsilon、检查 reward 信号是否有区分度
OOM 显存不足 减小 batch_size、降低序列长度、使用梯度累积
CUDA out of memory 训练中途崩溃 添加 torch.cuda.empty_cache()、减小网络规模
