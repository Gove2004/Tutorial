13　环境搭建与实战演练

本章给出一条可直接照做的路径：从空 Conda 环境到跑通 Demo、批量转换数据、训练并验证。命令均来自官方安装文档， 平台以你当前的 Windows 为主，并附 Linux 版本。

13.1 创建环境

框架要求 Python 3.12+，使用 Conda 管理环境：

conda create -n AI4AnimationPY python=3.12
conda activate AI4AnimationPY

13.2 Windows 安装（GPU）

pip install msvc-runtime==14.40.33807
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install nvidia-cudnn-cu12==9.3.0.75 nvidia-cuda-runtime-cu12==12.5.82 nvidia-cufft-cu12==11.2.3.61
pip install onnxruntime-gpu==1.19.0
pip install -e . --use-pep517
关于 CUDA 版本

官方文档明确提示：需要根据 GPU 调整 PyTorch/CUDA 版本。文档默认 cu124 是撰写时的基线；较新架构的显卡 （如 Blackwell 架构）应改用对应更新的 CUDA 索引安装，不要机械照抄 cu124。

13.3 Linux 安装（无显示器服务器）

conda create -y -n AI4AnimationPY python=3.12 pip
conda activate AI4AnimationPY
pip install torch torchvision torchaudio onnx raylib numpy scipy matplotlib scikit-learn einops pygltflib pyscreenrec tqdm pyyaml ipython
pip install onnxruntime-gpu
pip install -e . --no-dependencies

macOS 流程相同，把 onnxruntime-gpu 换成 onnxruntime。

13.4 验证安装

python Demos/Empty/Program.py
python Demos/Actor/Program.py

第一个无报错即安装成功；第二个会打开独立窗口显示角色模型。

13.6 数据转换

代码内单文件加载

from ai4animation import Motion

glb_motion = Motion.LoadFromGLB("character.glb", names=bone_names, floor=None)
fbx_motion = Motion.LoadFromFBX("character.fbx")
bvh_motion = Motion.LoadFromBVH("character.bvh", scale=0.01)
npz_motion = Motion.LoadFromNPZ("character.npz")

glb_motion.SaveToNPZ("character")
两个依赖要点
  • BVH 常以厘米为单位，必须传 scale=0.01 转米；GLB 与 BVH 开箱即用，无额外依赖
  • FBX 导入需要单独安装 Autodesk FBX SDK Python 绑定并配置 FBXSDK_ROOT、FBXSDK_COMPILER 环境变量

CLI 批量转换

convert --input_dir path/to/motions --output_dir path/to/output --skeleton Cranberry
参数说明
--input_dir含 GLB/FBX/BVH 的目录，递归搜索
--output_dirNPZ 输出目录，默认 input_dir/NPZ
--skeleton可选骨骼过滤定义：Cranberry 或 Geno
--bvh_scaleBVH 位置缩放，默认 0.01

13.7 构建数据集与运动浏览

from ai4animation import (
    AI4Animation, MotionEditor, Dataset,
    RootModule, MotionModule, ContactModule, GuidanceModule,
)

class Program:
    def Start(self):
        editor = AI4Animation.Scene.AddEntity("MotionEditor")
        editor.AddComponent(
            MotionEditor,
            Dataset(npz_path, [
                lambda x: RootModule(x, Definitions.HipName,
                    Definitions.LeftHipName, Definitions.RightHipName,
                    Definitions.LeftShoulderName, Definitions.RightShoulderName),
                lambda x: MotionModule(x),
                lambda x: ContactModule(x, [
                    (Definitions.LeftAnkleName, 0.1, 0.25),
                    (Definitions.LeftBallName, 0.05, 0.25),
                    (Definitions.RightAnkleName, 0.1, 0.25),
                    (Definitions.RightBallName, 0.05, 0.25),
                ]),
                lambda x: GuidanceModule(x),
            ]),
            model_path, bone_names
        )
        AI4Animation.Standalone.Camera.SetTarget(editor)

    def Update(self):
        pass

if __name__ == "__main__":
    AI4Animation(Program())

MotionEditor 提供时间轴 GUI，可拖动浏览 NPZ 片段并检查接触与轨迹是否正确——这是训练前必须做的数据质检环节。

13.8 推荐的实战推进顺序

1

跑通 Empty 与 Actor，确认环境与渲染正常

2

取 3–5 个 BVH 用 convert 转 NPZ，检查单位与骨骼名

3

用 MotionEditor 逐片段质检，确认接触标签与根轨迹

4

先在小数据子集训练 MLP 基线，跑通完整训练-评估回路

5

再换用 PFNN/MANN 等目标模型，全量训练并导出 ONNX

13.9 故障排查

现象可能原因处理
ImportError: 找不到包未激活环境或未用 -e 安装确认 conda 环境，重新 pip install -e .
torch 无法调用 CUDACUDA 版本与显卡不匹配按 GPU 架构换对应 PyTorch 索引重装
角色尺寸异常放大/缩小BVH 厘米未转米LoadFromBVH 或 convert 传 scale=0.01
STANDALONE 无法开窗远程/无显示环境或 raylib 缺失改用 HEADLESS，或补齐 raylib 依赖
FBX 导入报错未装 FBX SDK 绑定配置 FBXSDK_ROOT 等环境变量后安装绑定
onnxruntime 初始化失败GPU 版与驱动不匹配核对驱动版本，必要时退回 CPU 版 onnxruntime

1

全流程

独立完成一次"BVH → NPZ → MotionEditor 质检 → 小数据训练"，记录每一步的实际耗时与遇到的报错。

2

环境判断

解释为什么在你当前显卡上不能直接照抄 cu124 命令，应如何确定正确的 PyTorch 版本。

本章小结

  • Python 3.12 + Conda，Windows 用 GPU 版安装、Linux 服务器装无窗口依赖，editable 模式安装
  • 执行模式为 HEADLESS 与 STANDALONE；BVH 必须 scale=0.01，FBX 需额外 SDK
  • convert 支持批量转换，MotionEditor 是训练前的数据质检入口
  • 先小数据跑通基线再全量训练，是降低返工成本的标准推进方式
