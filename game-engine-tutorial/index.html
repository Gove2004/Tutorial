从零构建游戏引擎入门到精通

系统掌握游戏引擎的每一个核心子系统：渲染管线、数学基础、场景图、资源管理、物理引擎、音频系统、输入系统、编辑器开发。不只是 API 调用，而是理解每个子系统的设计哲学、数据结构和性能权衡。

关于本教程：
  • 前置知识：C/C++ 基础、线性代数（矩阵/向量）、基本的图形学概念
  • 学习深度：系统掌握 — 核心架构 + 数据结构 + 性能权衡
  • 引擎类型：2D 为主，兼顾 3D 扩展
  • 主题风格：技术蓝（适合编程/架构类教程）

版本：v1.0 | 更新日期：2026-07-02

适用环境：C++17 / OpenGL 4.6 / SDL2 / GLFW / GLM

课程目录

基础

01 - 游戏引擎架构全景

渲染/物理/音频/场景图/资源管理五大子系统。引擎 vs 框架 vs 库的区别，单体架构 vs 模块化架构。

基础

02 - 渲染管线

02 - 渲染管线：从顶点到像素

固定功能管线到可编程管线的演进。顶点着色器、几何着色器、光栅化、片段着色器。Draw Call 优化与 Batch。

基础

03 - 数学基础

向量、矩阵、四元数、变换。齐次坐标、投影矩阵、空间划分（BVH/Octree/BSP）。

进阶

04 - 场景图与实体系统

Scene Graph 设计、ECS 架构、节点树遍历、空间索引。从 OOP 到 ECS 的架构演进。

进阶

05 - 资源管理

05 - 资源管理：加载、流送、缓存

Asset Pipeline、纹理/模型/音频加载、异步加载、资源引用计数、热重载。

进阶

06 - 物理引擎

06 - 物理引擎：碰撞检测与刚体动力学

碰撞检测（SAT/GJK/EPA）、刚体动力学、约束求解、积分器（Verlet/Runge-Kutta）。

高级

高级

事件总线、输入映射、手柄支持、输入缓冲、宏/连招系统、跨平台输入抽象。

高级

09 - 编辑器开发

09 - 编辑器开发：UI 框架与场景编辑

Dear ImGui、场景编辑器、属性面板、撤销/重做、序列化、插件系统。

高级

10 - 实战：从零构建 2D 游戏引擎

从架构设计到完整项目：Sprite 渲染、Tilemap、粒子系统、脚本集成、打包发布。

学习路线建议

1

第一阶段：理解架构（第 1-3 章）

渲染管线、数学基础。不写代码，先理解引擎的"身体"是怎么运作的。

2

第二阶段：核心子系统（第 4-6 章）

第二阶段：核心子系统（第 4-6 章）

场景图、资源管理、物理引擎。这些是引擎的"内脏"，决定引擎的能力和上限。

3

第三阶段：外围系统与工具（第 7-9 章）

音频、输入、编辑器。这些让引擎变得"可用"和"好用"。

4

第四阶段：完整项目（第 10 章）

把所有子系统整合到一个完整的 2D 引擎中，从设计到发布。

开发环境与工具链

  • 语言：C++17（推荐）或 C++20
  • 图形 API：OpenGL 4.6（教学用）或 Vulkan（生产用）
  • 窗口/输入：SDL2 或 GLFW
  • 数学库：GLM（OpenGL Mathematics）
  • 音频：FMOD Studio 或 OpenAL
  • 编辑器 UI：Dear ImGui
  • 构建系统：CMake 3.20+
  • IDE：Visual Studio 2022 / CLion / VS Code
