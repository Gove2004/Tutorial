07 - 等价关系与偏序

本章目标：掌握等价关系、等价类、商集与划分的一一对应；会用模 n 同余关系分类；掌握偏序、哈斯图画法与特殊元素（最大/极大、上/下确界）的区分。

7.1 等价关系：把"相同"抽象出来

定义 7.1（等价关系）

A 上自反、对称、传递的关系称为等价关系，记作 ∼ 或 ≡。"∼"读作"等价于"，直观含义就是"视为同一类"。

例 7.1 三个身边的等价关系

  • 同一所大学毕业：自反 ✓、对称 ✓、传递 ✓（同校的校友的校友还是校友）。
  • 同余关系：整数集上 a ≡ b (mod n) ⇔ n | (a−b)。自反对称传递全部成立，这是代数中最重要的等价关系。
  • 矩阵相似：线性代数里"矩阵相似"是等价关系（自反 I·A·I⁻¹=A；对称由逆推；传递 A∼B∼C 则 A∼C）。"相似"这个词本身就暗示了等价关系。
  • 反例："是兄弟姐妹"——对称 ✓，但不传递（A 的兄弟是 B，B 的兄弟是 C，A 与 C 可能是同一个人或不是……实际上"有共同父母"才是传递的等价关系）。

定义 7.2（等价类与商集）

设 ∼ 是 A 上的等价关系，对 a∈A，等价类 [a] = { x | x ∼ a }。全部等价类构成的集合 { [a] | a∈A } 称为 A 关于 ∼ 的商集，记作 A/∼。

定理 7.1（等价类的三大性质）

  • 任意 a∈A，[a] ≠ ∅（a 自己就在里面——自反的功劳）。
  • 两个等价类要么相等、要么不交：[a]∩[b] ≠ ∅ ⇒ [a] = [b]（传递的功劳）。
  • 所有等价类的并 = A。

定理 7.2（核心定理：等价关系 ⇔ 划分）

A 上的等价关系与 A 的划分一一对应：给定等价关系，其等价类构成一个划分；给定划分，"同块则相关"定义一个等价关系。两个方向互逆。

例 7.2 模 3 同余：ℤ 切成三块

ℤ 关于 mod 3 的等价类：[0] = {…, −3, 0, 3, 6, …}，[1] = {…, −2, 1, 4, 7, …}，[2] = {…, −1, 2, 5, 8, …}。商集 ℤ/3 = {[0], [1], [2]}，恰好 3 块，互不相交、并起来是 ℤ。在商集上还能定义加法：[1] + [2] = [3] = [0]——"模运算"就是在等价类上做的运算。第 10 章的 ℤn 群、密码学里的模幂运算，全部建立在这个构造上。

商集的"压缩"视角：商集就是把"彼此等价"的点捏成一团后的新世界。数据库的 GROUP BY、面向对象里的 equals/hashCode 契约（相等对象必须同 hash 桶）都是商集思想的工程化身：equals 定义等价关系，hash 桶就是等价类。

7.2 偏序：能比大小，但不必全能比

定义 7.3（偏序关系）

A 上自反、反对称、传递的关系 ≤ 称为偏序关系，(A, ≤) 称为偏序集（poset）。若任意两元素都可比较，则称为全序。

对比记忆：等价关系把集合"分堆"，偏序把集合"排序"。自反+对称+传递 vs 自反+反对称+传递——只差"对称"变"反对称"，一个管分类一个管大小。

例 7.3 三个偏序、一个全序

  • (ℤ, ≤)：全序（任意两整数可比较大小）。
  • (P(A), ⊆)：偏序——{1} 与 {2} 谁也不包含谁，不可比。
  • (ℤ⁺, |)（整除）：偏序——2 与 3 互不整除。但注意和 ≤ 不同：这里 a|b 时 b 不一定"大"。整除与 ≤ 在部分数上重合、在整体上不同。

7.3 哈斯图：偏序的极简画像

1
去掉所有自环（自反性人人都有，画出来是废话）。
2
去掉由传递性派生的边（若 a<b<c，则 a 到 c 的边不画）。
3
剩下的"覆盖关系"（b 盖住 a ⇔ a<b 且中间无第三者）画成边，小的在下、大的在上，箭头一律省略（默认向上）。

例 7.4 画 ({1,2,3,6,12}, |) 的哈斯图

覆盖关系：1 盖住底（1 整除一切），2、3 盖住 1，6 盖住 2 和 3（4 不在集合里所以 6 直接管 2 与 3？——6 由 2×3 得到，2|6、3|6 且无中间元 ✓），12 盖住 6（也盖住 2？12 = 2×6？不对，中间有 6，不画；2|12 且 2<6<12，故 2 到 12 的边被 6 拦截）。结构：

        12
         |
         6
        / \
       2   3
        \ /
         1

这张菱形图信息量极大：能"爬"的路径就是整除关系；2 和 3 处在同一层但互不相连——不可比元素。

7.4 特殊元素：考试重灾区

定义 7.4（特殊元素）

概念定义唯一性
最大元与所有元素可比且 ≥ 之若存在则唯一
极大元没有比它更大的（别的都 ≤ 它或不可比）可以有多个
最小元 / 极小元对偶同理同上
上界子集 B 之上、A 中可比且 ≥ 每个成员的元素可有多个
上确界 sup上界中最小的那个若存在则唯一，且必属于 A（未必属于 B！）
最大 vs 极大：一字之差天壤之别
  • 最大元要求"碾压所有人"——必须和每个元素可比并且都赢。
  • 极大元只要求"没有人压过我"——不可比也算我没输。
在例 7.4 的哈斯图（整除）中：12 是最大元（1,2,3,6 全整除于 12）✓；把 12 拿掉，6 和……6 整除 12？12 没了，那 6 与谁？6 是极大元之一；若无 12，3 也是极大元？3|6 ✓ 所以 3 不是。换成 ({2,3,6}, |)：2 和 3 都是极大元，但最大元不存在——因为 2、3 不可比，谁也当不了"王"。再如 (P({a,b,c}), ⊆)：{a,b,c} 是最大元；{a} 所在链的顶……{a} 不是极大元（{a,b} 盖着它）。全体单元素集 {a},{b},{c} 是极小元吗？∅ 才是极小元兼最小元。

例 7.5 求子集 {2, 3} 在例 7.4 偏序集中的上界与上确界

上界：能被 2 和 3 同时"够到"的元素——6 和 12 都是上界。上确界 = 上界中最小的 = 6（2 和 3 的"最小公倍数"）。下界：整除 2 且整除 3 的元素——只有 1，故下确界 = 1（最大公约数）。
这不是巧合：在整除偏序里，上确界 = LCM，下确界 = GCD。GCD/LCM 这对初等数论的概念，在偏序语言里统一成了 sup/inf——这就是抽象的回报。

7.5 链、反链与哈斯图的"读法"

定义 7.5（链与反链）

子集中任意两元素都可比 → 链；都不可比 → 反链。链中元素个数称为链长。

定理 7.3（有限偏序集的分层定理）

含 n 个元素的偏序集中，最长链长度 + 最长反链长度……精确地说：若最长链长为 m，则全集可划分成 m 个反链（按"高度"分层）；对偶地（Dilworth 定理），最小反链划分数 = 最长链长。这一对结果在调度理论（最少机器数 = 最长任务链）中有直接应用。

7.6 自测题

  1. 在 ℤ 上定义 R = {<a,b> | a ≡ b (mod 4)}，写出 [1] 和商集 ℤ/4 的元素个数。
  2. 判断："同一部电影里的演员"（按出演关系分组）是否给出一个自然等价关系？
  3. 画 ({1,2,3,4,6,12}, |) 的哈斯图，指出全部极大元与最大元。
  4. 在 (P({a,b,c}), ⊆) 中求 { {a}, {b} } 的所有上界与上确界。
  5. "非空有限偏序集必有极大元"——给出证明思路（提示：顺着可比方向走，走不动了就是极大元）。
参考答案（先做再看）
  1. [1] = {…, −7, −3, 1, 5, 9, …}。ℤ/4 = {[0], [1], [2], [3]}，共 4 个元素。
  2. 不能。"出演过同一部电影"不传递（A、B 合演一部，B、C 合演另一部，A、C 可能毫无交集）。要构成等价关系需改为"通过任意链的合演关系连通"——连通分量（第 12 章的概念）才给出划分。
  3. 哈斯图：1 在底，2、3 盖住 1，4 盖住 2，6 盖住 2 和 3，12 盖住 4 和 6。极大元 = 最大元 = {12}（唯一）。
  4. 上界：包含 {a}∪{b} = {a,b} 的所有子集：{a,b}、{a,b,c}。上确界 = {a,b}（并集）。注意到确界运算与 ∪/∩ 的一致性。
  5. 任取一个元素 a₀；若非极大，取压过它的 a₁；继续 a₂, a₃, …。由有限性且序关系反对称（不会出现循环——出现循环会推出相等，矛盾），序列严格上升必在有限步内停止，停下的那个就是极大元。这也是"有限性 + 严格单调 ⇒ 有端点"的通用论证模式。
本章小结：等价关系（自反对称传递）↔ 划分，商集是"捏团后的新集合"，模 n 同余是标杆例子；偏序（自反反对称传递）用哈斯图极简呈现；最大/极大一字之差——"碾压全员" vs "无人压我"；整除偏序里 sup = LCM、inf = GCD。特殊关系玩够了，下一步把"单值、处处有定义"的关系拿出来专门研究——函数。
