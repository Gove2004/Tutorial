04 - 一阶谓词逻辑

本章目标：理解命题逻辑为什么不够用；掌握谓词、量词与辖域；会做变元换名与代替；熟记谓词等值式与四条量词推理规则（UI/UG/EI/EG），特别是 EI 的限制条件。

4.1 命题逻辑的天花板

经典的苏格拉底三段论：所有人都会死；苏格拉底是人；所以苏格拉底会死。在命题逻辑里只能写成 p, q ⇒ r——形式上完全无效（取 p=1, q=1, r=0 即反例）。问题出在：命题逻辑把"所有人都会死"当作不可拆的黑箱，看不见"所有人"与"苏格拉底是人"之间的共同结构 ××× 会死。

要拆开这个黑箱，需要两样新东西：谓词（描述性质与关系的模板）和量词（表达"所有/存在"）。

定义 4.1（个体词与谓词）

  • 个体词：可以独立存在的对象（如苏格拉底、数字 3）。用小写字母 a, b… 表示个体常项，x, y… 表示个体变项。
  • 谓词：刻画个体性质或关系的模板，记 F(x) 表示"x 具有性质 F"。"…会死"写成 D(x)；"… 比 … 大"是二元谓词 L(x, y)。

谓词本质上是"填空题"：D(苏格拉底) 填上空后就成了命题（真值为真）。而带变元的 D(x) 本身不是命题，真假不定——除非量词登场。

4.2 量词：∀ 与 ∃

定义 4.2（全称量词与存在量词）

  • 全称量词 ∀：∀xF(x) 读作"对所有 x，F(x) 都成立"。∀xF(x) 为真 ⇔ 论域中每一个个体都满足。
  • 存在量词 ∃：∃xF(x) 读作"存在 x 使 F(x) 成立"。为真 ⇔ 论域中至少有一个个体满足。
  • 论域（个体域）：变元的取值范围。符号化前必须明确论域——"人都会死"在全称论域下是 ∀x(P(x) → D(x))，在"论域 = 所有人"下可简写为 ∀xD(x)。
最高频易错：全称配蕴含，存在配合取
  • "所有人都会死" = ∀x(P(x) → D(x)) ✓。不能写成 ∀x(P(x) ∧ D(x))——那意味着"所有东西都是人且会死"，猫、石头全中招，显然错。
  • "有的人会游泳" = ∃x(P(x) ∧ W(x)) ✓。不能写成 ∃x(P(x) → W(x))——只要存在一个不是人的东西（此时前件假、蕴含式真），整个式子就恒真了，与"有人会游泳"毫无关系。
口诀：全称蕴含，存在合取。

例 4.1 符号化"没有最大的素数"（论域：自然数）

层层翻译："没有最大的素数" ⇔ "任给素数 x，都存在更大的素数" ⇔ ∀x( Prime(x) → ∃y( Prime(y) ∧ (y > x) ) )。量词嵌套（∀ 在前 ∃ 在后）表达"每个 x 各自有属于自己的 y"——顺序不能颠倒：∃y∀x 会变成"存在一个素数比所有素数都大"，意思完全反了。

4.3 否定、辖域与变元约束

量词否定等值式（量词的德摩根律）

¬∀xA(x) ⇔ ∃x¬A(x)
¬∃xA(x) ⇔ ∀x¬A(x)

"并非人人都及格" = "有人不及格"；"没有人及格" = "人人都没及格"。这是 SQL 里 NOT EXISTS 与 NOT IN 查询转换的理论依据。

定义 4.3（辖域、约束变元与自由变元）

量词后面紧跟的最短公式是该量词的辖域。辖域内与量词同名的变元是约束变元（被量词"管住了"），否则是自由变元。含自由变元的公式不是命题。

∀x(P(x) ∨ Q(x)) 里两个 x 都被约束；而 (∀xP(x)) ∨ Q(x) 中末尾的 x 是自由的（量词辖域只到第一个括号）。两条整理规则：

  • 换名规则：对约束变元改名（如 ∀xP(x) 改为 ∀yP(y)），要求改遍整个辖域且不与已有变元重名。
  • 代替规则：对自由变元代入新名（如 Q(x) 改为 Q(z)），要求该变元在公式中的所有自由出现都改，且新名不与约束变元冲突。

4.4 常用等值式与前束范式

量词辖域收缩与扩张（B 不含自由 x）

∀x(A(x) ∨ B) ⇔ ∀xA(x) ∨ B；　∀x(A(x) ∧ B) ⇔ ∀xA(x) ∧ B
∃x(A(x) ∨ B) ⇔ ∃xA(x) ∨ B；　∃x(A(x) ∧ B) ⇔ ∃xA(x) ∧ B

注意：∀x(A(x) ∨ B(x)) 与 ∀xA(x) ∨ ∀xB(x) 不等值！量词管不到变元之外的常量，但管不到另一个带变元的子公式。这是选择题的常客。

定义 4.4（前束范式）

全部量词都位于公式最前端（无否定号越过它们）且辖域覆盖到公式末尾的公式。任何谓词公式都能化为与之等值的前束范式，但前束范式不唯一。

例 4.2 求 ¬(∀xP(x) → ∃yQ(y)) 的前束范式

¬(∀xP(x) → ∃yQ(y))
⇔ ¬(¬∀xP(x) ∨ ∃yQ(y))　　（蕴含展开）
⇔ ∀xP(x) ∧ ¬∃yQ(y)　　（德摩根）
⇔ ∀xP(x) ∧ ∀y¬Q(y)　　（量词否定等值式）
⇔ ∀x∀y(P(x) ∧ ¬Q(y))　　（量词前移）

4.5 量词推理规则：UI、UG、EI、EG

四条量词规则（论域有限时最直观）

规则形式含义
UI（全称指定）∀xA(x) ⇒ A(c)对所有的都成立，当然对 c 成立
UG（全称推广）A(y) ⇒ ∀xA(x)y 须是"任取的"自由变元
EI（存在指定）∃xA(x) ⇒ A(c)c 必须是尚未出现过的"新"常项！
EG（存在推广）A(c) ⇒ ∃xA(x)有个具体的都行，当然"存在"
EI 的铁律（全书最著名的坑）
从 ∃xA(x) 指定出来的 c 只是"某一个不知道是谁的个体"，必须用新名字，且后续步骤不能把它当作"谁都可以"来使用。

反例：∃xP(x)（有人是男的）、∃xQ(x)（有人是女的）⇒ 想推 ∃x(P(x) ∧ Q(x))（存在既是男又是女的人）？
错误流程：EI 得 P(a)，再 EI 又得 Q(a)——第二次 EI 复用了同一个名字 a，等于偷偷假设"是男的那个人和是女的那个人是同一个人"，证出荒谬结论。

正确流程：两次 EI 必须用不同名字（a 和 b），此时 ∃x(P(x) ∧ Q(x)) 根本推不出来——事实上它也确实不成立。

例 4.3 苏格拉底三段论的完整证明

符号化（论域：全总个体域）：前提 ∀x(P(x) → D(x))，P(s)；结论 D(s)。

(1)  ∀x(P(x) → D(x))    P
(2)  P(s) → D(s)        T (1)，UI
(3)  P(s)               P
(4)  D(s)               T (2)(3)，MP

命题逻辑里 8 条等值式 + 9 条推理定律 + 4 条量词规则合起来，就是一阶谓词逻辑的完整证明系统。这个系统的表达能力足以形式化几乎全部数学证明。

4.6 自测题

  1. 符号化"每个自然数都有比它大的素数"（论域：自然数；谓词 P：是素数，> 用二元关系表达）。
  2. ∀x(P(x) ∨ Q(x)) 与 ∀xP(x) ∨ ∀xQ(x) 是否等值？给出反例或证明。
  3. 求 ¬∃x(∀yF(y) → G(x)) 的前束范式。
  4. 指出推理错在哪一步：∃xF(x), ∃xG(x) ⇒ ∃x(F(x) ∧ G(x))。
  5. "只有有人不迟到，会议才开得成"符号化（设 L(x)：x 迟到；S：会议开成；论域：与会者）。
参考答案（先做再看）
  1. ∀x∃y( P(y) ∧ (y > x) )。
  2. 不等值。取论域 {1, 2}，P 只对 1 成立、Q 只对 2 成立：左式 ∀x(P ∨ Q) = 1，右式 ∀xP ∨ ∀xQ = 0 ∨ 0 = 0。（左 ⇒ 右不成立；反向 ∀xP ⇒ ∀x(P∨Q) 是成立的。）
  3. ¬∃x(¬∀yF(y) ∨ G(x)) ⇔ ¬∃x(∃y¬F(y) ∨ G(x)) ⇔ ∀x(∀yF(y) ∧ ¬G(x)) ⇔ ∀x∀y(F(y) ∧ ¬G(x))。
  4. 两次 EI 指定用同一个体名（或第二次 EI 所用名字已在公式中出现），把"可能不同的两个存在者"偷换成了同一个。EI 的指定项必须是全新名字。
  5. "有人不迟到"是会议开成的必要条件：¬∃x¬L(x) → ¬S，即 ∃x¬L(x) → S？验证语义："只有 A 才 B" = B → A，故为 S → ∃x¬L(x)，等值于 ¬∃x¬L(x) → ¬S。
本章小结：谓词拆开命题黑箱，量词补上"所有/存在"；符号化口诀"全称蕴含、存在合取"；量词否定 = 换量词 + 否定辖域；前束范式把量词全部提到最前；EI 必须用全新个体常项。至此逻辑部分完结，接下来进入集合论——离散数学的地基。
