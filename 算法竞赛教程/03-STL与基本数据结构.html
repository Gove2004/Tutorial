第 3 章 STL 与基本数据结构

STL 让竞赛代码从 200 行缩到 80 行。但用错 STL 也会让你从 AC 掉到 RE：迭代器失效、比较函数写错、 vector::erase 在循环里用成 O(n2)，都是真正常见的翻车现场。 这一章按“什么时候用、怎么用、哪里会炸”的顺序讲。

学完本章，你应该能做到

  • 在需要动态数组、栈、队列、优先队列、有序集合、键值映射时，立刻选对容器；
  • 记住每个容器的核心操作复杂度，知道什么时候它会退化成线性；
  • 写出正确的 sort 比较函数（严格弱序，不含 <=）；
  • 用 next_permutation 枚举全排列，并知道它要求序列先有序。

3.2 vector：默认选择

数组有两种：静态和动态。竞赛里的惯例是空间够就用静态数组，简单、不会错； 空间紧张或者长度真的不确定时，用 vector 建动态数组。

vector 的内存是连续的，所以下标访问是 O(1)；但在中间插入/删除要搬移后面所有元素，是 O(n)。 另外，容量不足时会重新申请一块更大的内存并整体复制——这就是“扩容”的成本。 

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a;                       // 空
    vector<int> b(a);                    // 用 a 构造 b（拷贝）
    vector<int> c(100);                  // 100 个 0
    vector<int> d(100, 6);               // 100 个 6
    vector<string> e(10, "hello");       // 10 个 "hello"

    a.push_back(1);                      // 尾部添加，O(1) 均摊
    cout << a.size() << endl;           // 元素个数
    a.pop_back();                        // 删除尾部
    a.clear();                           // 清空（不释放容量）
    a.empty();                           // 是否为空

    // 二维数组：第一维固定，第二维动态，常用于邻接表
    const int MAXN = 100005;
    vector<int> g[MAXN];
    return 0;
}

3.2.1 一个真实用例：HDU 4841 圆桌问题

2n 个人围坐一桌，前 n 个是好人，后 n 个是坏人。从第 1 个人开始数，数到第 m 个人就赶走，然后从下一个人继续数。 要求输出座位安排，好人用 G，坏人用 B。这是约瑟夫环的变体，vector 的 erase 正好能模拟“赶走”。 

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    while (cin >> n >> m) {
        vector<int> table;
        for (int i = 0; i < 2 * n; i++) table.push_back(i);   // 0 表示第 1 个人

        int pos = 0;
        for (int i = 0; i < n; i++) {                          // 赶走 n 个人
            pos = (pos + m - 1) % table.size();                // 圆桌取余
            table.erase(table.begin() + pos);                  // 删除，后面元素前移
        }

        int j = 0;
        for (int i = 0; i < 2 * n; i++) {
            if (i % 50 == 0 && i) cout << endl;                // 每 50 个换行
            if (j < (int)table.size() && i == table[j]) {
                j++;
                cout << "G";
            } else {
                cout << "B";
            }
        }
        cout << endl << endl;
    }
    return 0;
}
这里藏着一个复杂度陷阱。erase 在中间删元素是 O(n)，外层又循环 n 次， 总复杂度 O(n2)。当 n 到 105 就会 TLE。 如果数据更大，要改用 list 或树状数组/线段树求第 k 个存活位置。

3.3 栈 stack：后进先出

栈的特点是“先进后出”。坐电梯时先进去的最后出来；一盒泡腾片，先放进去的在最底下，最后才拿到。 

#include <stack>

stack<int> s;
s.push(1);        // 压栈
s.top();          // 取栈顶，不删除
s.pop();          // 删除栈顶，不返回
s.size();         // 元素个数
s.empty();        // 是否为空

经典用例：HDU 1062 Text Reverse。输入 olleh !dlrow，输出 hello world!。 把每个单词的字符依次压栈，遇到空格或换行就全部弹出，天然实现“单词内逆序、单词间顺序不变”。 

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    cin >> T;
    cin.ignore();                       // 吃掉第一行末尾的换行
    while (T--) {
        string line;
        getline(cin, line);
        stack<char> st;
        for (size_t i = 0; i <= line.size(); i++) {
            if (i < line.size() && line[i] != ' ') {
                st.push(line[i]);
            } else {
                while (!st.empty()) { cout << st.top(); st.pop(); }
                if (i < line.size()) cout << ' ';
            }
        }
        cout << endl;
    }
    return 0;
}

3.4 队列 queue 与优先队列 priority_queue

#include <queue>

queue<int> q;      // 先进先出
q.push(1); q.front(); q.back(); q.pop(); q.size(); q.empty();

// 优先队列：默认大根堆，每次取最大值
priority_queue<int> pq;
pq.push(3); pq.top(); pq.pop();

// 小根堆：用 greater
priority_queue<int, vector<int>, greater<int>> pqmin;

// 自定义优先级（例如按距离最小）
struct Node { int d, id; };
struct cmp { bool operator()(const Node& a, const Node& b) const { return a.d > b.d; } };
priority_queue<Node, vector<Node>, cmp> pqnode;

优先队列底层是二叉堆，push/pop 都是 O(log n)。用它排序就是把所有数压进去再一个个取出来， 总复杂度 O(n log n)——和 sort 同阶，但常数更大，所以排序还是用 sort。

它在图论里才是主角：Dijkstra 需要每次取出当前距离最小的点，用 priority_queue 可以把“找最小”从 O(n) 降到 O(log n)，整个算法从 O(n2) 降到 O(m log n)。第 10 章会看到完整代码。

用例 HDU 1873 看病要排队：三个医生，每个病人有优先级，优先级高的先看，同优先级按先来后到。 这就是一个“优先队列 + 入队序号”的经典题：比较时先比优先级，再比入队时间。

3.5 链表 list

list 是双向链表，内存不连续，通过指针访问。它和 vector 的优缺点正好相反：

vectorlist
随机访问 a[i]O(1)不支持，只能迭代器移动
中间插入/删除（已定位）O(n)，要搬移元素O(1)，只改指针
内存占用紧凑每个节点额外存两个指针
缓存友好性好差，实际常数大

所以结论很实用：插入删除少、随机访问多 → vector；插入删除频繁、随机访问少 → list。 用例 HDU 1276 士兵队列训练：1 到 2 报数，报 2 的出列；再从队头 1 到 3 报数，报 3 的出列； 循环直到剩下不超过 3 人。list::erase 是 O(1)，正好合适。

3.6 set 与 map：有序的平衡树

两者底层都是红黑树，插入、删除、查找都是 O(log n)，并且自动保持有序。 set 只有键，map 是键值对。它们都会自动去重。 

#include <set>
#include <map>

set<int> s;
s.insert(3);                 // 插入，重复元素不会插入
s.erase(3);                  // 删除
s.count(3);                  // 存在返回 1，否则 0
s.find(3);                   // 返回迭代器，找不到返回 s.end()
*s.begin();                  // 最小值
*s.rbegin();                 // 最大值

// 找前驱/后继（C++ 迭代器不支持 +1，要用 lower_bound）
auto it = s.lower_bound(x);  // 第一个 >= x 的元素

map<string, int> mp;
mp["apple"] += 2;            // 不存在时默认构造 0
mp.count("apple");           // 是否出现过
for (auto& p : mp) cout << p.first << " " << p.second << endl;

用例：按店铺名字累加价格并排名。题面给若干条“价格 店铺名”，要求对每个时刻输出 memory 这家店的价格排名 （1 表示最贵）。直接用 map<string,int> 累加，再遍历比较即可。 

map<string, int> shop;
while (cin >> n) {
    string s;
    for (int i = 1; i <= n; i++) cin >> s;     // 店名，实际用不到
    cin >> m;
    while (m--) {
        int p; string name;
        cin >> p >> name;
        shop[name] += p;                        // 直接按键累加
    }
    int rank = 1;
    for (auto it = shop.begin(); it != shop.end(); it++)
        if (it->second > shop["memory"]) rank++;  // 数有几个比它贵
    cout << rank << endl;
    shop.clear();
}
三处常见错误： ① 用 mp[key] 查询不存在的键，会插入一个默认值，后续遍历就多了一条脏数据——查询请用 find 或 count； ② 一边遍历 map 一边 erase，迭代器会失效，正确写法是 it = mp.erase(it)； ③ unordered_map 在极端数据下会被卡成 O(n)，需要防哈希冲突（加随机偏移或换 map）。

3.7 sort：竞赛里用得最多的函数

两种形式： 

void sort(iterator first, iterator last);                  // 默认升序
void sort(iterator first, iterator last, Compare comp);    // 自定义比较

排序范围是 [first, last)——包含 first，不包含 last。返回值为空。复杂度 O(n log n)。 

#include <bits/stdc++.h>
using namespace std;

bool my_less(int i, int j)    { return i < j; }    // 自定义小于
bool my_greater(int i, int j) { return i > j; }    // 自定义大于

int main() {
    vector<int> a = {3, 7, 2, 5, 6, 8, 5, 4};
    sort(a.begin(), a.begin() + 4);                    // 只排前 4 个：2 3 5 7 6 8 5 4
    sort(a.begin(), a.end());                          // 升序：2 3 4 5 5 6 7 8
    sort(a.begin(), a.end(), greater<int>());          // 降序：8 7 6 5 5 4 3 2
    sort(a.begin(), a.end(), my_greater);              // 同上，用自定义函数
    for (int x : a) cout << x << " ";
    return 0;
}

3.7.1 给结构体排序

struct Student {
    char name[256];
    int score;
};

// 按分数从大到小；分数相同按名字升序（保证严格弱序）
bool cmp(const Student& a, const Student& b) {
    if (a.score != b.score) return a.score > b.score;
    return strcmp(a.name, b.name) < 0;
}

vector<Student> v;
sort(v.begin(), v.end(), cmp);
比较函数必须满足“严格弱序”。写成 return a.score <= b.score; 会在相等元素上返回 true， 导致 sort 内部判断混乱，轻则结果无序，重则段错误。记住：比较函数里永远用 < 或 >， 不要用 <= 或 >=。

3.7.2 三个衍生函数

stable_sort(v.begin(), v.end(), cmp);   // 稳定排序：相等元素保持原相对顺序
partial_sort(v.begin(), v.begin() + k, v.end());  // 只保证前 k 个有序，O(n log k)
nth_element(v.begin(), v.begin() + k, v.end());   // 第 k 小归位，左边都比它小，O(n) 均摊

partial_sort 的典型场景：10 个数里找最小的 5 个。用 sort 要全排一遍， 用 partial_sort 只需要排前 5 个。第 2 章那道“输出前 m 大”的题，它就是一个折中方案。

3.8 next_permutation：枚举全排列

它按字典序生成“下一个排列”，返回 false 表示已经是最后一个。3 个字符 a、b、c 会依次得到 abc, acb, bac, bca, cab, cba 共 6 个。 

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[] = {1, 2, 3};
    do {
        for (int i = 0; i < 3; i++) cout << a[i] << " ";
        cout << endl;
    } while (next_permutation(a, a + 3));
    return 0;
}
必须先升序排列。next_permutation 从当前排列往后找，如果初始序列不是字典序最小的， 前面的排列会被漏掉。做全排列前一律先 sort。 另外它的复杂度是 O(n!·n)，n 超过 10 就不要想枚举了。

自测清单

问题要点
vector::erase 在循环里用为什么不安全？每次 O(n) 搬移，且迭代器失效，容易越界
priority_queue 默认是大根堆还是小根堆？大根堆；小根堆要写 greater<int>
比较函数里写了 <= 会怎样？违反严格弱序，可能乱序或崩溃
map 用 [] 查询有什么副作用？不存在的键会被插入默认值
next_permutation 前为什么要先排序？否则漏掉更小的排列
