第二届 T3/T4：没有题面时怎么练

先说结论：这两题的原题没有公开版本

CACC 官方不整体公开赛题。第二届区域赛结束后，能在公开网络上找到的只有 T1、T2 的原题（17noi 题库收录）， 以及 T5 的标题级线索（「AI 算力中心调度」，未经核实）。T3、T4 连题面标题都没有稳定来源。

本教程不编题。这一章做两件事：把证据链讲清楚（让你知道「查不到」不是没查）， 再给两道同型训练题，把该练的能力练到。

结论：T3、T4 只能按 C 级（未公开，仅有赛制）处理。 任何声称「第二届 T3 是 XXX」的题面，如果没有样例和数据范围，都不可信——包括本教程。

为什么「编一道像的题」是有害的

编出来的题会给你错误的难度预期和错误的题型分布。你练了「树上差分」，结果真题考的是「计算几何 + 扫描线」， 时间就白花了。缺题时正确的做法是练能力，不押题。

从已公开的两题，反推 T3/T4 可能考什么

T1、T2 的定位很清晰：签到 + 基础 DP。按区域赛常见的梯度，T3、T4 大概率落在下面几类里：

位置常见题型对应能力
T3数据结构（线段树/树状数组/分块）+ 一个观察把「模板 + 限制」拆成可维护的信息
T3 备选树上问题（LCA、子树统计、启发式合并）把树上操作转成区间/合并
T4搜索 + 剪枝 / 折半搜索 / 状态压缩 DP在指数级空间里做有效裁剪
T4 备选贪心 + 证明 / 构造先猜后证，或用对拍反推

下面两道训练题就按这个分布设计。它们不是原题，是「同型训练」。

训练题 A：区间赋值 + 区间最大子段和

题目描述（训练题，非 CACC 原题）

C 级 · 本教程自编训练题 对应 T3 题型

给定长度为 n 的序列 a，支持两种操作：

  • 1 l r v：把区间 [l, r] 的所有元素赋值为 v；
  • 2 l r：查询区间 [l, r] 的最大子段和（子段不能为空）。

数据范围：1 ≤ n, m ≤ 105，−109 ≤ ai, v ≤ 109。

样例

输入：
5 3
1 -2 3 -1 2

2 1 5
1 2 4 5
2 1 5

输出：
4
18

第一次查询：子段 [3,5] 的和为 3 + (−1) + 2 = 4。赋值后序列为 1 5 5 5 2，整个区间和为 18，最大子段是 [1,5]，和为 18。

造样例也要用程序验算

这段样例的第一版把 1+5+5+5+2 手算成了 12。造题、写解析时手算错误非常常见， 任何写进题面的样例都应该先用一段暴力程序跑一遍。

线段树维护四个量

每个节点维护：

字段含义
sum区间和
pre必须包含左端点的最大子段和
suf必须包含右端点的最大子段和
best区间内最大子段和（不能为空）

合并公式

sum = L.sum + R.sum pre = max(L.pre, L.sum + R.pre) suf = max(R.suf, R.sum + L.suf) best = max(L.best, R.best, L.suf + R.pre)

区间赋值的懒标记处理是这题的关键：一整段都变成 v 后， sum = pre = suf = len × v，而 best = max(v, len × v)—— 当 v 为负数时，最优子段只取一个元素，不能取整段。 

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll NEG = LLONG_MIN / 4;

struct Node {
    ll sum, pre, suf, best;
};

Node mergeNode(const Node& L, const Node& R) {
    Node res;
    res.sum  = L.sum + R.sum;
    res.pre  = max(L.pre, L.sum + R.pre);
    res.suf  = max(R.suf, R.sum + L.suf);
    res.best = max({L.best, R.best, L.suf + R.pre});
    return res;
}

struct SegTree {
    int n;
    vector<Node> t;
    vector<ll> lazy;          // 是否有待下推的赋值
    vector<bool> has;

    SegTree(const vector<ll>& a) {
        n = (int)a.size() - 1;            // 1-indexed
        t.assign(4 * n + 4, {0, 0, 0, 0});
        lazy.assign(4 * n + 4, 0);
        has.assign(4 * n + 4, false);
        build(1, 1, n, a);
    }

    void apply(int p, int l, int r, ll v) {
        int len = r - l + 1;
        t[p].sum  = (ll)len * v;
        t[p].pre  = t[p].sum;
        t[p].suf  = t[p].sum;
        t[p].best = max(v, t[p].sum);     // v 为负时只取一个元素
        lazy[p] = v;
        has[p] = true;
    }

    void push(int p, int l, int r) {
        if (!has[p]) return;
        int mid = (l + r) >> 1;
        apply(p << 1, l, mid, lazy[p]);
        apply(p << 1 | 1, mid + 1, r, lazy[p]);
        has[p] = false;
    }

    void build(int p, int l, int r, const vector<ll>& a) {
        if (l == r) {
            t[p] = {a[l], a[l], a[l], a[l]};
            return;
        }
        int mid = (l + r) >> 1;
        build(p << 1, l, mid, a);
        build(p << 1 | 1, mid + 1, r, a);
        t[p] = mergeNode(t[p << 1], t[p << 1 | 1]);
    }

    void assignRange(int p, int l, int r, int ql, int qr, ll v) {
        if (ql <= l && r <= qr) { apply(p, l, r, v); return; }
        push(p, l, r);
        int mid = (l + r) >> 1;
        if (ql <= mid) assignRange(p << 1, l, mid, ql, qr, v);
        if (qr > mid)  assignRange(p << 1 | 1, mid + 1, r, ql, qr, v);
        t[p] = mergeNode(t[p << 1], t[p << 1 | 1]);
    }

    Node query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return t[p];
        push(p, l, r);
        int mid = (l + r) >> 1;
        if (qr <= mid) return query(p << 1, l, mid, ql, qr);
        if (ql > mid)  return query(p << 1 | 1, mid + 1, r, ql, qr);
        Node L = query(p << 1, l, mid, ql, qr);
        Node R = query(p << 1 | 1, mid + 1, r, ql, qr);
        return mergeNode(L, R);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<ll> a(n + 1);
    for (int i = 1; i <= n; ++i) cin >> a[i];

    SegTree seg(a);
    while (m--) {
        int op; cin >> op;
        if (op == 1) {
            int l, r; ll v;
            cin >> l >> r >> v;
            seg.assignRange(1, 1, n, l, r, v);
        } else {
            int l, r;
            cin >> l >> r;
            Node res = seg.query(1, 1, n, l, r);
            cout << res.best << '\n';
        }
    }
    return 0;
}

样例的正确输出是 4 和 18（第一行来自 3 + (−1) + 2， 第二行来自赋值后的 1 + 5 + 5 + 5 + 2）。

这题和 T3 的关系

共同的能力是「把一种不常规的区间操作，翻译成节点上可合并的几个量」。 第一题的「按奇偶坍缩」和这道题的「赋值后 pre/suf/best 同时等于 sum」，本质是同一类思考： 先问「一个整段被打上标记后，它的统计信息长什么样」。

训练题 B：折半搜索

题目描述（训练题，非 CACC 原题）

C 级 · 本教程自编训练题 对应 T4 题型

给定 n 个正整数和一个上限 S，从这 n 个数中选出一个子集， 使子集和不超过 S 且尽可能大。输出这个最大子集和。

数据范围：1 ≤ n ≤ 40，1 ≤ ai ≤ 109，1 ≤ S ≤ 1015。

样例

输入：
5 10
3 8 6 4 2

输出：
10

3 + 4 + 2 = 9，但 8 + 2 = 10 更优；也可以选 6 + 4 = 10。

为什么不能直接枚举

240 ≈ 1.1×1012，不可能枚举。但 220 ≈ 1.05×106，是可以的。 折半搜索（meet in the middle）就是把 n 个数分成两半，各自枚举所有子集和，再合并。

1

枚举左半

前 ⌈n/2⌉ 个数，220 种子集和，存进数组 L。

2

枚举右半并排序

后 ⌊n/2⌋ 个数，得到数组 R，排序。

3

合并

对每个 L 中的值 x，在 R 里二分找 ≤ S − x 的最大值，更新答案。复杂度 O(2n/2 log 2n/2)。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    ll S;
    cin >> n >> S;
    vector<ll> a(n);
    for (auto& x : a) cin >> x;

    int h = n / 2;                    // 前 h 个为左半
    vector<ll> L, R;

    for (int mask = 0; mask < (1 << h); ++mask) {
        ll s = 0;
        for (int i = 0; i < h; ++i)
            if (mask >> i & 1) s += a[i];
        if (s <= S) L.push_back(s);
    }

    int h2 = n - h;
    for (int mask = 0; mask < (1 << h2); ++mask) {
        ll s = 0;
        for (int i = 0; i < h2; ++i)
            if (mask >> i & 1) s += a[h + i];
        if (s <= S) R.push_back(s);
    }

    sort(R.begin(), R.end());

    ll ans = 0;
    for (ll x : L) {
        auto it = upper_bound(R.begin(), R.end(), S - x);
        if (it != R.begin()) {
            --it;
            ans = max(ans, x + *it);
        }
    }

    cout << ans << '\n';
    return 0;
}

常数优化

  • 枚举子集和时用「lowbit 递推」：sum[mask] = sum[mask ^ lowbit] + a[idx]，把内层 O(n) 降到 O(1)，总复杂度从 O(n2n/2) 降到 O(2n/2)。
  • 排序后去重（unique），减少二分范围。
  • 把较大的数放在右半，右半的子集和更分散，二分的剪枝效果更好（可选技巧）。
折半搜索适用信号

「n ≤ 40」「每个元素选或不选」「求满足某约束的最优子集」——这三个条件同时出现，先想折半搜索。 n ≤ 20 时直接状压枚举，n ≤ 40 时折半，n 更大时就要想 DP 或贪心。

没有原题时，怎么安排训练

  1. 按题型分布练，不按题号练：T1/T2 练速度，T3 练「模板 + 观察」，T4 练搜索剪枝，T5 练工程。
  2. 限时：T3 给 60 分钟，T4 给 50 分钟，超时就停，看解析。赛场上你不会有一整晚。
  3. 对拍：每道题都写暴力，随机 1000 组。这比多刷一道题有用。
  4. 记录失败原因：是没想到观察、写挂边界、还是读错题？三类问题解法完全不同。

本章小结

  • 第二届区域赛 T3、T4 的题面没有公开版本，本教程按 C 级处理，不编题。
  • 缺题时练能力：数据结构合并信息 + 搜索剪枝/折半搜索。
  • 区间赋值维护最大子段和的关键：负值时 best 只能取单元素。
  • 折半搜索把 240 压到 220，是 n ≤ 40 子集问题的标准解法。
