15 - 组合计数初步

本章目标：熟练运用加法/乘法原理与鸽笼原理；掌握排列组合的典型模型与"不重不漏"技巧；会用二项式定理；掌握递推关系的建立与求解（特征方程法）；初步了解生成函数。

15.1 两大原理：计数的地基

加法原理与乘法原理

  • 加法原理：任务按互斥类划分（或关系），各类方案数相加。
  • 乘法原理：任务按先后步骤划分（且关系），各步方案数相乘。

判断用哪个的关键词："或"分类（加）、"分步"（乘）。混用是最常见的翻车点。

鸽笼原理（抽屉原理）

n + 1 只鸽子进 n 个笼子，必有一个笼子 ≥ 2 只。加强版：N 只鸽子进 k 个笼，必有笼子 ≥ ⌈N/k⌉。

例 15.1 鸽笼原理的经典应用

  • "任取 13 人，必有两人同月生日"：13 人入 12 个月笼。
  • "任取 82 个正整数，必有两数差为 15 的倍数"：按 mod 15 分 15 类，82 > 5×15 = 75，必有某类 ≥ 6 个；同类的两数差是 15 的倍数。（其实 16 个就够——按 15 类，16 个必有同笼。）
  • "边长 1 的正三角形内任放 5 点，必有两点距离 ≤ 1/2"：连接各边中点分成 4 个小三角形，5 点入 4 笼，同一小三角内两点距离 ≤ 1/2。鸽笼原理的威力在于"构造笼子"——笼子设计得好，结论白送。

15.2 排列与组合：四个基本模型

定义 15.1（基本计数公式）

模型条件公式
排列 P(n,r)从 n 个不同元素取 r 个有序不放回P(n,r) = n(n−1)…(n−r+1)
组合 C(n,r)取 r 个无序不放回C(n,r) = n!/(r!(n−r)!)
全排列r = nn!
多重集排列含重复元素的全排n!/(n₁!·n₂!·…·nₖ!)
多重集组合n 类元素各取足够多，取 r 个C(n+r−1, r)（隔板法）
三大易错场景
  • 排列还是组合？看"交换两个选中者是否算不同方案"。"选 3 人开会"组合；"选 3 人当正副队长"排列（先选后排序 = C·r!）。
  • 相邻问题用捆绑，不相邻问题用插空："五人排队甲乙相邻" = 4!×2! = 48；"甲乙不相邻" = 5! − 48 = 72（总数减相邻，或 3!×A(4,2) 插空）。
  • 至少问题用补集："至少一个红球" = 总数 − 一个红球都没有。直接分类（恰 1、恰 2、…）容易漏，正难则反。

例 15.2 隔板法：10 个相同球放入 4 个不同盒子

每个盒子至少一个：把 10 个球排成一排，中间有 9 个空隙，选 3 个空隙插板：C(9,3) = 84。
允许空盒：补 4 个"虚拟球"（每盒先预置 1 个），问题变成 13 个球至少一盒一个：C(12,3) = 220。一般公式：n 个相同球 k 个盒子（允许空）= C(n+k−1, k−1)。
隔板法的识别信号："相同元素 + 不同归属"。

15.3 二项式定理与恒等式

定理 15.1（二项式定理）

(a + b)ⁿ = Σr=0n C(n, r) aⁿ⁻ʳ bʳ

组合解释：展开式的每一项从 n 个 (a+b) 因子中选 r 个贡献 b。推论：令 a = b = 1 得 ΣC(n,r) = 2ⁿ（子集总数！与第 5 章幂集呼应）；令 a = 1, b = −1 得奇偶项个数相等。

常用组合恒等式

C(n, r) = C(n, n−r)　（对称）
C(n, r) = C(n−1, r−1) + C(n−1, r)　（帕斯卡公式——杨辉三角的递推核）
Σk=rn C(k, r) = C(n+1, r+1)　（ Hockey stick / 朱世杰恒等式）

15.4 递推关系：从数列规律到封闭解

定义 15.2

aₙ 由前面项表示的关系 aₙ = f(aₙ₋₁, …, aₙ₋ₖ) 是递推关系；k 个初始值 a₀…aₖ₋₁ 合称初始条件。两者齐备才能唯一确定数列。

例 15.3 两个经典建模

  • 汉诺塔：n 层塔从 A 移到 C。递推：先把 n−1 层挪到 B（aₙ₋₁ 步），最大盘一步到 C，再 n−1 层压上来。aₙ = 2aₙ₋₁ + 1, a₁ = 1 → 叠加法解出 aₙ = 2ⁿ − 1。64 层 = 2⁶⁴ − 1 步 ≈ 1.8×10¹⁹——传说中僧侣搬完世界毁灭并不夸张。
  • 斐波那契：n 级台阶每次上 1 或 2 级，方案数 fₙ = fₙ₋₁ + fₙ₋₂（最后一步是 1 级还是 2 级，两类互斥），f₁ = 1, f₂ = 2。递推建模三问：最后一步是什么？分类互斥吗？初始条件齐吗？

定理 15.2（常系数线性齐次递推的解法）

对 aₙ = c₁aₙ₋₁ + c₂aₙ₋₂（c₂ ≠ 0），写特征方程 x² = c₁x + c₂：

  • 两不等实根 x₁ ≠ x₂：通解 aₙ = Ax₁ⁿ + Bx₂ⁿ，用初始条件解 A、B。
  • 重根 x：通解 aₙ = (A + Bn)xⁿ（多一个 n 因子！）。
  • 共轭复根：可化为三角形式（超越本教程范围）。

例 15.4 解 fₙ = fₙ₋₁ + fₙ₋₂，f₀ = 0, f₁ = 1

特征方程 x² = x + 1，根 x = (1 ± √5)/2。通解 fₙ = A((1+√5)/2)ⁿ + B((1−√5)/2)ⁿ。代入 f₀ = 0、f₁ = 1 解得 A = 1/√5, B = −1/√5：

fₙ = ( φⁿ − ψⁿ ) / √5，　φ = (1+√5)/2（黄金比），ψ = (1−√5)/2

整数数列由无理数表达——递推解法最惊艳的瞬间。斐波那契数还在第 14 章露过脸：它是欧几里得算法的最坏输入（连续斐波那契对让辗转相除步数最多）。

15.5 生成函数：把数列装进多项式

定义 15.3

数列 a₀, a₁, a₂, … 的（普通）生成函数是形式幂级数 G(x) = Σ aₙxⁿ。"生成函数是数列的衣服，脱下来还是数列"——我们不关心 x 的收敛，只把它当记录装置。

例 15.5 生成函数解"取硬币方案数"

1 元、2 元、5 元硬币各无限，凑 10 元的方案数。三类硬币的生成函数：(1 + x + x² + …) = 1/(1−x)，1/(1−x²)，1/(1−x⁵)。方案数 = 乘积 1/((1−x)(1−x²)(1−x⁵)) 中 x¹⁰ 的系数。展开（部分分式或逐项累加）：x¹⁰ 系数 = 10 种。生成函数把"组合计数"变成"代数运算"——级数乘法的每一步合并正是"方案分类汇总"的机械化。

进阶预告：Catalan 数（可折叠）

n 对括号的合法匹配数、n 个节点的二叉树形态数、出栈序列数……都是 Catalan 数 Cₙ = C(2n, n)/(n+1)：1, 1, 2, 5, 14, 42, …。递推 Cₙ = Σ CᵢCₙ₋₁₋i 的组合证明（"第一个回到地平线的位置"分割）是组合数学中最优美的论证之一，也是考研与算法面试的高频考点。

15.6 自测题

  1. 6 个人中必有两人属相相同吗？7 个人呢？
  2. 5 名男生 3 名女生排成一排，女生互不相邻的排法数？
  3. 把 12 本相同书籍分给 4 个班级，每班至少 2 本，几种分法？
  4. 求 aₙ = 5aₙ₋₁ − 6aₙ₋₂，a₀ = 1, a₁ = 0 的通项。
  5. (1 + x)⁶ 展开式中 x⁴ 的系数？并给出组合解释。
参考答案（先做再看）
  1. 6 人入 12 笼无保证；13 人才必有（12 类 + 1）。
  2. 先排男生 5! = 120，产生 6 个空隙（含两端），选 3 个插女生 A(6,3) = 120。共 120 × 120 = 14400。
  3. 每班先发 2 本（用掉 8 本），剩 4 本相同书分 4 班允许空：隔板 C(4+4−1, 4−1) = C(7,3) = 35。
  4. 特征方程 x² − 5x + 6 = 0 → x = 2, 3。aₙ = A·2ⁿ + B·3ⁿ。a₀: A+B = 1；a₁: 2A+3B = 0 → B = −2, A = 3。通项 aₙ = 3·2ⁿ − 2·3ⁿ。验：a₂ = 5×0 − 6×1 = −6；公式 3×4 − 2×9 = −6 ✓。
  5. C(6,4) = 15。组合解释：6 个 (1+x) 因子中选 4 个贡献 x。
本章小结（也是全书结语）：计数三板斧——分类加、分步乘、反面减；鸽笼原理靠"造笼子"；排列组合先问"有序吗、可重复吗"；相邻捆绑、插空、隔板各司其职；递推关系用特征方程封闭化；生成函数把计数变成代数。至此，数理逻辑给了你精确的语言，集合关系给了你结构的模型，代数结构给了你运算的规律，图论给了你网络的视野，组合计数给了你数数的章法——离散数学的五大武器全部到齐。算法、数据库、编译原理、密码学、人工智能，都会反复调用这套装备。
