T1 数位运算：200 位整数相加

题目描述

A 级 · 17noi #1719 原题 第二届区域赛 100 分（推定）

给定两个整数 x、y，求 x + y 的各位数字之和。

输入描述

一行两个整数 x、y，以空格分隔。

输出描述

一个整数，表示 x + y 的各位数字之和。

样例

输入：
58 65

输出：
6

58 + 65 = 123，1 + 2 + 3 = 6。

数据范围：30% 的数据 x, y ≤ 109；100% 的数据 x, y ≤ 10200。

先自己想一想（建议 5 分钟）
  • unsigned long long 最大约 1.8×1019，10200 需要多少位？
  • 如果只写 long long，能拿到多少分？

签到题，但有一半人会掉进去

30% 的数据 ≤ 109，用 long long 直接加、再循环取数位就能过。 剩下 70% 的数据到 10200，long long 会溢出，结果是错的而不是崩溃—— 这类错误最难发现，因为本地小样例全对。

溢出不是崩溃，是静默给错答案

C++ 的有符号整数溢出是未定义行为，实际常表现为回绕成一个看起来「正常」的数。你不会看到 Runtime Error， 只会看到 WA。所以只要题面出现「10100」这种范围，第一反应必须是字符串或高精度。

做法：模拟竖式加法，边加边求和

把两个数当成字符串，从最低位开始逐位相加，处理进位。因为题目只要「和的数位和」，不需要保存完整结果， 可以边加边累计。

核心循环

d = carry + x[i] + y[j] sum += d % 10; carry = d / 10

循环条件是 i ≥ 0 || j ≥ 0 || carry，最后一个 carry 不能漏。

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string x, y;
    cin >> x >> y;

    int i = (int)x.size() - 1;
    int j = (int)y.size() - 1;
    int carry = 0;
    long long sum = 0;

    while (i >= 0 || j >= 0 || carry) {
        int d = carry;
        if (i >= 0) d += x[i] - '0';
        if (j >= 0) d += y[j] - '0';

        sum += d % 10;
        carry = d / 10;

        --i;
        --j;
    }

    cout << sum << '\n';
    return 0;
}

复杂度 O(max(|x|, |y|))，最多 201 次循环。即使两个数都是 200 位、每一位都产生进位，sum 最大也只有 201 × 9 ≈ 1809，long long 完全够用。

第三行就是「循环条件里必须带 carry」的原因：两个数都加完了，进位还没处理完。

一个可用于自检的性质

设 s(n) 为 n 的数位和，则每发生一次进位，数位和就减少 9：

s(x + y) = s(x) + s(y) − 9 × (进位次数)

这个式子可以用来对拍：分别统计 s(x) + s(y) 与进位次数，与逐位累加的结果比较。 如果两者不等，说明进位处理有漏。

更直接的办法是用 Python 的任意精度整数做随机对拍：

import random

def digit_sum_add(a: str, b: str) -> int:
    i, j, carry, s = len(a) - 1, len(b) - 1, 0, 0
    while i >= 0 or j >= 0 or carry:
        d = carry
        if i >= 0: d += int(a[i]); i -= 1
        if j >= 0: d += int(b[j]); j -= 1
        s += d % 10
        carry = d // 10
    return s

for _ in range(2000):
    x = random.randint(0, 10 ** 200)
    y = random.randint(0, 10 ** 200)
    got = digit_sum_add(str(x), str(y))
    want = sum(int(c) for c in str(x + y))
    assert got == want, (x, y, got, want)
print("ok")

如果你用 Python 或 Java 参赛

Python 的 int 是天生的任意精度，一行就够： 

x, y = input().split()
print(sum(int(c) for c in str(int(x) + int(y))))

Java 用 BigInteger：new BigInteger(x).add(new BigInteger(y)).toString()，再逐位累加。 注意 BigInteger 的构造参数是字符串，不要先 Long.parseLong。

语言选择本身就是策略

区域赛允许 C/C++/Java/Python。纯大数题用 Python 三十秒写完，用 C++ 要写 20 行字符串处理。 但工程题、需要卡常的数据结构题，Python 大概率超时。赛前就要决定「哪类题用哪种语言」，不要在赛场上临时切。

易错点清单

  • 用 long long 存输入，30% 的数据能过，剩下 70% 全 WA。
  • 循环写成 while (i >= 0 && j >= 0)，两个数长度不同时高位丢失。
  • 循环条件漏了 carry，如 99 + 1 输出 0 而不是 1。
  • 把「和的数位和」写成「两个数的数位和相加」——注意后者只有在没有进位时才相等。
  • 读入用 int 或 double，200 位直接被截断。
  • 输出用了 int 之外的格式（比如补零），评测按整数比较会 WA。

延伸练习

1

改成求 x × y 的数位和

高精度乘法，O(n²) 的竖式乘法在 200 位下完全够用。注意进位可能累积到几千。

2

求 x − y 的数位和

需要处理借位，且结果可能为负。先判断大小，再用大减小。

3

数位和直到一位数

反复求数位和直到只剩一位（数字根）。试着用 n % 9 的性质直接给出 O(1) 答案，注意 0 和 9 的边界。

本章小结

  • 看到 10100 级别的范围，先想字符串/高精度，不要想「long long 应该够」。
  • 模拟竖式加法时，循环条件必须包含 carry。
  • 「只要数位和」可以边加边算，不必保存完整结果。
  • 进位让数位和减少 9，这是一个可用于自检的恒等式。
