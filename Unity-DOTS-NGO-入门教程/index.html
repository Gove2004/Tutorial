Unity DOTS 与 Netcode for GameObjects 入门教程

写给已经熟悉 MonoBehaviour 与面向对象、但从未动手写过 ECS 的 Unity 开发者：从思维转换讲起，一路写到可运行的实体系统与多人联机代码。

本教程的定位
  • 读者画像：你不是 Unity 新手，写过 MonoBehaviour、懂类与继承，但对 ECS 的认知停留在“听说很快”的层面。
  • 核心目标：完成从“对象 + 方法”到“数据 + 系统”的思维转换，并能独立写出可运行的 DOTS 代码与 NGO 联机代码。
  • 深度：系统掌握级。不只讲 API 怎么调，还讲为什么这样设计、什么时候不该用、生产环境怎么排查问题。
  • 视觉风格：技术蓝主题，C# 代码带语法高亮与一键复制。
版本基准（2026 年 11 月核对）
  • Unity 编辑器：Unity 6.4 及以上（示例按 6.7 文档核对）。从 Unity 6.4 起，Entities、Collections、Mathematics、Entities Graphics 转为随编辑器分发的核心包，包版本号跟随编辑器版本（如 Unity 6.6 对应 Entities 6.6.0），不再使用旧的 1.x 版本号。
  • Entities API：基于 6.x 的 ISystem、SystemAPI.Query、IJobEntity、Baker 工作流。旧的 Entities.ForEach、Aspects 已在 6.5 移除，教程不会出现这些过时写法。
  • Netcode for GameObjects：基于 3.x（3.0 于 2026 年 9 月发布，要求 Unity 6.7+）。运行时命名空间仍是 Unity.Netcode，RPC 采用统一的 [Rpc(SendTo.*)] 写法；2.x 的差异会在对应章节注明。

这份教程怎么学

全程建议开一个空项目边读边敲。前七章解决 DOTS，第八、九章解决 NGO 网络，第十章把两条线合起来讲边界与选型，第十一章讲迁移与性能分析。章节之间有明确递进，不要跳过第二、三章直接写 Job——大多数 DOTS 的困惑都来自没建立“数据布局”的直觉。

课程目录

基础

01　全景与思维转换：从 OOP 到 DOD

DOTS 到底解决什么问题；缓存未命中、GC、单线程瓶颈三大痛点；DOTS 组成；为什么 NGO 不等于 DOTS 网络。

基础

02　ECS 核心概念：Entity、Component、System 与 Chunk

实体为什么只是一个 ID；原型（Archetype）与内存块（Chunk）如何决定性能；World 与 EntityId；对照 MonoBehaviour 建立心智模型。

基础

03　作者工作流与 Baking：GameObject 如何变成实体

子场景、Authoring 组件、Baker、TransformUsageFlags；包安装与项目设置；完整跑通一个 Cube 示例。

基础

04　编写第一个 System：行为属于系统，不属于对象

ISystem 与 SystemState、SystemAPI.Query、RefRO/RefRW、查询过滤、时间；把一个 MonoBehaviour 重构为 ECS。

进阶

05　Job System 与 Burst：让数据跑满多核

C# Job System、IJob 与 IJobEntity、调度方式、Burst 编译原理与限制、Job 安全系统与典型报错。

进阶

06　数据组织与访问进阶

EntityQuery、ComponentLookup、DynamicBuffer、Tag、Enableable Component、BlobAsset、UnityObjectRef、实体预制体实例化。

进阶

07　结构变更与系统调度

EntityCommandBuffer 与 ECBSystem、并行写入、系统组与更新顺序、生成销毁实体的实战模式。

进阶

08　Netcode for GameObjects 入门：拓扑、权威与 NetworkManager

主机/服务器/客户端模型、权威服务器、NetworkManager、UnityTransport、NetworkObject、NetworkBehaviour 生命周期。

高级

09　网络变量与 RPC：状态同步与消息传递

NetworkVariable、NetworkList、统一 [Rpc] 写法、所有权、NetworkTransform、连接与场景管理。

高级

10　DOTS 与网络的边界：NGO、Netcode for Entities 与混合工作流

两套网络栈对比、NGO 3.x 与 Entities 的关系、GameObject 与实体互操作、Netcode for Entities 概念预览。

高级

11　迁移、调试与性能：从 OOP 项目渐进落地

Profiler 与 Burst 检查器、常见坑清单、渐进迁移策略、什么时候不该用 DOTS、综合练习与深入路径。
