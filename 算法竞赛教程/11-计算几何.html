第 11 章 计算几何

计算几何的代码量小、思维量中等，但对精度极其敏感。同一份代码，换一个 eps 就从 AC 变 WA。 这一章先把两个基础运算（点积、叉积）讲透，再谈凸包、圆、三维——因为几乎所有几何结论都由这两个运算推出来。 每一节都给出可以直接抄进模板文件的完整实现，不是伪代码。

学完本章，你应该能做到

  • 用点积判断夹角是锐角还是钝角，用叉积判断转向与面积；
  • 求点到直线距离、垂足、关于直线的对称点，判断两条线段是否相交；
  • 用 Andrew 算法求凸包，并知道它比 Graham 稳在哪里；
  • 用分治求最近点对、用旋转卡壳求凸包直径；
  • 用增量裁剪求半平面交，用随机增量法求最小圆覆盖；
  • 处理精度问题：eps 怎么选、sgn 怎么写、为什么不能直接用 ==。

11.1 二维几何基础

11.1.1 点与向量

点可以用 Point(x, y) 表示，向量用 Vector 表示，两者在代码里通常是同一个结构体。 需要支持的操作：加减、数乘、数除、比较相等、旋转、极角排序。 

const double eps = 1e-8;
const double PI = acos(-1.0);
int sgn(double x) {                       // 三态符号函数，处理精度
    if (fabs(x) < eps) return 0;
    return x < 0 ? -1 : 1;
}

struct Point {
    double x, y;
    Point() {}
    Point(double x, double y) : x(x), y(y) {}

    Point operator + (Point b) { return Point(x + b.x, y + b.y); }
    Point operator - (Point b) { return Point(x - b.x, y - b.y); }
    Point operator * (double k) { return Point(x * k, y * k); }
    Point operator / (double k) { return Point(x / k, y / k); }
    bool operator == (Point b) { return sgn(x - b.x) == 0 && sgn(y - b.y) == 0; }

    double len() { return sqrt(x * x + y * y); }
    Point rotate(double ang) {             // 绕原点逆时针转 ang 弧度
        double c = cos(ang), s = sin(ang);
        return Point(x * c - y * s, x * s + y * c);
    }
};
永远不要用 a.x == b.x 判等。浮点数经过加减乘除后会有误差， 必须用 sgn(a.x - b.x) == 0。eps 一般取 1e-8；如果坐标范围到 109， 要用相对误差或把 eps 放大到 1e-6 量级。

11.1.2 点积与叉积

点积（Dot product）

A · B = |A||B|cosθ = A.x·B.x + A.y·B.y

几何意义：A 在 B 上的投影长度乘以 B 的模长。

点积的正负直接反映夹角：dot > 0 是锐角，dot == 0 是直角，dot < 0 是钝角。 这个判断在“点是否在射线前方”“线段是否相交”里反复用到。 

double dot(Point A, Point B) { return A.x * B.x + A.y * B.y; }
double len(Point A) { return sqrt(dot(A, A)); }             // 模长
double angle(Point A, Point B) {                            // 夹角（0~π）
    return acos(dot(A, B) / len(A) / len(B));
}

叉积（Cross product）

A × B = |A||B|sinθ = A.x·B.y − A.y·B.x

几何意义：以 A、B 为邻边的平行四边形有向面积。正值表示 B 在 A 的逆时针方向。

double cross(Point A, Point B) { return A.x * B.y - A.y * B.x; }

// 判断三点转向：cross(B-A, C-A) > 0 表示 C 在 AB 左侧（逆时针）
int turn(Point A, Point B, Point C) {
    return sgn(cross(B - A, C - A));        // 1 左转，-1 右转，0 共线
}

叉积的三个常用结论：三角形面积 = |cross(B−A, C−A)| / 2； 多边形面积 = 相邻边叉积之和的一半（鞋带公式）；共线判断 = 叉积为 0。 

double polygon_area(Point* p, int n) {       // 鞋带公式，结果取绝对值
    double area = 0;
    for (int i = 0; i < n; i++)
        area += cross(p[i], p[(i + 1) % n]);
    return fabs(area) / 2;
}
为什么要用叉积算面积？因为它是有向面积：顶点逆时针排列时每一项为正， 这样“凹多边形”“顶点顺序混排”都能自动抵消，不需要判断凹凸。这也是后面求凸包、半平面交的基础。

11.1.3 点、直线、线段

// 点到直线 AB 的距离
double dist_line(Point P, Point A, Point B) {
    Point v1 = B - A, v2 = P - A;
    return fabs(cross(v1, v2)) / len(v1);
}

// 点到线段 AB 的距离：投影落在段内用垂距，否则取端点距离
double dist_seg(Point P, Point A, Point B) {
    if (sgn(dot(B - A, P - A)) <= 0) return len(P - A);
    if (sgn(dot(A - B, P - B)) <= 0) return len(P - B);
    return dist_line(P, A, B);
}

// 点在直线 AB 上的投影（垂足）
Point projection(Point P, Point A, Point B) {
    Point v = B - A;
    return A + v * (dot(v, P - A) / dot(v, v));
}

// 点关于直线 AB 的对称点
Point symmetry(Point P, Point A, Point B) {
    return projection(P, A, B) * 2 - P;
}

// 两条直线 AB 与 CD 的交点（保证不平行）
Point line_inter(Point A, Point B, Point C, Point D) {
    Point u = B - A, v = D - C;
    double t = cross(C - A, v) / cross(u, v);
    return A + u * t;
}

线段相交的判定是几何题里最常写错的一个，原因是共线重叠这一种情况容易被漏掉： 

// p 在直线 AB 上时，判断它是否落在线段 AB 内
bool on_seg(Point p, Point A, Point B) {
    return sgn(cross(A - p, B - p)) == 0 && sgn(dot(A - p, B - p)) <= 0;
}

// 线段 AB 与 CD 是否相交（含端点、含共线重叠）
bool seg_intersect(Point A, Point B, Point C, Point D) {
    int d1 = sgn(cross(B - A, C - A));
    int d2 = sgn(cross(B - A, D - A));
    int d3 = sgn(cross(D - C, A - C));
    int d4 = sgn(cross(D - C, B - C));
    if (d1 * d2 < 0 && d3 * d4 < 0) return true;      // 规范相交（跨立）
    if (d1 == 0 && on_seg(C, A, B)) return true;       // 端点共线且落在段内
    if (d2 == 0 && on_seg(D, A, B)) return true;
    if (d3 == 0 && on_seg(A, C, D)) return true;
    if (d4 == 0 && on_seg(B, C, D)) return true;
    return false;
}
跨立条件必须用乘积判断。d1 * d2 < 0 同时要求两侧的叉积一正一负， 写成 d1 > 0 || d2 > 0 会把“都在同侧”也判成相交。 另外共线的 4 个 if 不能省——那是“两条线段搭在同一条直线上”的情况。

11.1.4 多边形

  • 面积：鞋带公式，注意顶点顺序（顺时针为负）。
  • 点在多边形内：射线法——从该点向右作射线，统计与多边形边的交点个数，奇数在内、偶数在外； 要特殊处理“点正好在边上”和“射线经过顶点”的情况。
  • 凸多边形判定：所有相邻三点的转向一致。
  • 重心：把多边形拆成三角形，按有向面积加权求重心。
// 射线法判点在多边形内（p 为待判点，poly 任意顺序，n 个点）
bool in_polygon(Point p, Point* poly, int n) {
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        Point a = poly[i], b = poly[(i + 1) % n];
        if (sgn(dist_seg(p, a, b)) == 0) return true;        // 在边上
        if (sgn(a.y - b.y) == 0) continue;                    // 水平边跳过
        if ((a.y > p.y) != (b.y > p.y)) {                    // 这条边跨越水平线
            double x = a.x + (p.y - a.y) / (b.y - a.y) * (b.x - a.x);
            if (sgn(x - p.x) > 0) cnt++;                      // 交点在该点右侧
        }
    }
    return cnt & 1;
}

// 多边形重心（按有向面积加权）
Point polygon_center(Point* p, int n) {
    Point ans(0, 0);
    double area = 0;
    for (int i = 0; i < n; i++) {
        double s = cross(p[i], p[(i + 1) % n]);
        ans = ans + (p[i] + p[(i + 1) % n]) * s;
        area += s;
    }
    return ans / (area * 3);              // 面积 2 倍 → 除以 3 才是 1/3 加权
}

11.1.5 凸包

凸包是“能把所有点包住的最小凸多边形”，可以想象用一根橡皮筋把所有点箍住后形成的形状。 常用两种算法：Graham 扫描 O(n log n)、Jarvis 步进 O(nh)。原书推荐 Graham 的变种 Andrew 算法—— 它更快、更稳，代码也更好写。

1
排序去重。按 x 升序，x 相同按 y 升序；删掉重复点。
2
从左到右扫“下凸包”。新点在当前前进方向的左侧就加入； 在右侧说明拐弯了，弹出栈顶点，继续判断。
3
从右到左扫“上凸包”。同样逻辑，两段拼起来就是完整凸包。
bool cmp(Point a, Point b) {
    if (sgn(a.x - b.x) != 0) return a.x < b.x;
    return a.y < b.y;
}

// 返回凸包顶点数，hull 中按逆时针存放（首尾不重复）
int convex_hull(Point* p, int n, Point* hull) {
    sort(p, p + n, cmp);
    int k = 0;
    for (int i = 0; i < n; i++) {                       // 下凸包
        while (k >= 2 && sgn(cross(hull[k-1] - hull[k-2], p[i] - hull[k-2])) <= 0) k--;
        hull[k++] = p[i];
    }
    int t = k;
    for (int i = n - 2; i >= 0; i--) {                  // 上凸包
        while (k > t && sgn(cross(hull[k-1] - hull[k-2], p[i] - hull[k-2])) <= 0) k--;
        hull[k++] = p[i];
    }
    return k - 1;                                        // 最后一个点是起点，去掉
}
<= 0 还是 < 0？ 写 <= 0 会剔除共线点，凸包顶点最少、后续旋转卡壳最好写； 写 < 0 会保留共线的边界点，适合“凸包上的点数也要统计”的题。 两者都正确，先想清楚题目要哪一种。

凸包本身常作为“中间结果”：周长、面积可以直接算，最远点对（直径）用旋转卡壳， 最小宽度、凸包与直线交点、判断点是否在凸包内（二分或三角形剖分）都建立在它之上。 

double hull_perimeter(Point* h, int n) {
    double ans = 0;
    for (int i = 0; i < n; i++) ans += len(h[(i + 1) % n] - h[i]);
    return ans;
}

11.1.6 最近点对

n 个点中找距离最近的一对。暴力 O(n2)，分治可以做到 O(n log n)：按 x 排序后从中线分成两半， 分别求两半的最近距离 d，再检查中线两侧宽度为 d 的带状区域——带内每个点只需比较 y 差小于 d 的少数几个点。

实现的关键是递归返回时顺手把区间按 y 归并好，这样带宽内的点天然按 y 有序， 比较时一旦 y 差超过 d 就可以停下。如果不做这步归并、每次重新排序，复杂度会退化成 O(n log2 n)。 

Point p[MAXN], tmp[MAXN];

double closest(int l, int r) {              // 处理 [l, r)，p 已按 x 排序；返回后 p[l..r) 按 y 有序
    if (r - l <= 1) return 1e100;
    int m = (l + r) >> 1;
    double mx = p[m].x;                     // 中线的 x 坐标
    double d = min(closest(l, m), closest(m, r));

    int i = l, j = m, k = l;                 // 按 y 归并两半
    while (i < m && j < r) tmp[k++] = (p[i].y <= p[j].y) ? p[i++] : p[j++];
    while (i < m) tmp[k++] = p[i++];
    while (j < r) tmp[k++] = p[j++];
    for (k = l; k < r; k++) p[k] = tmp[k];

    Point cand[8];                          // 带宽内的候选点，最多比较 7 个
    int c = 0;
    for (k = l; k < r; k++) {
        if (fabs(p[k].x - mx) >= d) continue;        // 不在带宽内
        for (int t = c - 1; t >= 0 && p[k].y - cand[t].y < d; t--)
            d = min(d, len(p[k] - cand[t]));         // 与带内更低的点比较
        if (c < 8) cand[c++] = p[k];
    }
    return d;
}

// 调用：先按 x 排序，再 closest(0, n)；n == 1 时返回 INF，需要特判
double closest_pair(Point* pt, int n) {
    if (n < 2) return 0;
    sort(pt, pt + n, cmp);
    for (int i = 0; i < n; i++) p[i] = pt[i];
    return closest(0, n);
}
为什么带宽内只比较常数个点？把带宽区域按 d × 2d 切成格子， 每个格子里最多放 6 个点（否则这两点距离会小于 d，与当前最优解矛盾）， 所以每个点向后只需要看常数个邻居。这个“鸽巢”论证就是分治能降到 O(n log n) 的原因。

11.1.7 旋转卡壳

凸包上有两个“卡壳”指针：固定一条边，另一个指针沿凸包前进，使三角形面积最大。 因为凸包是凸的，随着一条边前进，最远点也单调前进，两个指针各自只转一圈，总复杂度 O(n)。 

// 凸包直径（最远点对距离），h 为逆时针凸包，n 个点
double hull_diameter(Point* h, int n) {
    if (n == 1) return 0;
    if (n == 2) return len(h[1] - h[0]);
    double ans = 0;
    int j = 1;
    for (int i = 0; i < n; i++) {
        // 固定边 i → i+1，让 j 前进到使三角形面积最大的位置
        while (sgn(fabs(cross(h[(i+1)%n] - h[i], h[(j+1)%n] - h[i]))
                 - fabs(cross(h[(i+1)%n] - h[i], h[j] - h[i]))) > 0)
            j = (j + 1) % n;
        ans = max(ans, len(h[j] - h[i]));
        ans = max(ans, len(h[(j+1)%n] - h[i]));        // 平形四边形时两个端点都要试
    }
    return ans;
}

同一套框架还能求最小宽度（凸包的最小宽度 = 最小面积矩形的宽，即某条边到其最远点的距离）， 以及两凸包的最远/最近距离。核心都是“单调指针”，不是新算法。

11.1.8 半平面交

每个半平面用一条有向直线表示（保留直线左侧）。所有半平面的交集是一个凸多边形。 标准做法是“按极角排序 + 双端队列”，复杂度 O(n log n)，代码偏长； 如果 n 只有几十到一两百，更稳的写法是增量裁剪：始终维护当前可行区域这个凸多边形，逐条边去切。

1
初始可行区域取一个足够大的矩形（必须比所有交点范围大）。
2
对每条半平面，遍历当前多边形的每条边：两端点都在左侧则整条保留； 一内一外则保留内侧端点并补上交点；两端都在右侧则整条丢弃。
3
切完所有边后剩下的多边形就是交集，面积为 0 表示无解。
struct Line { Point p, v; };               // 过点 p、方向 v，保留 v 的左侧

bool on_left(Line L, Point q) {            // q 在 L 左侧（含线上）
    return sgn(cross(L.v, q - L.p)) >= 0;
}

// 用半平面 L 裁剪凸多边形 poly[0..n)，结果写入 out，返回新顶点数
int clip_polygon(Point* poly, int n, Line L, Point* out) {
    int m = 0;
    for (int i = 0; i < n; i++) {
        Point a = poly[i], b = poly[(i + 1) % n];
        int sa = sgn(cross(L.v, a - L.p));   // >= 0 表示在内侧
        int sb = sgn(cross(L.v, b - L.p));
        if (sa >= 0) out[m++] = a;           // 起点在内侧，保留
        if (sa * sb < 0) {                   // 一内一外，补交点
            Point u = b - a;
            double t = cross(L.p - a, L.v) / cross(u, L.v);
            out[m++] = a + u * t;
        }
    }
    return m;
}

// 求 n 个半平面的交，返回交集多边形顶点数（poly 逆时针）
int half_plane_intersect(Line* L, int n, Point* poly) {
    const double BIG = 1e9;                 // 按题目坐标量级改，一般取真实范围的 2 倍
    int m = 0;
    poly[m++] = Point(-BIG, -BIG); poly[m++] = Point(BIG, -BIG);
    poly[m++] = Point(BIG, BIG);   poly[m++] = Point(-BIG, BIG);
    static Point tmp[MAXN];                 // 必须 static：MAXN=1e5 时 1.6MB，放栈上会爆（Windows 默认栈只有 1MB）
    for (int i = 0; i < n; i++) {
        m = clip_polygon(poly, m, L[i], tmp);
        for (int j = 0; j < m; j++) poly[j] = tmp[j];
        if (m == 0) return 0;               // 交集为空
    }
    return m;
}
初始框是关键。框太小会把真实解裁掉，框太大又会带来严重的精度误差。 经验做法是先读出所有直线的交点量级，把框设成它的 2 倍左右，而不是无脑 1e9。 如果 n 上万，就换成 O(n log n) 的排序 + 双端队列版本。
框太大为什么会让面积错？鞋带公式要算 x1*y2 − x2*y1，坐标到 109 时单次乘积就到 1018， double 只剩 15~16 位有效数字，几百次加减后小面积的误差能到几十。 用 1e9 的框、答案又是有界多边形时，尽量先用 2 倍真实范围的框；实在要留大框， 就把顶点先平移到第一个顶点再算面积（translate −p[0]）。

11.2 圆

11.2.1 基本计算

问题做法
点是否在圆内比较 len(P − O) 与 r，用 sgn 判等
直线与圆的位置关系圆心到直线距离 d 与 r 比较：> 相离，= 相切，< 相交
圆与圆的交点先判位置关系，再用余弦定理求弦心距与半弦长
两圆公切线分外公切线与内公切线，用相似三角形求切点
圆与多边形面积交按边拆成三角形/扇形，用有向面积累加
 
struct Circle { Point c; double r; };

// 线段 AB 与圆心在原点的圆求交，返回交点个数，结果写入 p
int seg_circle(Point A, Point B, double r, Point* p) {
    Point v = B - A;
    double a = dot(v, v), b = 2 * dot(A, v), c = dot(A, A) - r * r;
    double delta = b * b - 4 * a * c;
    if (sgn(delta) < 0) return 0;
    double t1 = (-b - sqrt(max(0.0, delta))) / (2 * a);
    double t2 = (-b + sqrt(max(0.0, delta))) / (2 * a);
    int m = 0;
    if (sgn(t1) >= 0 && sgn(t1 - 1) <= 0) p[m++] = A + v * t1;   // 只保留落在段内的解
    if (sgn(t2) >= 0 && sgn(t2 - 1) <= 0 && sgn(t2 - t1) > 0) p[m++] = A + v * t2;
    return m;
}

// 两圆交点，返回个数（0 相离/内含，1 相切，2 相交）
int circle_inter(Circle A, Circle B, Point* p) {
    double d = len(B.c - A.c);
    if (sgn(d - A.r - B.r) > 0 || sgn(fabs(A.r - B.r) - d) > 0) return 0;
    double a = (A.r * A.r - B.r * B.r + d * d) / (2 * d);   // 圆心连线上的投影长度
    double h = sqrt(max(0.0, A.r * A.r - a * a));           // 半弦长
    Point u = (B.c - A.c) / d;
    Point base = A.c + u * a;
    Point v(-u.y, u.x);                                     // u 的垂直方向
    if (sgn(h) == 0) { p[0] = base; return 1; }
    p[0] = base + v * h;
    p[1] = base - v * h;
    return 2;
}

圆与多边形面积交的做法是逐边贡献：把每条边按“与圆的交点”切成若干段， 段内（中点在圆内）算三角形面积、段外（中点在圆外）算扇形面积，两者都带符号， 整个多边形累加后取绝对值。符号不能省——否则弦接近直径时会把弧取反。 

// 有向扇形面积：a、b 可以是圆上的交点，也可以只是两条方向射线上的点
// 必须用 atan2 的有向角（返回 -π~π），不能用 acos（只给 0~π，会丢掉方向）
double sector_area(Point a, Point b, double r) {
    return r * r * atan2(cross(a, b), dot(a, b)) / 2;
}

// 三角形 OAB 与圆盘（圆心在原点、半径 r）的相交面积
double tri_circle_area(Point a, Point b, double r) {
    Point ip[2];
    int cnt = seg_circle(a, b, r, ip);
    Point pt[4];                             // 按 A → 交点 → B 的顺序把这条边切开
    int m = 0;
    pt[m++] = a;
    for (int i = 0; i < cnt; i++) pt[m++] = ip[i];
    pt[m++] = b;
    double sum = 0;
    for (int i = 0; i + 1 < m; i++) {
        Point u = pt[i], v = pt[i + 1];
        if (sgn(len(u - v)) == 0) continue;                  // 交点与端点重合，跳过退化段
        Point mid = (u + v) / 2;
        if (sgn(len(mid) - r) <= 0) sum += cross(u, v) / 2;      // 整段在圆内：三角形
        else                        sum += sector_area(u, v, r); // 整段在圆外：扇形
    }
    return fabs(sum);
}
两个坑，都是实测查出来的。 ① 扇形角必须用 atan2 而不是 acos：acos 只返回 0~π， a、b 顺序反了、或者弦几乎穿过圆心时，会取到另一侧的弧，结果直接偏到“半圆量级”。 ② 三角形面积不能套 fabs：一旦两边都取绝对值，累加就不再是鞋带公式那种有向求和， 凹多边形和“圆只在多边形外”的情况都会算错。
为什么切开而不是分三种情况讨论？旧的写法要分别处理“0 个交点 / 1 个交点 / 2 个交点”， 每支都要判断“a 在圆内还是圆外”，分支多、容易漏。切成小段之后只剩两种情况， 而且中点判定天然避开了“端点在圆上”的边界。

11.2.2 最小圆覆盖

给 n 个点，求半径最小的圆把所有点包住。结论：这个圆一定由其中 2 个点（直径为两点连线）或 3 个点（三角形外接圆）确定。

随机增量法是这个问题的标准解法：把点随机打乱，逐个加入；若当前点不在圆内， 则以它为圆上一点重新定圆，再做两层内层循环修正。期望复杂度 O(n)。 

Circle circumcircle(Point a, Point b, Point c) {        // 三点定圆（外接圆）
    double bx = b.x - a.x, by = b.y - a.y;
    double cx = c.x - a.x, cy = c.y - a.y;
    double d = 2 * (bx * cy - by * cx);                 // 叉积的两倍
    if (sgn(d) == 0)                                    // 三点共线：退化成以最远两点为直径
        return Circle{(a + c) / 2, len(c - a) / 2};
    double b2 = bx * bx + by * by;
    double c2 = cx * cx + cy * cy;
    // 圆心满足 |P-a| == |P-b| 且 |P-a| == |P-c|，解这个线性方程组
    Point center(a.x + (cy * b2 - by * c2) / d,
                 a.y + (bx * c2 - cx * b2) / d);
    return Circle{center, len(center - a)};
}

Circle min_circle(Point* p, int n) {
    shuffle(p, p + n, mt19937(chrono::steady_clock::now().time_since_epoch().count()));
    Circle c = {p[0], 0};
    for (int i = 1; i < n; i++) {
        if (sgn(len(p[i] - c.c) - c.r) > 0) {           // p[i] 在圆外，重定圆
            c = {p[i], 0};
            for (int j = 0; j < i; j++)
                if (sgn(len(p[j] - c.c) - c.r) > 0) {   // 两点定圆
                    c.c = (p[i] + p[j]) / 2;
                    c.r = len(p[i] - c.c);
                    for (int k = 0; k < j; k++)
                        if (sgn(len(p[k] - c.c) - c.r) > 0)
                            c = circumcircle(p[i], p[j], p[k]);   // 三点定圆
                }
        }
    }
    return c;
}
随机化不是可选项。如果不打乱点，最坏情况会退化成 O(n3)。 std::random_shuffle 在 C++17 已被移除，必须用 shuffle(p, p + n, mt19937(...))，否则在某些编译器上直接编译失败。

最小圆覆盖还有模拟退火解法：从一个点开始，每次向外“迁移”圆心并逐步缩小步长。 它的正确性不保证，但实现简单、可以处理带权或带约束的变种。

11.3 三维几何

三维部分的核心仍是两个运算： 

struct Point3 {
    double x, y, z;
    Point3 operator + (Point3 b) { return {x + b.x, y + b.y, z + b.z}; }
    Point3 operator - (Point3 b) { return {x - b.x, y - b.y, z - b.z}; }
    Point3 operator * (double k) { return {x * k, y * k, z * k}; }
};

double dot3(Point3 a, Point3 b) { return a.x*b.x + a.y*b.y + a.z*b.z; }
Point3 cross3(Point3 a, Point3 b) {          // 结果是向量，模长 = 平行四边形面积
    return {a.y*b.z - a.z*b.y, a.z*b.x - a.x*b.z, a.x*b.y - a.y*b.x};
}
double len3(Point3 a) { return sqrt(dot3(a, a)); }

struct Plane { Point3 n, p; };                 // 法向量 n + 平面上一点 p
// 点到平面距离（带符号：在法向量一侧为正）
double dist_plane(Point3 q, Plane pl) {
    return dot3(pl.n, q - pl.p) / len3(pl.n);
}
// 三点定平面
Plane plane_of(Point3 a, Point3 b, Point3 c) {
    return {cross3(b - a, c - a), a};
}
// 判断四点共面：混合积为 0
bool coplanar(Point3 a, Point3 b, Point3 c, Point3 d) {
    return sgn(dot3(cross3(b - a, c - a), d - a)) == 0;
}

最小球覆盖是最小圆覆盖的三维版本，同样是随机增量：加入点 pi 若在球外， 则以它为球上一点；再看 pj 是否在球外，两点定球；再看 pk 是否在球外，三点定圆； 最后一个 pl 决定四点定球（求四面体外接球，用三个面法向量联立解方程）。期望 O(n)。

三维凸包用增量法：先取 4 个不共面的点组成一个四面体， 每加入一个点，删掉它能“看到”的所有面（用有向体积判断），再用这个点与被删面的边界缝合成新面。 复杂度 O(n2)，n 到 104 就危险。

这两个模板的代码量都在 200 行以上，而且对精度极其敏感。 比赛里的正确做法是提前维护一份自己验证过的模板文件，而不是现场推导。 真正需要你设计的是“用哪种几何对象建模、怎么判退化”，不是把公式再抄一遍。

11.4 精度：几何题 90% 的 WA 来自这里

场景eps 取值说明
坐标 ≤ 104，普通判等1e-8最常用，误差约 1e-11 量级
坐标 ≤ 109，求距离/面积1e-6 ~ 1e-7坐标本身精度就低，eps 必须跟着放大
判断共线/共面1e-9 相对误差叉积的绝对值要乘坐标量级再比
二分/迭代求交点1e-10迭代 60 次比固定 eps 更可靠
  • 不要用 == 比较浮点，一律 sgn(a - b) == 0。
  • 输出用 %.2f 而不是 %lf：%lf 在 printf 里是未定义行为，很多判题机会直接判 WA。
  • 注意 -0.00：printf("%.2f", -0.001) 会输出 -0.00，部分题会判错，必要时加 eps 再取绝对。
  • 叉积写反是另一个高频错误：cross(A, B) 与 cross(B, A) 差一个负号，判定左/右会整体反过来。

11.5 几何模板的组织方式

几何题的代码几乎全是“函数拼装”。建议按下面顺序组织，每个函数只做一件事：

1
基础层：sgn、Point、dot、cross、len、angle。
2
关系层：点在线上、线段相交、点在线段上、直线与圆关系、圆与圆关系。
3
计算层：距离、垂足、对称点、交点、面积、重心。
4
算法层：凸包、最近点对、旋转卡壳、半平面交、最小圆覆盖。
调试几何题的经验：把关键中间量（交点坐标、距离、叉积符号）打印出来， 用简单数据（正三角形、正方形、共线三点、相切圆）先验证每个函数。 几何题的错误几乎都是“某个函数在边界情况下返回了错值”——先测边界，再测一般情况。

自测清单

问题要点
点积为正说明夹角是什么？锐角（0 为直角，负为钝角）
叉积为负说明什么？B 在 A 的顺时针方向，或三点右转
线段相交为什么要单独判共线？共线重叠时叉积全为 0，“跨立”条件不成立
为什么凸包要“排序 + 两次扫描”？保证上下凸包都按 x 单调推进，避免 Graham 的角度排序误差
最近点对为什么必须按 y 归并？不归并就要每层重排，退化成 O(n log2 n)
旋转卡壳为什么是 O(n)？两个指针各自单调前进，总共各转一圈
最小圆覆盖为什么必须随机打乱？否则最坏 O(n3)
eps 怎么选？坐标 104 内用 1e-8，109 量级要放大或改相对误差

练习题

  1. 实现 Point 与 dot/cross，用正三角形、正方形验证面积公式。
  2. 求点到线段的最短距离，用 5 组数据覆盖“投影在段内/外”两种情况。
  3. 写 seg_intersect，用“共线不重叠”“共线重叠”“端点相接”“规范相交”四组数据测试。
  4. Andrew 凸包：输入 10 个随机点，输出凸包顶点，手画验证；再把 <= 0 改成 < 0 观察共线点是否保留。
  5. 最近点对：与 O(n2) 暴力对拍 1000 组随机数据，确认没有精度/边界错误。
  6. 用旋转卡壳求凸包直径，与“枚举所有点对”的暴力版本对拍。
  7. 最小圆覆盖：用随机点测试，与暴力三点定圆的结果比较半径。
  8. 最小圆覆盖的退化情形：所有点共线、只有 1 个点、所有点重合，逐一验证。
  9. 半平面交：用三角形三条边求交集，验证面积；再试“无解”的情况（两条平行且方向相反）。
