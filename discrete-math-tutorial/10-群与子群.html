10 - 群与子群

本章目标：掌握半群 → 独异点 → 群的升级路线；会用群的性质做证明；掌握子群判定、循环群与生成元；理解陪集与拉格朗日定理；了解模运算在密码学中的应用。

10.1 三级火箭：半群 → 独异点 → 群

定义 10.1（升级路线）

结构要求典型例子欠缺什么
半群封闭 + 结合<ℤ⁺, +>、字符串拼接无幺元、无逆元
独异点（含幺半群）半群 + 幺元<ℕ, +>、<ℤ, ×>缺逆元
群独异点 + 人人可逆<ℤ, +>、<ℤₙ, ⊕ₙ>——（满级）

交换群（阿贝尔群）再附加交换律。半群也有用武之地：MapReduce 里的归并操作就是半群运算，链式归并的合法性与结合律直接相关。

群的三连问（判断题套路）：① 结合律成立吗？（最费劲的一步）② 幺元是谁？③ 每个元素的逆元存在吗？最常踩的坑：<ℤ, ×> 不是群——幺元 1 有，但 5 的逆元 1/5 ∉ ℤ。<ℤ, −>更惨，连结合律都没有。而 <ℤₙ, ⊕ₙ> 是群：结合 ✓（模加继承）、幺元 0 ✓、x 的逆元 (n−x) mod n ✓。

10.2 群的基本性质：五条"速算规则"

定理 10.1

  • 消去律：a*b = a*c ⇒ b = c（两边左乘 a⁻¹）。
  • 方程唯一解：a*x = b 有唯一解 x = a⁻¹*b。
  • (ab)⁻¹ = b⁻¹a⁻¹（穿鞋脱袜）。
  • 指数律：aᵐ·aⁿ = aᵐ⁺ⁿ，(aᵐ)ⁿ = aᵐⁿ。
  • 运算表中每行每列都是重排（拉丁方）——有限群验证的实用判据。

例 10.1 用消去律做证明

证明：群中若 a² = e 且 a ≠ e，则 a 的阶为 2，且它与所有元素交换？——不，这里证更基础的：设 a*b = a*c，则左乘 a⁻¹：a⁻¹*(a*b) = a⁻¹*(a*c)，结合律整理得 (a⁻¹*a)*b = (a⁻¹*a)*c，即 e*b = e*c，故 b = c。∎ 每一步都是定义驱动——群证明的文风就是如此，没有任何直觉跳跃。

10.3 子群：群中之群

定义 10.2（子群）

群 <G, *> 的非空子集 H 若对 * 封闭、含幺元（或至少含 e）且对逆封闭，则 <H, *> 是 G 的子群，记 H ≤ G。平凡的子群：{e} 与 G 本身。

定理 10.2（子群判定定理）

H 非空且 ∀a,b∈H，a*b⁻¹ ∈ H ⇒ H ≤ G（一步判定法）。等价的实用版本：H 非空有限时，只需封闭性即可（有限半群 + 消去律自动补齐幺元与逆元）。

例 10.2 <ℤ, +> 的全部子群

对每个 n ≥ 0，nℤ = {…, −n, 0, n, 2n, …} 是子群（封闭 ✓，含 0 ✓，取逆即取负 ✓），且判定定理验证：ma − nb ∈ nℤ ✓。反过来，ℤ 的任何子群都形如 nℤ——整除结构完美控制了加法子群。这个现象在 <ℤ₆, ⊕₆> 里更直观：子群只有 {0}、{0,3}、{0,2,4}、ℤ₆ 四个，阶数 1, 2, 3, 6——全部是 6 的因子。这不是巧合，是拉格朗日定理。

10.4 循环群与生成元

定义 10.3（循环群）

若 G = { a⁰, a¹, a², … }（每个元素都是某个 a 的幂），则 G 是循环群，a 是生成元。a 的阶 = 使 aⁿ = e 的最小正 n（不存在则称阶为 ∞）。

定理 10.3（循环群的分类）

  • 无限循环群 ≅ <ℤ, +>，恰有两个生成元（1 和 −1）。
  • n 阶循环群 ≅ <ℤₙ, ⊕ₙ>，生成元恰有 φ(n) 个（欧拉函数：与 n 互质的数目）。ℤ₆ 的生成元是 1 和 5（φ(6) = 2）；ℤ₇ 的生成元有 6 个。
  • 循环群的子群仍是循环群，且 n 阶循环群对 n 的每个因子 d 恰有一个 d 阶子群。

例 10.3 找 ℤ₁₀ 的全部生成元

与 10 互质的数：1, 3, 7, 9，共 φ(10) = 4 个。验证 3：3, 6, 9, 2, 5, 8, 1, 4, 7, 0——十步遍历全群 ✓。而 2 只能生成 {0, 2, 4, 6, 8}（2 阶？不，5 阶子群），4 只能生成 {0,4,8,2,6}（同一个 5 阶子群）。生成元 = "步长与 n 无公因子"的数，跳步会漏点。

10.5 陪集与拉格朗日定理

定义 10.4（陪集）

子群 H ≤ G，对 a∈G，左陪集 aH = { a*h | h∈H }。aH 把 H "平移"到 a 的位置。

定理 10.4（陪集三性质）

  • a ∈ aH（幺元在 H 里）。
  • aH = bH ⇔ a⁻¹b ∈ H（"同陪集"是等价关系）。
  • 任意两个陪集要么相等要么不交，且 |aH| = |H|（aH 与 H 之间有双射 h ↦ a*h）。

定理 10.5（拉格朗日定理）

有限群 G 的阶 = |H| × 陪集个数（指数 [G:H]）。推论：子群的阶整除群的阶。

一条定理直接回答了三件事：① 例 10.2 中 ℤ₆ 子群阶为何全是因子；② 阶为素数 p 的群只有 {e} 和自身两个子群，且必为循环群；③ 为什么不存在 6 阶群有 4 阶子群这种事（4 ∤ 6）。

例 10.4 手算 ℤ₆ 对 H = {0, 3} 的陪集分解

0+H = {0, 3}；1+H = {1, 4}；2+H = {2, 5}；3+H = {3, 0}（与 0+H 重合）。全部陪集：{0,3}, {1,4}, {2,5}——3 个陪集，每个 2 个元素，2 × 3 = 6 ✓。加法"沿陪集整体进行"：{0,3} + {1,4} = {1, 4}——陪集自己构成一个系统（商群 ℤ₆/H ≅ ℤ₃，第 9 章商代数思想的落地）。

10.6 为什么群论统治了密码学

RSA 的底座是 <ℤn*, ×>（模 n 乘法可逆元群，n 为两素数之积，阶 = φ(n) = (p−1)(q−1)）。欧拉定理 aφ(n) ≡ 1 (mod n) 是循环群指数循环性的直接推论：在阶为 φ(n) 的群里，任何元素自乘 φ(n) 次必回到幺元。加密者把"算 aᵉ mod n"设计成易事，而破译者要面对的"从 aᵉ 反解 a"是离散对数问题——群论里的单向门。Diffie-Hellman 密钥交换、椭圆曲线密码，全是"找一个运算好算、逆运算极难的群"。屈婉玲教材第 10 章的每一行定义，都在为这些系统写出生证明。

10.7 自测题

  1. 判断 <ℤ, ×>、<ℤ, +>、<奇数集, ×> 哪些是独异点、哪些是群。
  2. 证明：群中若 (ab)² = a²b² 且 a²b² 对一切 a,b 成立，则群是交换群。
  3. 求 ℤ₁₂ 的全部生成元（共几个？）。
  4. 证明 4 阶群中每个非幺元的阶为 2 或 4。
  5. ℤ₇ 的子群有哪些？各多少阶？
参考答案（先做再看）
  1. <ℤ, ×>：结合 ✓ 幺元 1 ✓ 逆元大多缺失 ⇒ 独异点非群。<ℤ, +>：群（也是交换群）。<奇数, ×>：封闭 ✓ 结合 ✓ 幺元 1 ✓ 逆元缺失 ⇒ 独异点非群。
  2. (ab)² = a²b² ⇔ abab = aabb。左乘 a⁻¹、右乘 b⁻¹：ba = ab。∎
  3. 与 12 互质的数：1, 5, 7, 11，共 φ(12) = 4 个。
  4. 任取 a ≠ e。a 的阶 d 整除 |G| = 4（拉格朗日推论：a 生成的循环子群 <a> 的阶整除 4），且 d > 1，故 d ∈ {2, 4}。∎
  5. 7 是素数 ⇒ ℤ₇ 是 7 阶循环群，7 的因子只有 1 和 7 ⇒ 子群只有 {0} 和 ℤ₇。
本章小结：半群(结合) → 独异点(+幺) → 群(+逆)；子群判定 a*b⁻¹ ∈ H；循环群由生成元撑起，ℤₙ 的生成元 φ(n) 个；拉格朗日：子群阶整除群阶，陪集分解是它的肉体。群的运算只有一个——下一章给它配上"加减乘除"四则，升级为环与域，再走向逻辑运算的代数化身：布尔代数。
