第六章：物理引擎——碰撞检测与刚体动力学

学习目标：深入理解碰撞检测算法（AABB、OBB、SAT、GJK、EPA），掌握刚体动力学、数值积分器和约束求解器。物理引擎是让游戏世界「真实」的核心模块——从简单的弹球到复杂的角色移动，都离不开它。

为什么需要物理引擎？

物理引擎解决两个核心问题：碰撞检测（两个物体是否相交）和碰撞响应（相交后如何运动）。很多初学者混淆这两者，但它们是独立的子系统。

输入：物体位置、速度、形状、质量

↓ 碰撞结果 ↓

↓ 输出 ↓
更新后的位置、速度、碰撞事件回调

碰撞检测：从简单到复杂

碰撞检测算法按精度递增分为几个层次。每一层都有各自的性能特征和适用范围。

AABB（Axis-Aligned Bounding Box）

AABB 是最简单的碰撞体——各轴对齐的包围盒。因为不与旋转对齐，检测速度极快。

// AABB 碰撞检测：O(1) 时间复杂度，只需 6 次比较
bool AABB::collidesWith(const AABB& other) const {
    // 三个轴分别检测，任何一轴分离则不相交
    if (max.x < other.min.x || min.x > other.max.x) return false;
    if (max.y < other.min.y || min.y > other.max.y) return false;
    if (max.z < other.min.z || min.z > other.max.z) return false;
    return true;
}

// 计算穿透深度（用于位置修正）
float AABB::penetrationDepth(const AABB& other) const {
    // 分别计算每个轴的穿透量，取最小值
    float overlapX = std::min(max.x - other.min.x, other.max.x - min.x);
    float overlapY = std::min(max.y - other.min.y, other.max.y - min.y);
    float overlapZ = std::min(max.z - other.min.z, other.max.z - min.z);
    return std::min({overlapX, overlapY, overlapZ});
}

定义：Broad Phase 与 Narrow Phase

Broad Phase（粗检测）：快速排除不可能相交的物体对，通常使用空间分区（网格、BVH、Octree）或 Sweep and Prune 算法。复杂度接近 O(n log n) 而非 O(n²)。

Narrow Phase（精检测）：对 Broad Phase 筛选出的候选对执行精确碰撞检测，返回接触点、法线和穿透深度。复杂度取决于形状类型。

OBB（Oriented Bounding Box）

OBB 是带旋转的包围盒。检测 AABB 的简单比较不再适用，需要使用 SAT（分离轴定理）在 OBB 的局部坐标系中进行。

// OBB 数据结构
struct OBB {
    Vec3 center;       // 中心点
    Vec3 halfExtents;  // 半长
    Mat3 orientation;  // 旋转矩阵（3 列 = 局部轴）
};

// OBB-OBB 碰撞检测（使用 SAT）
// 最多需要测试 15 条分离轴
bool OBBCollide(const OBB& a, const OBB& b) {
    const Mat3& Ra = a.orientation;
    const Mat3& Rb = b.orientation;

    // 15 条分离轴：A 的 3 个轴 + B 的 3 个轴 + 9 个叉积轴
    Vec3 axes[15];
    int axisCount = 0;

    // A 的局部轴
    for (int i = 0; i < 3; ++i) axes[axisCount++] = Ra.getColumn(i);
    // B 的局部轴
    for (int i = 0; i < 3; ++i) axes[axisCount++] = Rb.getColumn(i);
    // 轴叉积
    for (int i = 0; i < 3; ++i) {
        for (int j = 0; j < 3; ++j) {
            axes[axisCount++] = cross(Ra.getColumn(i), Rb.getColumn(j));
        }
    }

    // 对所有分离轴测试投影
    for (int i = 0; i < axisCount; ++i) {
        float projA = projectOBB(a, axes[i]);
        float projB = projectOBB(b, axes[i]);
        if (projA + projB < 0.0f) return false;  // 找到分离轴
    }
    return true;  // 所有轴都重叠 → 相交
}

Sphere（球体）

球体的碰撞检测最简单——只需比较圆心距离与半径之和。

bool sphereCollides(const Sphere& a, const Sphere& b) {
    float radiusSum = a.radius + b.radius;
    float distSq = squaredDistance(a.center, b.center);
    return distSq <= radiusSum * radiusSum;  // 用平方距离避免 sqrt
}

// 球体 - AABB 碰撞
bool sphereAABBCollide(const Sphere& s, const AABB& aabb) {
    // 找到球心到 AABB 最近的点
    Vec3 closest = clamp(s.center, aabb.min, aabb.max);
    float distSq = squaredDistance(s.center, closest);
    return distSq <= s.radius * s.radius;
}

Capsule（胶囊体）

胶囊体是球体沿直线扫过的轨迹。广泛用于角色碰撞（头部球形 + 身体圆柱形），比 AABB 更贴合人体。

struct Capsule {
    Vec3 p1;          // 线段起点
    Vec3 p2;          // 线段终点
    float radius;     // 半径
};

// 胶囊体 vs 球体
bool capsuleSphereCollide(const Capsule& cap, const Sphere& sph) {
    // 找到球心到胶囊线段的最短距离
    Vec3 seg = cap.p2 - cap.p1;
    float t = dot(sph.center - cap.p1, seg) / lengthSquared(seg);
    t = clamp(t, 0.0f, 1.0f);  // 限制在线段范围内
    Vec3 closest = cap.p1 + seg * t;
    float distSq = squaredDistance(sph.center, closest);
    return distSq <= (cap.radius + sph.radius) * (cap.radius + sph.radius);
}

SAT：凸多边形的精确碰撞检测

分离轴定理（Separating Axis Theorem）是凸多边形碰撞检测的黄金标准。它的核心思想很简单：

如果存在一条直线，使得两个凸多边形的投影在该直线上不重叠，则这两个多边形不相交。
// SAT 实现：凸多边形碰撞检测
bool SATCollide(const ConvexPolygon& a, const ConvexPolygon& b) {
    // 候选分离轴：每个面的法线
    std::vector<Vec2> axes;
    for (const auto& edge : a.edges) axes.push_back(perpendicular(edge));
    for (const auto& edge : b.edges) axes.push_back(perpendicular(edge));

    // 对每条轴测试投影
    for (const auto& axis : axes) {
        float minA, maxA, minB, maxB;
        projectPolygon(a, axis, minA, maxA);
        projectPolygon(b, axis, minB, maxB);

        // 如果投影不重叠 → 找到分离轴 → 不相交
        if (maxA < minB || maxB < minA) {
            return false;
        }
    }
    return true;  // 所有轴上都重叠 → 相交
}

// 将多边形投影到轴上，返回 [min, max]
void projectPolygon(const ConvexPolygon& poly, const Vec2& axis,
                    float& minOut, float& maxOut) {
    minOut = dot(poly.vertices[0], axis);
    maxOut = minOut;
    for (size_t i = 1; i < poly.vertices.size(); ++i) {
        float proj = dot(poly.vertices[i], axis);
        minOut = std::min(minOut, proj);
        maxOut = std::max(maxOut, proj);
    }
}
SAT 的局限：SAT 只适用于凸多边形。对于凹多边形，需要先分解为凸多边形（如使用三角剖分或凸分解算法），否则会得到错误的碰撞结果。

GJK：任意凸形状的碰撞检测

Gilbert-Johnson-Keerthi (GJK) 算法是工业级物理引擎的核心。它不依赖于具体的形状表示，而是通过Minkowski 差来判断两个凸形状是否相交。

Minkowski 差

给定两个凸集 A 和 B，它们的 Minkowski 差定义为：A ⊖ B = {a - b | a ∈ A, b ∈ B}。关键性质：A 和 B 相交当且仅当 Minkowski 差包含原点。

// GJK 算法：判断两个凸形状是否相交
// 核心：Support 函数 —— 在给定方向上返回 Minkowski 差的最远点
bool GJKCollide(const ConvexShape& a, const ConvexShape& b) {
    // Simplex 初始化为一个点
    std::vector<Vec3> simplex;
    Vec3 direction = a.getSupportDirection(Vec3(1, 0, 0));  // 初始搜索方向

    simplex.push_back(a.support(direction) - b.support(-direction));
    direction = -simplex.back();  // 指向原点的方向

    // 迭代：每次添加一个新的 Support 点
    for (int iter = 0; iter < 100; ++iter) {
        Vec3 supportPoint = a.support(direction) - b.support(-direction);

        // 如果 Support 点没有跨越原点 → 不相交
        if (dot(supportPoint, direction) <= 0) {
            return false;
        }

        simplex.push_back(supportPoint);

        // 简化器：判断 Simplex 是否包含原点
        if (ProcessSimplex(simplex, direction)) {
            return true;  // 包含原点 → 相交
        }
    }
    return false;
}

// Support 函数：在给定方向上找到形状的最远点
Vec3 ConvexShape::support(const Vec3& direction) const {
    Vec3 furthest = vertices[0];
    float maxDot = dot(vertices[0], direction);
    for (size_t i = 1; i < vertices.size(); ++i) {
        float d = dot(vertices[i], direction);
        if (d > maxDot) {
            maxDot = d;
            furthest = vertices[i];
        }
    }
    return furthest;
}

GJK 的性能

GJK 算法每次迭代的复杂度是 O(V)，V 是顶点的数量。在 2D 中通常 3-5 次迭代即可收敛，3D 中通常需要 5-15 次迭代。相比 SAT 的 O(n*m)（n 和 m 分别为两个多边形的顶点数），GJK 在处理复杂形状时优势明显。

算法 适用形状 单次检测耗时 实现难度 返回信息
AABB 测试轴对齐矩形< 5ns极低是否相交
球体测试球体< 10ns极低是否相交
SAT凸多边形50-200ns中等是否相交 + 分离轴
GJK任意凸形状100-500ns高是否相交

EPA：穿透深度的精确计算

GJK 只能判断是否相交，但不能给出穿透深度和碰撞法线。EPA（Expanding Polytope Algorithm，膨胀多面体算法）在 GJK 的最后 Simplex 基础上继续扩展，直到精确找到穿透面。

// EPA：从 GJK 的 Simplex 开始，扩展找到最小穿透面
EPAResult EPA(const std::vector<Vec3>& simplex,
              const ConvexShape& a, const ConvexShape& b) {
    // 复制 GJK 最终 Simplex 作为 EPA 初始多面体
    std::vector<Face> polytope = BuildPolytope(simplex);

    Vec3 direction = FindClosestFaceDirection(polytope);

    for (int iter = 0; iter < 50; ++iter) {
        // 在方向上扩展 Support
        Vec3 supportA = a.support(direction);
        Vec3 supportB = b.support(-direction);
        Vec3 supportPoint = supportA - supportB;

        // 找到离 supportPoint 最近的面对
        Face& closestFace = FindClosestFace(polytope, supportPoint);

        // 如果新 Support 点没有超越当前面 → 收敛
        float currentDist = dot(closestFace.normal, supportPoint);
        if (currentDist < dot(closestFace.normal, closestFace.points[0]) + epsilon) {
            return EPAResult{
                .depth = currentDist,
                .normal = closestFace.normal,
                .point = supportPoint
            };
        }

        // 用新 Support 点细分最近的面（Loop Subdivision）
        RefineFace(polytope, closestFace, supportPoint);
    }
    return EPAResult{};  // 未收敛，返回近似结果
}

刚体动力学

碰撞检测告诉我们物体何时相交，而刚体动力学告诉我们相交后物体如何运动。一个刚体由位置、速度、质量和转动惯量描述。

RigidBody 类设计

class RigidBody {
public:
    Vec3 position;       // 质心位置
    Quat rotation;       // 四元数旋转
    Vec3 linearVelocity; // 线速度
    Vec3 angularVelocity;// 角速度

    float mass;          // 质量（0 = 静态物体）
    Vec3 inverseMass;    // 1/mass（静态物体为 0）

    Mat3 inertiaTensor;  // 惯性张量（局部坐标系）
    Mat3 inverseInertia; // 逆惯性张量
    Mat3 worldInertia;   // 世界坐标系惯性张量

    // 应用外力（重力、推力等）
    void applyForce(const Vec3& force, const Vec3& point = Vec3(0)) {
        // 力直接影响线加速度
        linearAcceleration += force * inverseMass;

        // 力矩 = r × F，影响角加速度
        if (point != Vec3(0)) {
            Vec3 torque = cross(point - position, force);
            angularAcceleration += inverseInertia * torque;
        }
    }

    // 更新世界坐标系惯性张量
    void updateWorldInertia() {
        Mat3 rotMatrix = rotation.toMatrix();
        worldInertia = rotMatrix * inertiaTensor * rotMatrix.transpose();
        inverseWorldInertia = worldInertia.invert();
    }

private:
    Vec3 linearAcceleration = Vec3(0);
    Vec3 angularAcceleration = Vec3(0);
};

惯性张量详解

惯性张量描述了物体绕各轴旋转的阻力，是一个 3×3 矩阵。对于均匀长方体（尺寸 2a × 2b × 2c，质量 m）：

// 均匀长方体的惯性张量（对角阵）
Mat3 computeBoxInertia(float mass, float hw, float hh, float hd) {
    float ix = mass * (hh*hh + hd*hd) / 12.0f;
    float iy = mass * (hw*hw + hd*hd) / 12.0f;
    float iz = mass * (hw*hw + hh*hh) / 12.0f;
    return Mat3(ix, 0, 0,
                0, iy, 0,
                0,  0, iz);
}

// 均匀球体的惯性张量
Mat3 computeSphereInertia(float mass, float radius) {
    float I = 2.0f * mass * radius * radius / 5.0f;
    return Mat3(I, 0, 0,
                0, I, 0,
                0, 0, I);
}

数值积分器

积分器负责将力和力矩转换为新的位置和速度。不同的积分器在精度、稳定性和性能之间有不同的权衡。

欧拉积分（Euler）

// 前向欧拉：最简单，但能量不守恒（会发散）
void eulerIntegrate(RigidBody& body, float dt) {
    // 位置更新
    body.position += body.linearVelocity * dt;
    // 旋转更新（用四元数）
    body.rotation *= Quat(body.angularVelocity * dt * 0.5f);
    body.rotation.normalize();
    // 速度更新
    body.linearVelocity += body.linearAcceleration * dt;
    body.angularVelocity += body.angularAcceleration * dt;

    // 清除累积的力
    body.linearAcceleration = Vec3(0);
    body.angularAcceleration = Vec3(0);
}

Verlet 积分

// Verlet 积分：用当前位置和前一个位置计算新位置
// 优点：能量守恒性好，隐式阻尼
void verletIntegrate(RigidBody& body, float dt) {
    Vec3 currentPosition = body.position;
    Vec3 velocity = (currentPosition - body.prevPosition) / dt;

    body.position += velocity * dt + 0.5f * body.linearAcceleration * dt * dt;
    body.prevPosition = currentPosition;
    body.linearAcceleration = Vec3(0);
}

Runge-Kutta 4（RK4）

// RK4：四阶精度，物理模拟中最准确的常规模积分器
void rk4Integrate(RigidBody& body, float dt) {
    // k1 = f(t, y)
    State k1 = evaluate(body, 0.0f);

    // k2 = f(t + dt/2, y + k1*dt/2)
    State state2 = body;
    state2.linearVelocity += k1.linearAcceleration * dt * 0.5f;
    state2.angularVelocity += k1.angularAcceleration * dt * 0.5f;
    State k2 = evaluate(state2, dt * 0.5f);

    // k3 = f(t + dt/2, y + k2*dt/2)
    State state3 = body;
    state3.linearVelocity += k2.linearAcceleration * dt * 0.5f;
    state3.angularVelocity += k2.angularAcceleration * dt * 0.5f;
    State k3 = evaluate(state3, dt * 0.5f);

    // k4 = f(t + dt, y + k3*dt)
    State state4 = body;
    state4.linearVelocity += k3.linearAcceleration * dt;
    state4.angularVelocity += k3.angularAcceleration * dt;
    State k4 = evaluate(state4, dt);

    // 加权平均
    body.linearVelocity += (k1.linearAcceleration + 2*k2.linearAcceleration
                           + 2*k3.linearAcceleration + k4.linearAcceleration) * dt / 6.0f;
    body.angularVelocity += (k1.angularAcceleration + 2*k2.angularAcceleration
                            + 2*k3.angularAcceleration + k4.angularAcceleration) * dt / 6.0f;
    body.position += (k1.linearVelocity + 2*k2.linearVelocity
                    + 2*k3.linearVelocity + k4.linearVelocity) * dt / 6.0f;
}

工程实践：大多数游戏引擎（PhysX、Bullet）默认使用半隐式欧拉（Symplectic Euler）——先更新速度，再用新速度更新位置。它在精度和性能之间取得了最佳平衡，且能量不会像前向欧拉那样无限增长。

约束求解

约束限制了物体的自由度。铰链约束让两个物体绕轴旋转，距离约束保持固定长度，接触约束防止穿透。约束求解有两种主流方法。

基于冲量的求解（Impulse-Based）

// 碰撞冲量求解：经典的 Baumgarte 稳定化方法
void solveCollisionConstraint(RigidBody& a, RigidBody& b,
                              const CollisionContact& contact) {
    // 相对速度
    Vec3 ra = contact.point - a.position;
    Vec3 rb = contact.point - b.position;
    Vec3 rv = (b.linearVelocity + cross(b.angularVelocity, rb))
            - (a.linearVelocity + cross(a.angularVelocity, ra));

    // 沿法线方向的相对速度
    float velAlongNormal = dot(rv, contact.normal);
    if (velAlongNormal > 0) return;  // 正在分离，不需要求解

    // 恢复系数（弹性）
    float e = std::min(a.restitution, b.restitution);

    // 法线方向的冲量标量
    float j = -(1 + e) * velAlongNormal;
    j /= (a.inverseMass.x + b.inverseMass.x
         + dot(cross(ra, contact.normal) * a.inverseWorldInertia, cross(ra, contact.normal))
         + dot(cross(rb, contact.normal) * b.inverseWorldInertia, cross(rb, contact.normal)));

    // 应用冲量
    Vec3 impulse = contact.normal * j;
    a.linearVelocity -= impulse * a.inverseMass;
    a.angularVelocity -= cross(ra, impulse) * a.inverseWorldInertia;
    b.linearVelocity += impulse * b.inverseMass;
    b.angularVelocity += cross(rb, impulse) * b.inverseWorldInertia;

    // Baumgarte 稳定化：位置修正（防止穿透累积）
    float penetration = contact.depth;
    const float slop = 0.01f;  // 允许少量穿透
    const float correctionPercent = 0.2f;  // 每帧修正 20%
    float correction = std::max(penetration - slop, 0.0f) * correctionPercent;
    Vec3 correctionImpulse = contact.normal * correction / (a.inverseMass.x + b.inverseMass.x);
    a.position -= correctionImpulse * a.inverseMass.x;
    b.position += correctionImpulse * b.inverseMass.x;
}

基于位置的求解（Position-Based Dynamics）

// PBD：直接修正位置而非计算冲量
// 优点：数值稳定性好，适合软体和大穿透
void solvePBDConstraint(RigidBody& a, RigidBody& b,
                        const PBDConstraint& constraint) {
    Vec3 delta = b.position - a.position;
    float dist = length(delta);
    float difference = (dist - constraint.restLength) / dist;

    float totalInvMass = a.inverseMass.length() + b.inverseMass.length();
    if (totalInvMass == 0) return;  // 两个都是静态物体

    Vec3 correctionA = a.inverseMass * difference / totalInvMass;
    Vec3 correctionB = b.inverseMass * difference / totalInvMass;

    a.position += correctionA;
    b.position -= correctionB;
}
为什么需要 Baumgarte 稳定化？：纯冲量求解只修正速度，不修正位置。如果物体已经穿透，下一帧仍然会穿透，导致「抖动」。Baumgarte 稳定化在每个时间步额外施加一个位置修正，将穿透误差按比例减小，但过大的修正系数会导致物体弹飞。

注意：这些数字是 narrow phase 的单次检测时间。实际引擎中，Broad Phase 使用空间分区将候选对从 O(n²) 减少到 O(n)，这才是性能瓶颈的关键。

完整示例：简易物理世界

class PhysicsWorld {
public:
    void addBody(RigidBody& body) {
        m_bodies.push_back(&body);
    }

    void step(float dt) {
        // 1. 积分：更新速度和位置
        for (auto* body : m_bodies) {
            if (body->inverseMass.length() == 0) continue;  // 跳过静态物体
            semiImplicitEuler(*body, dt);
        }

        // 2. Broad Phase：空间哈希找候选对
        auto pairs = broadPhaseDetect(dt);

        // 3. Narrow Phase：GJK/EPA 精确检测
        std::vector<CollisionContact> contacts;
        for (const auto& [a, b] : pairs) {
            auto contact = narrowPhaseDetect(a, b);
            if (contact.valid) contacts.push_back(std::move(contact));
        }

        // 4. 约束求解：冲量 + 位置修正
        for (auto& contact : contacts) {
            solveCollision(contact.bodyA, contact.bodyB, contact);
        }
    }

private:
    std::vector<RigidBody*> m_bodies;
    SpatialHash m_spatialHash;

    void semiImplicitEuler(RigidBody& body, float dt) {
        body.linearVelocity += body.linearAcceleration * dt;
        body.angularVelocity += body.angularAcceleration * dt;
        body.position += body.linearVelocity * dt;
        body.rotation *= Quat(body.angularVelocity * dt * 0.5f);
        body.rotation.normalize();
        body.linearAcceleration = Vec3(0);
        body.angularAcceleration = Vec3(0);
    }
};

本章小结

本章核心知识点回顾：
  1. 碰撞检测分层：Broad Phase（空间分区）→ Narrow Phase（精确检测）。AABB 最快，GJK 最通用。
  2. SAT：分离轴定理适用于凸多边形，最多测试 n+m 条轴。凹多边形需先凸分解。
  3. GJK/EPA：GJK 判断相交，EPA 计算穿透深度和法线。工业级引擎的标准方案。
  4. 刚体动力学：质量、惯性张量、力和力矩。半隐式欧拉是游戏引擎的最佳折中。
  5. 约束求解：冲量-based 适合碰撞，PBD 适合软体和穿透。Baumgarte 稳定化防止穿透累积。
  6. 性能：Narrow Phase 单次检测在 ns 到 μs 量级，真正的性能杀手是 Broad Phase 的 O(n²) 对数。
