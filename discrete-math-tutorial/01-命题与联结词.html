01 - 命题与联结词

本章目标：能准确判断一个语句是不是命题；能熟练使用五个联结词将自然语言符号化；理解蕴含联结词的真值表为什么"看起来反直觉"。

1.1 命题：能判断真假的陈述

逻辑学的起点是一个朴素的想法：我们要研究"推理"，就得先把推理拆成一个个可以判断真或假的原子部件。这个部件就是命题。

定义 1.1（命题）

命题是能够判断真假的陈述句。每个命题有且仅有一个真值：真（记作 T 或 1）或假（记作 F 或 0）。

易错点：三个"不是命题"的典型
  • 疑问句、祈使句、感叹句："请关门！""今天天气真好啊！"——不是陈述句，直接排除。
  • 无法确定真假的陈述句："x + 1 > 0"——真假取决于 x 的值，不是命题。但"存在实数 x 使 x + 1 > 0"是命题（真），因为可以判断真假了。
  • 悖论："我正在说谎"——若为真则假，若为假则真，真值无法唯一确定，不是命题。

例 1.1 判断下列语句是否为命题

  1. "π 是有理数" —— 是命题（值为假）。命题可以是很假的，假不碍事，关键是"能判断"。
  2. "2026 年世界杯冠军来自欧洲" —— 是命题。虽然现在不知道真假，但它客观上有确定的真值。命题的真值不需要我们当下知道，只需要它客观上确定。
  3. "x = y" —— 不是命题（含自由变元，真假不定）。
  4. "这道题真难啊！" —— 不是命题（感叹句）。

命题分为两类：原子命题（不能再分解为更简单命题）与复合命题（由原子命题用联结词组合而成）。比如"小明既聪明又勤奋"由"小明聪明"和"小明勤奋"组合而成。联结词正是把原子命题粘合起来的"胶水"。

1.2 五个联结词

数理逻辑只保留五个最基本的联结词。它们的严格含义由真值表给出——注意，下面每个真值表就是该联结词的全部定义，不需要任何日常语言的辅助理解。

1.2.1 否定 ¬

定义 1.2（否定）

¬ 是一元联结词，其余四个都是二元联结词。注意"否定"与"反对"的区别：¬"所有人都及格了"不是"所有人都不及格"，而是"并非所有人都及格了"（即"至少有一个人不及格"）。这个细节在第 4 章量词部分会再次强调。

1.2.2 合取 ∧

定义 1.3（合取）

"p 并且 q"记作 p ∧ q，当且仅当两个命题都为真时为真。

常见误译：自然语言里的"和"不总是合取。"小王和小李是夫妻"不能符号化为 p ∧ q（"小王是夫妻"本身不是命题）。判断标准：拆开之后每一半是否仍是完整命题。

1.2.3 析取 ∨

定义 1.4（析取）

"p 或者 q"记作 p ∨ q，当且仅当两个命题都为假时为假。

逻辑中的"或"是相容或：两者都真时，p ∨ q 仍为真。日常语言中"苹果或者香蕉二选一"是排斥或（两者都真时语句为假）。排斥或需要写成 (p ∨ q) ∧ ¬(p ∧ q)，或等价地 (p ∧ ¬q) ∨ (¬p ∧ q)。

1.2.4 蕴含 →：最重要的一个

定义 1.5（蕴含）

"如果 p，则 q"记作 p → q。p 称为前件，q 称为后件。仅当前件真而后件假时，p → q 为假。

核心易错点：前件为假时蕴含式恒真（"善意推定"）
"若 2 + 2 = 5，则太阳从西边升起"真值为 1。这不是耍赖，而是数学的需要：数学定理"若 n > 2，则 xn + yn = zn 无正整数解"只在前件成立的情形下接受检验；前件不成立的情形（n ≤ 2）定理一律视为真，即"前件为假，蕴含式为真"。把这个真值表刻进脑子里，后面第 3 章的推理规则（假言推理、拒取式）才不会出错。

另外注意方向性：p → q 与 q → p 是两个不同的命题。与 p → q 相关的三种变形：

例 1.2 "除非你努力，否则你会挂科"怎么符号化？

"除非 A，否则 B"是一个高频且最容易翻车的句型。两种等价读法：

  • 读法一："如果不努力，那么挂科" → 令 p：你努力，q：你挂科，符号化为 ¬p → q。
  • 读法二："只有努力，才不挂科" → q → p？验证：¬p → q 与 q → p 真值表不同，是哪个出了问题？其实"只有 p 才 q"符号化为 q → p，"只有努力，才不挂科"是 ¬q → p。而 ¬p → q 与 ¬q → p 恰好互为逆否，两者等值 ✓。

记住口诀："除非 p，否则 q" = ¬p → q = ¬q → p。

1.2.5 等价 ↔

定义 1.6（等价）

"p 当且仅当 q"记作 p ↔ q，当且仅当两命题真值相同时为真。

区分两个"等价"：p ↔ q 是一个命题（有真值表，可以真可以假）；而"A ⇔ B"（等值式）是关于两个公式之间关系的断言，是元语言记号。同理 →（命题内的蕴含）与 ⇒（推理关系"永真蕴含"）也要分清。考试写混了会直接扣分。

1.3 复合命题的符号化

符号化的标准流程：① 找出原子命题并命名；② 确定联结结构；③ 按逻辑含义（而非语序）加括号。

例 1.3 符号化下列命题

  1. "小张是江西人且是程序员"。设 p：小张是江西人，q：小张是程序员。符号化：p ∧ q。
  2. "他要么是老师，要么是医生"。排斥或：( p ∧ ¬q ) ∨ ( ¬p ∧ q )。
  3. "如果明天不下雨且有空，我就去爬山"。设 r：明天下雨，s：我有空，t：我去爬山。符号化：( ¬r ∧ s ) → t。
  4. "只有复习了，才能通过考试"。"只有 p 才 q" = q → p（通过考试 ⇒ 一定复习过）。设 p：复习，q：通过考试，符号化：q → p。

1.4 合式公式与真值表

把命题变元（p, q, r, …）用联结词按规则组合起来的表达式称为命题公式（合式公式，well-formed formula）。定义是递归的：单个变元是公式；若 A、B 是公式，则 (¬A)、(A ∧ B) 等也是公式。只有有限次应用这两条规则得到的才是合式公式——所以 p ∧ 是非法串。

定理 1.1

含 n 个命题变元的公式，共有 2n 组真值指派，因此不同的真值函数（真值表模式）共有 22n 个。

例如 n = 2 时有 16 种真值函数，而联结词只给了我们表达手段——同一个真值函数可以对应无穷多个长得不同的公式（比如 p → q、¬p ∨ q、¬(p ∧ ¬q)）。"哪些公式本质上相同"正是第 2 章等值演算要解决的问题。

1.5 为什么值得学：逻辑与电路

命题逻辑不只是纸面游戏。CPU 中的每个门电路（AND、OR、NOT、NAND）就是物理实现的联结词，整个处理器不过是一个巨型命题公式的硬件版本。一段 if (a && b || !c) 代码的条件表达式，其短路求值行为就由 ∧ ∨ 的真值表决定。第 2 章讲主范式时你会看到：任何一个真值表都能机械地翻译回一个逻辑表达式——这正是"真值表 ↔ 逻辑电路"双向可逆的原因。

1.6 自测题

  1. 判断是否为命题并说明理由：(a) "快别刷手机了！"；(b) "任一大于 2 的偶数都可写成两个素数之和"；(c) "本命题是假的"。
  2. 设 p：小明坐地铁，q：小明迟到，写出"除非小明坐地铁，否则他迟到"的符号化。
  3. 求复合命题 (p → q) ∧ (q → r) 在指派 p=1, q=0, r=1 下的真值。
  4. "只有年满 18 岁，才能办银行卡"符号化为 p → q（p：年满 18，q：能办卡）对吗？
  5. 写出与 p → q 等值的两个公式（不用 ¬p ∨ q 和它本身）。
参考答案（先做再看）
  1. (a) 祈使句，不是命题；(b) 是命题（哥德巴赫猜想——真值客观确定，虽然未证出）；(c) 悖论，真值无法确定，不是命题。
  2. ¬p → q（等价于 q → p？不对——¬p → q 的逆否是 ¬q → p，即"不迟到就必须坐地铁"，符合"除非…才…"语义）。
  3. p → q：1→0 = 0，整个合取式为 0。
  4. 不对。"只有 p 才 q" 应为 q → p。写成 p → q 变成"满 18 岁就一定能办卡"，语义错了。
  5. ¬q → ¬p（逆否式）；¬(p ∧ ¬q)。（也可以答 q ∨ ¬p 等。）
本章小结：命题 = 能判真假的陈述句；五个联结词由真值表定义；蕴含式只在前件真后件假时为假；"只有/除非"句型方向易错；¬ 与"反对"、∨ 与"排斥或"不能想当然。下一步：把这些公式的等价变形系统化——等值演算与范式。
