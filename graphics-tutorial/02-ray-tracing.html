02 - 光线追踪：从 Whitted 到 PBRT

光线追踪是计算机图形学中最优雅、最直观的渲染算法之一。它的核心思想很简单：从相机发射光线，追踪它们与世界的交互。但在这个简单的想法背后，隐藏着深刻的数学——辐射度量学、蒙特卡洛积分、加速结构。本章从零开始构建你的第一个光线追踪器。

2.1 Whitted 光线追踪：基本原理

1980 年，Turner Whitted 发表了开创性论文 "Refractions and Reflections in Ray Tracing Systems"，首次将反射和折射纳入光线追踪框架。其核心算法如下：

Whitted 光线追踪算法

对于图像中的每个像素：

  1. 从相机光心通过像素中心发射一条射线
  2. 找到射线与场景的第一个交点
  3. 在该交点处：
    • 计算直接光照（阴影射线）
    • 如果表面有反射属性，发射反射射线
    • 如果表面有折射属性，发射折射射线
    • 递归地追踪反射/折射射线
  4. 将所有贡献累加为该像素的颜色

2.2 射线-三角形求交：Möller-Trumbore 算法

光线追踪中最基本的操作是判断一条射线是否与三角形相交。暴力方法需要解三次方程，但 Möller-Trumbore 算法巧妙地将其简化为线性方程组。

设射线为 R(t) = O + tD（O 为原点，D 为方向），三角形的三个顶点为 V0, V1, V2。三角形上任意一点可以表示为：

P = V0 + u(V1 - V0) + v(V2 - V0)，其中 u ≥ 0, v ≥ 0, u + v ≤ 1

令两者相等，得到：

O + tD = V0 + u(V1-V0) + v(V2-V0)

改写为矩阵形式并求解：[D | V1-V0 | V2-V0] · [t, u, v]ᵀ = O - V0

// Möller-Trumbore 光线-三角形求交算法
// 返回 true 如果射线与三角形相交，hit_t 保存交点参数
bool rayTriangleIntersect(
    const Vec3& orig, const Vec3& dir,
    const Vec3& v0, const Vec3& v1, const Vec3& v2,
    float& hit_t, float& u, float& v)
{
    Vec3 edge1 = v1 - v0;
    Vec3 edge2 = v2 - v0;
    Vec3 h = cross(dir, edge2);
    float a = dot(edge1, h);

    // 如果 a 接近 0，说明射线与三角形平面平行
    if (abs(a) < EPSILON) return false;

    float f = 1.0f / a;
    Vec3 s = orig - v0;
    u = f * dot(s, h);

    // 检查 u 是否在 [0, 1] 范围内
    if (u < 0.0f || u > 1.0f) return false;

    Vec3 q = cross(s, edge1);
    v = f * dot(dir, q);

    // 检查 v 是否在 [0, 1] 范围内且 u+v <= 1
    if (v < 0.0f || u + v > 1.0f) return false;

    // 计算交点沿射线的距离 t
    float t = f * dot(edge2, q);

    // 只接受正向交点（射线前方的交点）
    if (t > EPSILON) {
        hit_t = t;
        return true;
    }

    return false;
}
为什么用临界逆（critical inverse）？：注意代码中的 f = 1.0f / a。这里计算了一次倒数，然后在三个点积运算中复用。这比分别计算三个除法要快约 3 倍。在光线追踪器中，这种优化累积效应巨大——每秒要进行数十亿次求交测试。

2.3 递归光线追踪

Whitted 算法的核心是递归——在每个交点处，根据材质属性发射新的光线：

// 递归光线追踪主函数
Color traceRay(const Ray& ray, int depth) {
    // 基本情况：超出最大递归深度
    if (depth > MAX_DEPTH) return Color(0.0f);

    // 查找最近的交点
    Intersection closest;
    if (!scene.intersect(ray, closest)) {
        // 没有交点，返回背景色（天空）
        return skyColor(ray.direction);
    }

    // 计算直接光照
    Color diffuse = 0.0f;
    Color specular = 0.0f;

    for (const auto& light : scene.lights) {
        // 阴影射线：检查交点到光源之间是否有遮挡
        Ray shadowRay(closest.point + normalOffset(closest.normal),
                      light.position - closest.point);
        Intersection shadowHit;

        if (!scene.intersect(shadowRay, shadowHit) ||
            shadowHit.distance > (light.position - closest.point).length() - EPSILON) {
            // 光源可见，计算光照
            float NdotL = max(dot(closest.normal, shadowRay.direction), 0.0f);
            diffuse += closest.material.diffuse * light.intensity * NdotL;

            // Phong 高光
            Vec3 viewDir = -ray.direction;
            Vec3 reflectDir = reflect(shadowRay.direction, closest.normal);
            float spec = pow(max(dot(viewDir, reflectDir), 0.0f),
                           closest.material.shininess);
            specular += closest.material.specular * light.intensity * spec;
        }
    }

    // 递归：反射
    Color refl = 0.0f;
    if (closest.material.reflectivity > 0.0f) {
        Ray reflRay(closest.point + normalOffset(closest.normal),
                    reflect(ray.direction, closest.normal));
        refl = traceRay(reflRay, depth + 1) * closest.material.reflectivity;
    }

    // 递归：折射
    Color refr = 0.0f;
    if (closest.material.transmittance > 0.0f) {
        float eta = closest.material.refractionIndex;
        bool entering = dot(ray.direction, closest.normal) < 0.0f;
        if (entering) eta = 1.0f / eta;

        Ray refrRay(closest.point - normalOffset(closest.normal),
                    refract(ray.direction, closest.normal, eta));
        refr = traceRay(refrRay, depth + 1) * closest.material.transmittance;
    }

    return diffuse + specular + refl + refr;
}

2.4 BVH 加速结构

如果没有加速结构，光线追踪器需要对每条光线扫描场景中所有三角形——复杂度 O(N × R)（N 为三角形数，R 为光线数）。对于 100 万个三角形的场景，这就是每秒万亿次求交测试。BVH（Bounding Volume Hierarchy）将复杂度降到 O(log N × R)。

2.4.1 BVH 构建：SAH 启发式

最优的 BVH 构建是 NP-hard 问题，但 Surface Area Heuristic (SAH) 提供了优秀的近似：

SAH（表面积启发式）代价函数

对于分割节点，代价为：

C(node) = C_tree + Σ (P_child × C_leaf_child)

其中：

  • C_tree = 遍历内部节点的代价（常数，通常取 1）
  • P_child = 光线进入子节点的概率 ≈ 子节点表面积 / 父节点表面积
  • C_leaf_child = 叶节点中三角形的数量
// SAH BVH 构建
class BVHNode {
public:
    BoundingBox bounds;
    BVHNode* left;
    BVHNode* right;
    Triangle* triangle;  // 叶节点存储三角形索引
    int triangleCount;

    static BVHNode* build(const std::vector& triangles,
                          int depth = 0) {
        auto node = std::make_unique();
        node->bounds = computeBounds(triangles);

        if (triangles.size() <= MAX_LEAF_SIZE) {
            node->triangleCount = triangles.size();
            node->left = node->right = nullptr;
            // 存储三角形索引
            return node.release();
        }

        // SAH：尝试所有可能的分割平面，选择代价最小的
        float bestCost = FLT_MAX;
        int bestAxis = 0;
        float bestSplit = 0.0f;

        for (int axis = 0; axis < 3; axis++) {
            // 沿 axis 方向排序
            auto sorted = triangles;
            std::sort(sorted.begin(), sorted.end(),
                [axis](const Triangle& a, const Triangle& b) {
                    return a.centroid()[axis] < b.centroid()[axis];
                });

            // Huttenlocher 算法：用两个指针找到最优分割点
            BoundingBox leftBounds, rightBounds;
            int splitPoint = 1;

            for (int i = 0; i < (int)sorted.size() - 1; i++) {
                leftBounds.merge(sorted[i]);
                rightBounds = computeBounds(sorted.begin() + i + 1, sorted.end());

                float cost = surfaceArea(leftBounds) * leftBounds.triangleCount +
                            surfaceArea(rightBounds) * rightBounds.triangleCount;

                if (cost < bestCost) {
                    bestCost = cost;
                    bestAxis = axis;
                    bestSplit = (sorted[i].centroid()[axis] +
                               sorted[i+1].centroid()[axis]) / 2.0f;
                    splitPoint = i + 1;
                }
            }
        }

        // 按最优轴和分割点划分
        auto leftTri = std::vector();
        auto rightTri = std::vector();
        for (size_t i = 0; i < triangles.size(); i++) {
            if (triangles[i].centroid()[bestAxis] < bestSplit)
                leftTri.push_back(triangles[i]);
            else
                rightTri.push_back(triangles[i]);
        }

        // 防止一侧为空
        if (leftTri.empty()) leftTri.push_back(rightTri.back());
        if (rightTri.empty()) rightTri.push_back(leftTri.back());

        node->left = build(leftTri, depth + 1);
        node->right = build(rightTri, depth + 1);
        return node.release();
    }
};

2.4.2 BVH 遍历

BVH 遍历可以用递归来写，但在光线追踪器中，栈式遍历更可控（避免栈溢出）：

// 栈式 BVH 遍历
struct BVHTraversal {
    float tMin, tMax;
    Intersection closest;

    bool traverse(BVHNode* node, const Ray& ray) {
        // 使用显式栈而非递归
        std::stack stack;
        stack.push(node);

        while (!stack.empty()) {
            BVHNode* current = stack.top();
            stack.pop();

            // 快速拒绝：包围盒不相交
            if (!current->bounds.intersects(ray, tMin, tMax))
                continue;

            if (current->left == nullptr && current->right == nullptr) {
                // 叶节点：测试所有三角形
                for (int i = 0; i < current->triangleCount; i++) {
                    float t, u, v;
                    if (rayTriangleIntersect(ray.origin, ray.direction,
                        current->triangles[i].v0,
                        current->triangles[i].v1,
                        current->triangles[i].v2, t, u, v)) {
                        if (t < tMax) {
                            tMax = t;
                            closest = {current->triangles[i], t, u, v};
                        }
                    }
                }
            } else {
                // 先遍历近的节点（优化：减少最远交点的更新次数）
                float tLeft, tRight;
                bool hitLeft = current->left->bounds.intersects(ray, tMin, tLeft);
                bool hitRight = current->right->bounds.intersects(ray, tMin, tRight);

                if (hitLeft && hitRight) {
                    if (tLeft < tRight) {
                        stack.push(current->left);
                        stack.push(current->right);
                    } else {
                        stack.push(current->right);
                        stack.push(current->left);
                    }
                } else if (hitLeft) {
                    stack.push(current->left);
                } else if (hitRight) {
                    stack.push(current->right);
                }
            }
        }
        return closest.hit;
    }
};

2.5 辐射度量学基础

光线追踪的物理基础是辐射度量学（Radiometry）。这是描述电磁辐射（包括可见光）的数学框架。不理解辐射度量学，就无法写出 physically-based 的光线追踪器。

量 符号 单位 定义
辐射强度IW/sr单位立体角内的辐射通量
辐射亮度LW/(m²·sr)单位投影面积、单位立体角的辐射通量
辐射出射度MW/m²从表面发出的总辐射通量/面积
辐射照度EW/m²到达表面的辐射通量/面积
为什么 L 最重要？：在光线追踪中，radiance（辐射亮度 L） 是守恒量——沿无散射介质传播时不变。这就是为什么路径追踪器直接计算 L，然后通过 L = ∫ f_r · L_i · cos(θ) dω（渲染方程）求解。

2.5.1 BRDF（双向反射分布函数）

BRDF 描述了光线从哪个方向入射、从哪个方向反射的概率密度：

f_r(ωᵢ, ωₒ) = dLₒ(ωₒ) / (Lᵢ(ωᵢ) · cos(θᵢ) dωᵢ)

BRDF 必须满足四个物理约束：

  1. 非负性：f_r ≥ 0
  2. 赫歇尔-比尔定律（能量守恒）：∫ f_r · cos(θ) dω ≤ 1
  3. 互易性（Reciprocity）：f_r(ωᵢ, ωₒ) = f_r(ωₒ, ωᵢ)
  4. 菲涅尔效应：掠射角反射率趋近 1

2.6 Monte Carlo 积分

渲染方程是一个四维积分，没有解析解。Monte Carlo 积分是光线追踪器的数值引擎：

E = ∫ f(x) dx ≈ (1/N) Σ f(xᵢ) / p(xᵢ)

其中 p(x) 是采样概率密度函数（PDF）。重要性采样（Importance Sampling）选择 p(x) ∝ f(x) 来最小化方差。

// Monte Carlo 路径追踪器核心
Color pathTrace(const Ray& ray, int depth, RNG& rng) {
    Color throughput(1.0f);
    Color radiance(0.0f);
    Ray currentRay = ray;

    for (int d = 0; d < MAX_DEPTH; d++) {
        Intersection hit;
        if (!scene.intersect(currentRay, hit)) {
            radiance += throughput * skyColor(currentRay.direction);
            break;
        }

        // 计算直接光照（Next Event Estimation）
        for (const auto& light : scene.lights) {
            // 重要性采样：沿光源方向采样
            Vec3 lightDir = light.samplePosition(rng);
            float dist = (lightDir - hit.point).length();
            Vec3 sampleDir = normalize(lightDir - hit.point);

            float cosTheta = max(dot(hit.normal, sampleDir), 0.0f);
            if (cosTheta > 0.0f) {
                Ray shadowRay(hit.point + hit.normal * EPSILON, sampleDir);
                Intersection shadowHit;
                if (!scene.intersect(shadowRay, shadowHit) ||
                    shadowHit.distance > dist - EPSILON) {
                    // L_light / (pdf_light * area_light)
                    float pdf = cosTheta / light.area;
                    throughput *= hit.material.brdf(sampleDir, -currentRay.direction)
                                 * cosTheta / pdf;
                    radiance += throughput * light.emission;
                    throughput /= cosTheta / light.area; // 重置
                }
            }
        }

        // 采样反射方向
        Vec3 wo = -currentRay.direction;
        Vec3 wi = hit.material.sampleDirection(wo, rng);
        float pdf = hit.material.pdf(wi, wo);

        if (pdf > 0.0f) {
            throughput *= hit.material.brdf(wi, wo) * absDot(wi, hit.normal) / pdf;

            // Russian Roulette：低吞吐量时随机终止
            float q = std::max(0.05f, 1.0f - throughput.maxComponent());
            if (rng.float() < q) break;
            throughput /= 1.0f - q;

            currentRay = Ray(hit.point + hit.normal * EPSILON, wi);
        }
    }

    return radiance;
}

以下数据来自同一场景（100 万三角形，1080p，1 条/像素）在不同数据结构上的性能对比：

关键发现：

  • BVH 比暴力遍历快约 1000 倍，没有加速结构的光线追踪不可用
  • SAH 构建的 BVH 比简单的中位分割 BVH 快约 30%
  • LBVH（Level-Build BVH）可以在 1ms 内重建，适合动态场景
  • KD-Tree 遍历稍快但构建成本高，适合静态场景

2.8 本章小结

本章我们构建了光线追踪器的核心组件：

  1. Möller-Trumbore 求交算法：高效的射线-三角形求交，是光线追踪器的基础
  2. 递归光线追踪：Whitted 风格的光线追踪通过递归实现了反射和折射
  3. BVH 加速结构：SAH 启发式构建 + 栈式遍历，将复杂度从 O(N) 降到 O(log N)
  4. 辐射度量学：BRDF、辐射亮度的物理约束是 physically-based 渲染的基础
  5. Monte Carlo 积分：通过重要性采样和 Russian Roulette，我们用数值方法求解了渲染方程
