Rust 系统编程入门到精通

从零开始系统掌握 Rust 系统编程。不只是语法速成，而是深入理解所有权系统、借用检查器、生命周期、并发模型、宏系统和 unsafe Rust 的每一个细节。学完后能够独立编写高性能、内存安全的系统级程序。

关于本教程：
  • 前置知识：任何一门编程语言的基礎（C/C++/Java/Python 均可），了解指针和内存的基本概念
  • 学习深度：系统掌握 + 源码级剖析 + 实战项目
  • Rust 版本：Rust 1.80+（2024 年 LTS）
  • 主题风格：技术蓝（适合编程类教程）

版本：v1.0 | 更新日期：2026-07-02

适用环境：Rust 1.80+ / Cargo / Clippy / rustfmt

课程目录

基础

01 - Rust 哲学与设计理念

为什么选择 Rust？所有权系统如何消除空指针和数据竞争，零成本抽象，以及 Rust 与其他系统语言的根本区别。

基础

02 - 借用检查器深度解析

生命周期标注、借用规则、NLL（非词法生命周期）、Region Inference、借用检查器的算法原理。

基础

03 - 类型系统与模式匹配

Enum 与 Trait 的深度结合、Pattern Matching、类型别名、零成本抽象、Newtype 模式。

进阶

04 - 标准库深入

04 - 标准库深入：Vec、HashMap、Option、Result

Vec 的内存布局与扩容策略、HashMap 的哈希碰撞处理、Option/Result 的错误处理范式、Iterator 的零成本抽象。

进阶

05 - 错误处理

Result vs panic、anyhow 与 thiserror、自定义错误类型、Error _trait、try! 宏、? 操作符的展开机制。

进阶

06 - 并发编程

Send/Sync 的精确语义、Arc/Mutex/RwLock、Channel、async/await 底层机制、Tokio 运行时。

高级

07 - 宏系统

Declarative Macro（macro_rules!）、Proc Macro（derive/function）、Token Tree 解析、编译期代码生成。

高级

08 - FFI 与 C 互操作

cbindgen/bindgen、extern "C"、ABI 兼容性、安全 FFI 边界、与 C/C++ 库的集成。

高级

09 - 实战：构建命令行工具

09 - 实战：从零构建高性能日志分析器

从需求分析到架构设计：参数解析、文件 IO、多线程处理、性能基准测试。完整的工程项目。

高级

10 - 进阶：Unsafe Rust 与系统编程

10 - 进阶：Unsafe Rust 与内核级编程

unsafe 的六个超能力、raw pointer、align_of、ManuallyDrop、自定义 Drop、与操作系统交互。

学习路线建议

1

第一阶段：理解所有权（第 1-3 章）

这是 Rust 最难跨越的门槛。花足够的时间理解所有权和借用检查器，后面的章节会轻松很多。

2

第二阶段：掌握标准库与并发（第 4-6 章）

学会使用 Vec、HashMap、Option、Result 的正确姿势。理解 Send/Sync 的语义，编写安全的并发代码。

3

第三阶段：工程化与底层（第 7-10 章）

宏系统、FFI、完整项目实战、unsafe Rust。这些是区分"会用 Rust"和"精通 Rust"的分水岭。

开发环境

  • 安装：使用 rustup（官方推荐）— curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  • 编辑器：VS Code + rust-analyzer（推荐）或 JetBrains Rust（RustRover）
  • 必备工具：cargo（构建）、rustfmt（格式化）、clippy（linting）、rustdoc（文档）
  • 推荐工具：cargo-expand（宏展开）、cargo-udeps（未使用依赖）、miri（UB 检测）
  • 操作系统：Linux/macOS/Windows（WSL2 推荐）均可，本教程以 Linux 为主
