08 ｜ 受限玻尔兹曼机与深度信念网络

本章介绍能量模型史上工程上最成功的成员。Smolensky 在 1986 年把它称为「Harmonium」，Hinton 在 2002 年为它配上对比散度训练法并改名受限玻尔兹曼机（RBM）；2006 年堆叠 RBM 构成的深度信念网络直接点燃了深度学习的复兴。

8.1 结构：一个二分图

RBM 相对玻尔兹曼机只做一处结构修改：删去全部层内连接。可见单元之间、隐单元之间没有任何连接，连接只存在于跨层单元之间，网络构成二分图。能量函数简化为：

$$E(\mathbf{v},\mathbf{h}) = -\mathbf{v}^\top\mathbf{W}\mathbf{h} - \mathbf{b}^\top\mathbf{v} - \mathbf{c}^\top\mathbf{h}$$ (8.1)

这个看似牺牲表达能力的限制，换来的是推断结构的根本改善——它正是针对第 7 章「层内连接导致混合慢」的病根下的刀。

8.2 条件独立：RBM 的关键性质

由于能量中不含任何 $h_jh_k$ 项，固定可见层后，能量对隐单元是各单元线性项之和：

$$p(\mathbf{h}\mid\mathbf{v}) = \prod_j p(h_j\mid\mathbf{v}),\qquad p(h_j=1\mid\mathbf{v}) = \sigma\!\left(c_j + \mathbf{v}^\top\mathbf{W}_{:j}\right)$$

同理，固定隐层后：

$$p(\mathbf{v}\mid\mathbf{h}) = \prod_i p(v_i\mid\mathbf{h}),\qquad p(v_i=1\mid\mathbf{h}) = \sigma\!\left(b_i + \mathbf{W}_{i:}\mathbf{h}\right)$$

条件独立意味着给定一层，另一层的所有单元可以一次性并行采样，彼此之间不需要等待——层内没有连接，就没有需要传递的相互依赖。一次完整的 Gibbs 交替只需两步：$\mathbf{v}\to\mathbf{h}\to\mathbf{v}'$。对比 BM 中需要反复串行扫描才能化解层内相关，RBM 的混合速度大幅提高，且天然适合并行硬件。

8.3 自由能表达式

把隐单元解析地边缘化，得到可见状态的自由能。对隐单元的求和可以按单元因式分解：

$$\sum_{\mathbf{h}}e^{-E(\mathbf{v},\mathbf{h})} = e^{\mathbf{b}^\top\mathbf{v}}\prod_j\sum_{h_j\in\{0,1\}}e^{h_j(c_j+\mathbf{v}^\top\mathbf{W}_{:j})}$$

每个因子为 $1+e^{c_j+\mathbf{v}^\top\mathbf{W}_{:j}}$，取负对数：

$$F(\mathbf{v}) = -\mathbf{b}^\top\mathbf{v} - \sum_j\operatorname{softplus}\!\left(c_j+\mathbf{v}^\top\mathbf{W}_{:j}\right)$$ (8.2)

其中 $\operatorname{softplus}(x)=\ln(1+e^x)$。于是 $p(\mathbf{v})=e^{-F(\mathbf{v})}/Z$，一个深层隐变量模型被压缩成可见层上的显式（仅配分函数未知）能量模型。式 (8.2) 是 RBM 数值实现与梯度计算的直接依据。

8.4 对比散度：从数据出发的短链

精确的最大似然梯度仍需要负相位样本来自平衡分布，而 Gibbs 链跑到平衡依然昂贵。Hinton 2002 年提出的对比散度（Contrastive Divergence，CD-k）做了一个实用主义妥协：不从随机状态起跑，而从数据样本起跑，只跑 $k$ 步 Gibbs 就截断。完整算法如下：

1

取数据样本 $\mathbf{v}_0$；按条件概率并行采样 $\mathbf{h}_0\sim p(\mathbf{h}\mid\mathbf{v}_0)$。

2

交替重建 $k$ 轮：$\mathbf{v}_{t}\sim p(\mathbf{v}\mid\mathbf{h}_{t-1})$，$\mathbf{h}_{t}\sim p(\mathbf{h}\mid\mathbf{v}_{t})$。

3

用两端统计量更新参数：

$$\Delta\mathbf{W} = \eta\left(\langle\mathbf{v}_0\mathbf{h}_0^\top\rangle - \langle\mathbf{v}_k\mathbf{h}_k^\top\rangle\right)$$

实践中 $k=1$（CD-1）就常常够用，这是它能流行的直接原因：每个样本只需一次向上、一次向下采样。

展开：CD 的偏差——它不是最大似然梯度

必须清醒认识到：CD-k 不保证沿似然上升方向移动，它不是任何目标函数的精确梯度（理论上它对应两个 KL 散度之差 $\mathrm{KL}(p_0\Vert p_\infty)-\mathrm{KL}(p_k\Vert p_\infty)$）。$k\to\infty$ 时 CD 才收敛到真实最大似然梯度；$k$ 很小时收敛到的参数点与 MLL 解不同，且对能量函数的标定（似然绝对值）几乎不做约束。

后来的持续对比散度（PCD）用一条不重置的持久链生成负相位样本，训练稳定性和似然结果都更好。使用 CD-1 时应明确：你得到的是一个好用的近似，评估生成质量要靠独立的似然估计或样本检验，不能把 CD 损失下降当作似然上升的证据。

8.5 深度信念网络与 2006 年的转折

单个 RBM 只有两层。Hinton、Osindero 与 Teh 在 2006 年给出堆叠方案：训练好第一层 RBM 后，把隐层激活值当作下一层 RBM 的「数据」，再训练第二层，如此逐层向上。这一逐层贪心预训练把若干 RBM 叠成深度信念网络（Deep Belief Network，DBN）：顶层是无向联想记忆（一个 RBM），下层在生成方向上等价于有向 sigmoid 信念网络。

它的历史意义怎么强调都不为过：

  • 这是第一次有可靠程序训练出深的多层网络。此前深层网络直接用反向传播会陷入梯度消失和极差局部解，DBN 的预训练提供了良好的参数初值，之后再用反向传播微调。
  • 它在实验上展示了深度结构的优势，逆转了「深度不可训练」的共识，直接引发 2006 年后的深度学习浪潮——Bengio 团队的堆叠自动编码器等工作紧随其后。
后来的扬弃：DBN 的统治时间并不长。随着 ReLU、更好的权重初始化、Dropout 等技术出现，纯反向传播训练深层网络不再困难，繁琐的 RBM 预训练在 2010 年代中期基本退出主流。但公允地看，DBN 完成了它的历史使命——证明深度可行、重建研究信心。技术史上这类「桥梁性」方法被更好方案取代，并不降低其转折地位。RBM 本身今天仍用于协同过滤、推荐系统和特定的无监督特征学习。

8.6 练习与思考

基础练习 8-1

说明为什么 RBM 中给定可见层后，隐单元可以并行采样而 BM 不能。指出是能量函数中缺失的哪一项带来了这个差别。

基础练习 8-2

从式 (8.1) 独立推导自由能式 (8.2)，确认 softplus 项的来源。

思考题 8-3

CD-1 只跑一步 Gibbs，负相位样本离数据非常近。分析这会如何影响它对「远离数据的高能量区域」的建模能力，这与 CD 不约束能量绝对标定有什么关系？

思考题 8-4

DBN 预训练最终被纯反向传播取代。结合第 2 章感知机的历史，总结「训练可行性」在神经网络两次兴衰中扮演的共同角色。

本章小结

  • RBM 是无层内连接的二分图能量模型；条件独立使一层的全部单元可并行采样，一次 Gibbs 交替仅需两步。
  • 自由能解析可写为 $F(\mathbf{v})=-\mathbf{b}^\top\mathbf{v}-\sum_j\operatorname{softplus}(c_j+\mathbf{v}^\top\mathbf{W}_{:j})$。
  • 对比散度从数据出发跑短链近似负相位，CD-1 实用但非精确梯度，PCD 是更稳的改进。
  • 堆叠 RBM 构成的 DBN 首次实现深层训练、引爆 2006 复兴，后随纯反向传播技术成熟而被取代。
