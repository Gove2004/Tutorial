Web 浏览器内部入门到精通

从 URL 输入到页面渲染，深入浏览器每一个核心子系统：DNS 解析、TCP/TLS 握手、HTTP/2/3 协议、DOM 树构建、CSS 布局、JavaScript 引擎、渲染合成。不只是"怎么用浏览器"，而是理解浏览器"怎么工作"。

关于本教程：
  • 前置知识：计算机网络基础、HTML/CSS/JavaScript 基础、C/C++ 基础
  • 学习深度：系统掌握 — 协议细节 + 引擎内部 + 性能优化
  • 浏览器：Chromium/Blink/V8 架构
  • 主题风格：技术蓝（适合编程/网络类教程）

版本：v1.0 | 更新日期：2026-07-02

适用环境：Chrome 120+ / Chromium 源码 / Node.js 20+

学习路线建议

1

第一阶段：理解浏览器架构（第 1-3 章）

网络层、DNS、TCP/TLS、HTTP/2/3。这是浏览器的"血管"。

2

第二阶段：渲染管线（第 4-7 章）

DOM、CSS、Layout、Paint、Composite。这是浏览器的"心脏"。

3

第三阶段：JS 引擎与异步（第 8-9 章）

V8 引擎、事件循环、性能优化。这是浏览器的"大脑"。

4

第四阶段：完整项目（第 10 章）

从零构建一个能渲染网页的浏览器。把学到的所有知识整合。
