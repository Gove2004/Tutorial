计算机图形学入门到精通

系统掌握现代图形学的每一个核心领域：光线追踪、全局光照、物理模拟（流体/布料/刚体）、程序化内容生成、网格处理。不只是 API 调用，而是理解每个算法的数学基础和工程实现。

关于本教程：
  • 前置知识：C++ 基础、线性代数（矩阵/向量/四元数）、微积分
  • 学习深度：系统掌握 — 算法原理 + 数学推导 + 工程实现
  • 图形 API：OpenGL/Vulkan/DX12 均有涉及
  • 主题风格：技术蓝（适合编程/图形类教程）

版本：v1.0 | 更新日期：2026-07-02

适用环境：C++17 / OpenGL 4.6 / Vulkan 1.3 / CUDA 12+
