第 3 章 · 价值函数与贝尔曼方程

有了 MDP 和回报，我们引入强化学习最核心的概念之一——价值函数（value function）。它回答"某个状态（或状态里的某个动作）未来平均能拿多少分"，而贝尔曼方程则给出价值之间递归、可计算的关系。后面所有算法，本质上都是在估计或优化这里定义的价值。

3.1 策略：在每个状态如何选择动作

策略（policy） π 是智能体的"行为规则"，它可以是确定性的 a=π(s)，也可以是随机性的 π(a|s)——在状态 s 选择各动作的概率。强化学习的最终产物，往往就是一个好策略。

3.2 状态价值 V 与动作价值 Q

两类价值函数（都是"未来回报的期望"）

状态价值函数：从状态 s 出发、之后按策略 π 行动，能拿到的回报期望

V^π(s) = Eπ[ Gₜ | sₜ = s ]

动作价值函数：从 s 出发先做动作 a、之后再按 π 行动的回报期望

Q^π(s, a) = Eπ[ Gₜ | sₜ = s, aₜ = a ]

两者的差别很关键：V 衡量"身处这个状态好不好"（已经默认之后按 π 选动作）；Q 衡量"在这个状态里具体做某个动作好不好"。做决策时 Q 更直接：比较同一状态下各动作的 Q，选最大的即可。

3.3 贝尔曼期望方程：价值的递归表达

把 Gₜ = rₜ₊₁ + γ·Gₜ₊₁ 代入价值定义，就得到贝尔曼期望方程。它用"下一步"的价值表达"这一步"的价值：

V^π(s) = Σₐ π(a|s) Σ_{s′} P(s′|s,a) [ R(s,a,s′) + γ·V^π(s′) ]
Q^π(s,a) = Σ_{s′} P(s′|s,a) [ R(s′) + γ Σ_{a′} π(a′|s′) Q^π(s′, a′) ]

方括号里的 R + γV(s′) 称为一次贝尔曼备份（Bellman backup）：把"下一状态的价值"连同"即时奖励"回传一格给当前状态。这正是信用分配的数学实现——终点的高价值能一步步回传到通往终点的每个状态。

手算一次备份（建立直觉）

设某状态 s 下只有一个动作，做完一定进入 s′，即时奖励 R=0，γ=0.9，且已知 V^π(s′)=10。则

V^π(s) = 0 + 0.9 × 10 = 9

注意这里没有真正"走"，仅靠下一步价值的估计就更新了当前价值——这种"用估计去更新估计"的做法叫引导（bootstrapping），是时序差分方法的灵魂（第 5 章）。

3.4 最优价值与贝尔曼最优方程

在所有可能策略中，能让每个状态价值都最大的那个策略叫最优策略 π*，对应的价值叫最优价值函数 V* 与 Q*：

V*(s) = max_π V^π(s)，　Q*(s,a) = max_π Q^π(s,a)

最优策略下，我们不再对动作求加权平均（那是"将就当前策略"），而是假设可以直接选最好的动作，于是得到贝尔曼最优方程：

V*(s) = maxₐ Σ_{s′} P(s′|s,a)[ R + γ·V*(s′) ]
Q*(s,a) = Σ_{s′} P(s′|s,a)[ R + γ·max_{a′} Q*(s′, a′) ]
为什么 Q* 如此重要：一旦学到 Q*，最优策略根本不需要再做复杂规划——在任意状态，选 Q* 最大的那个动作即可：
π*(s) = argmaxₐ Q*(s,a)
这正是 Q-learning 和 DQN 拼命逼近 Q* 的原因。

3.5 代码：固定策略下用贝尔曼方程求 V^π

下面在一个模型已知的小网格上，反复套用贝尔曼期望方程（这个过程叫策略评估，第 4 章会系统讲），观察终点价值如何"扩散"到整张地图。

class TinyGrid:
    """4x4 确定性网格，目标(3,3)。模型完全已知：
    给定 (状态,动作) 可直接知道下一状态与奖励。"""
    def __init__(self, size=4):
        self.size = size
        self.goal = (size - 1, size - 1)
        self.states = [(x, y) for x in range(size) for y in range(size)]

    def model(self, s, a):
        if s == self.goal:
            return s, 0.0                       # 终点自循环，奖励 0
        x, y = s
        if   a == 0: x = max(0, x - 1)
        elif a == 1: x = min(self.size - 1, x + 1)
        elif a == 2: y = max(0, y - 1)
        else:        y = min(self.size - 1, y + 1)
        s2 = (x, y)
        r = 1.0 if s2 == self.goal else -0.01
        return s2, r

env = TinyGrid()
gamma = 0.9
V = {s: 0.0 for s in env.states}               # 初始价值全为 0

for iteration in range(100):
    newV = {}
    for s in env.states:
        # 随机均匀策略：每个动作概率 1/4
        total = 0.0
        for a in range(4):
            s2, r = env.model(s, a)
            total += 0.25 * (r + gamma * V[s2])
        newV[s] = total
    delta = max(abs(newV[s] - V[s]) for s in env.states)
    V = newV
    if delta < 1e-6:
        print(f"第{iteration+1}轮收敛")
        break

for x in range(4):
    print(" ".join(f"{V[(x,y)]:6.2f}" for y in range(4)))
如何读这张价值表：终点附近的格子价值最高（离奖励最近），越远越低（被 γ 和每步惩罚层层折扣）。这就是"未来值多少分"的具象化。注意：现在用的是随机策略，所以智能体即便在好位置也可能乱走；第 4 章我们让它"贪心地"朝高价值方向走，价值会进一步提高。

本章小结

  • 策略 π 是行为规则；V^π(s) 与 Q^π(s,a) 是未来回报的期望，Q 更便于直接决策。
  • 贝尔曼期望方程用"下一步价值 + 即时奖励"递归表达当前价值，一次计算即一次贝尔曼备份。
  • 最优价值 V*/Q* 满足带 max 的贝尔曼最优方程；学到 Q* 后，argmax 即得最优策略。
  • "用估计更新估计"称为引导，是后续时序差分方法的核心。
