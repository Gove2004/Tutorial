05 - 物理模拟：布料与刚体

布料和刚体是物理模拟中最实用的两个类别。布料模拟广泛用于服装、旗帜、帐篷等软体对象的渲染；刚体动力学则是游戏物理引擎的核心。本章我们将学习 Verlet 积分、位置基动力学（PBD）、弹簧质点系统以及连续碰撞检测（CCD）。

5.1 Verlet 积分

Verlet 积分是物理模拟中最常用的数值积分方法之一。它的特点是简单、稳定、且天然守恒能量（对保守系统而言）。

Verlet 积分公式

给定当前位置 x(t)、上一时刻位置 x(t-Δt) 和当前加速度 a(t)：

x(t+Δt) = 2x(t) - x(t-Δt) + a(t)·Δt²

速度隐含地表示为：

v(t) = (x(t) - x(t-Δt)) / Δt

// Verlet 积分器
class VerletIntegrator {
    struct Particle {
        vec3 position;
        vec3 previousPosition;  // 上一帧位置（隐含速度）
        vec3 acceleration;
        bool fixed;             // 是否固定（钉子点）
    };

    void integrate(std::vector& particles, float dt) {
        for (auto& p : particles) {
            if (p.fixed) continue; // 固定粒子不积分

            // x_new = 2*x - x_prev + a*dt^2
            vec3 newPos = 2.0f * p.position - p.previousPosition
                        + p.acceleration * dt * dt;

            p.previousPosition = p.position;
            p.position = newPos;

            // 阻尼（模拟空气阻力）
            vec3 vel = (p.position - p.previousPosition);
            vel *= dampingFactor;
            p.previousPosition = p.position - vel;
        }
    }
};

为什么 Verlet 适合布料？：布料模拟需要大量的约束求解（保持布料的拉伸/弯曲/剪切约束）。Verlet 只需要位置信息，不需要显式存储速度——速度可以从位置差中推导出来。这使得约束求解非常直接：修改位置，速度自然更新。

5.2 位置基动力学（PBD）

PBD 是由 Müller 等人在 2007 年提出的，它不求解力/加速度，而是直接修改粒子位置以满足约束。这是游戏引擎（如 NVIDIA Flex、Unity DOTS Physics）中广泛采用的方法。

// PBD 约束求解
class PositionBasedDynamics {
    struct Constraint {
        enum Type { Distance, Bending, Shear, Volumetric };
        Type type;
        std::vector particleIndices;
        float restValue;      // 约束的"目标值"
        float stiffness;      // 约束硬度 (0=软, 1=硬)

        void solve(std::vector& positions,
                   std::vector& constraints) {
            // 计算当前值
            float currentValue = computeCurrentValue(positions);

            // 计算修正量
            float correction = (restValue - currentValue) * stiffness;

            // 应用到相关粒子
            for (int idx : particleIndices) {
                positions[idx] += correction * getGradient(idx);
            }
        }
    };

    // 主循环
    void simulate(std::vector& positions, float dt) {
        // 1. Verlet 积分
        for (auto& p : positions) {
            Vec3 vel = p - prevPositions[&p - &positions[0]];
            vel *= damping;
            p += vel + acceleration * dt * dt;
        }

        // 2. 求解约束（迭代多次以提高稳定性）
        for (int iter = 0; iter < numConstraintIterations; iter++) {
            for (auto& c : constraints) {
                c.solve(positions);
            }
        }

        // 3. 保存当前位置作为下一帧的"上一帧位置"
        prevPositions = positions;
    }
};

5.3 弹簧质点系统

布料最基本的模型是弹簧质点系统：粒子代表布料上的点，弹簧代表粒子之间的连接。

┌──────────────────────────────────────────────────────────────────────┐ │ 布料弹簧质点模型 │ │ │ │ 结构弹簧（Stretch）： │ │ P0 ---- S1 ---- P1 ---- S2 ---- P2 ← 水平方向 │ │ | | | │ │ S3 S4 S5 │ │ | | | │ │ P3 ---- S6 ---- P4 ---- S7 ---- P5 ← 垂直方向 │ │ │ │ 弯曲弹簧（Bending）： │ │ P0 -------- P1 -------- P2 │ │ \ / │ │ \ / │ │ P3 ------ P4 ------ P5 │ │ │ │ 剪切弹簧（Shear）： │ │ P0 -------- P1 │ │ | \ / | │ │ | \ / | │ │ | \ / | │ │ | \/ | │ │ P3 -- P4 -- P5 │ │ │ │ 三种弹簧共同作用，才能模拟真实的布料行为 │ └──────────────────────────────────────────────────────────────────────┘ 
// 弹簧质点布料模拟
class ClothSimulation {
    struct Spring {
        int i, j;            // 连接的粒子索引
        float restLength;    // 自然长度
        float stiffness;     // 刚度
        enum Type { Stretch, Bend, Shear } type;
    };

    void applySpringForces(std::vector& positions,
                          std::vector& velocities,
                          const std::vector& springs,
                          float dt) {
        for (auto& spring : springs) {
            Vec3 delta = positions[spring.j] - positions[spring.i];
            float dist = delta.length();
            Vec3 force = delta / (dist + EPSILON) *
                        spring.stiffness * (dist - spring.restLength);

            velocities[spring.i] += force / mass * dt;
            velocities[spring.j] -= force / mass * dt;
        }

        // 积分
        for (size_t i = 0; i < positions.size(); i++) {
            positions[i] += velocities[i] * dt;
        }
    }

    // 推荐：用 PBD 代替弹簧力，因为更稳定
    // 弹簧力的问题： stiff spring → 需要极小的 dt，否则爆炸
    // PBD 直接修改位置，不受 dt 限制
};

5.4 碰撞检测与响应

布料模拟中最棘手的部分是碰撞——布料与自身、布料与其他物体的碰撞。

            // 法向速度：反弹或静止
        }

// 布料自碰撞检测（简化版：空间分区）
void handleSelfCollision(std::vector& positions,
                         std::vector& fixed,
                         float collisionRadius) {
    // 使用空间哈希加速
    SpatialHash hash(positions.size(), collisionRadius);

    for (size_t i = 0; i < positions.size(); i++) {
        if (fixed[i]) continue;

        auto neighbors = hash.query(positions[i], collisionRadius);
        for (int j : neighbors) {
            if (j <= i) continue;

            Vec3 diff = positions[i] - positions[j];
            float dist = diff.length();

            if (dist < collisionRadius && dist > EPSILON) {
                // 推开重叠的粒子
                float overlap = collisionRadius - dist;
                Vec3 push = normalize(diff) * overlap * 0.5f;
                positions[i] += push;
                positions[j] -= push;
            }
        }
    }
}

5.5 刚体动力学

刚体是形状不变的物体。与质点不同，刚体有旋转自由度，需要用角速度和惯性张量来描述。

刚体运动方程

平动：

F = m · a （牛顿第二定律）

转动：

τ = I · α + ω × (I · ω) （欧拉方程）

其中：

  • τ = 扭矩
  • I = 惯性张量（3×3 矩阵）
  • α = 角加速度
  • ω = 角速度
  • ω × (I · ω) = 陀螺效应项（非对角惯量时的进动）
// 刚体数据结构
struct RigidBody {
    // 平动状态
    Vec3 position;
    Vec3 velocity;
    float mass;
    float invMass;

    // 转动状态（用四元数避免万向节锁）
    Quat orientation;
    Vec3 angularVelocity;
    Mat3 inertiaTensor;      // 局部坐标系
    Mat3 invInertiaTensor;   // 局部坐标系

    // 碰撞形状
    BoundingBox bounds;

    void applyForce(const Vec3& force, const Vec3& point) {
        // 平动
        velocity += force * invMass * dt;

        // 转动：扭矩 = r × F
        Vec3 r = point - position;
        Vec3 torque = cross(r, force);

        // α = I^(-1) · (τ - ω × (I · ω))
        Vec3 angularAccel = invInertiaTensor *
            (torque - cross(angularVelocity, inertiaTensor * angularVelocity));
        angularVelocity += angularAccel * dt;
    }

    void integrate(float dt) {
        // 平动
        position += velocity * dt;

        // 转动：四元数积分
        // q_new = q_old + 0.5 * omega_quat * q_old * dt
        Quat omegaQuat(0, angularVelocity.x, angularVelocity.y, angularVelocity.z);
        orientation = orientation + 0.5f * (omegaQuat * orientation) * dt;
        orientation.normalize();
    }
};

5.6 连续碰撞检测（CCD）

当物体运动很快时，离散碰撞检测会"穿透"——两个物体在一帧之内就已经穿过彼此了。CCD 通过求解运动方程来检测两帧之间的碰撞。

// CCD：射线-球体求交（最简单的情形）
bool continuousCollisionSphere(
    const Vec3& sphereStart, const Vec3& sphereVel,
    float sphereRadius,
    const Vec3& obstacleCenter, float obstacleRadius,
    float& hitTime)  // 输出：碰撞发生的时间比例 [0, 1]
{
    Vec3 relStart = sphereStart - obstacleCenter;
    Vec3 relVel = sphereVel;
    float minDist = sphereRadius + obstacleRadius;

    // 求解 |relStart + t * relVel| = minDist
    // 即 (relStart + t*relVel)·(relStart + t*relVel) = minDist²
    // at² + bt + c = 0
    float a = dot(relVel, relVel);
    float b = 2.0f * dot(relStart, relVel);
    float c = dot(relStart, relStart) - minDist * minDist;

    float discriminant = b * b - 4.0f * a * c;
    if (discriminant < 0.0f) return false; // 无实根，不会碰撞

    float sqrtD = sqrt(discriminant);
    float t1 = (-b - sqrtD) / (2.0f * a);
    float t2 = (-b + sqrtD) / (2.0f * a);

    // 取第一个碰撞时间
    if (t1 > EPSILON && t1 <= 1.0f) {
        hitTime = t1;
        return true;
    }
    if (t2 > EPSILON && t2 <= 1.0f) {
        hitTime = t2;
        return true;
    }

    return false;
}

以下数据来自布料模拟测试（100×100 网格，10000 粒子，60fps 目标）：

关键观察：

  • PBD 比弹簧力方法更稳定，且不需要极小的时间步长
  • 约束迭代次数是稳定性和性能之间的主要权衡
  • CCD 使碰撞检测变慢约 2-3 倍，但大幅减少穿透
  • SDF（符号距离场）膨胀是 CCD 的高效替代方案

5.8 本章小结

本章我们覆盖了物理模拟的两个重要领域：

  1. Verlet 积分因其稳定性和无需显式速度而成为布料模拟的首选
  2. PBD直接求解位置约束，比传统的力方法更稳定、更易并行
  3. 弹簧质点系统是布料的基础模型，但需要拉伸/弯曲/剪切三种弹簧
  4. 刚体动力学引入了四元数旋转和惯性张量，避免了万向节锁
  5. CCD解决了高速运动的穿透问题，代价是约 2-3 倍的性能开销
