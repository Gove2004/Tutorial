软件工程完整教程

从需求分析到系统部署，从代码质量到团队协作——全面掌握软件工程的核心理论与实践方法。这不是"怎么写代码"的教程，而是"怎么做好一个软件项目"的系统课程。

关于本教程：
  • 前置知识：至少掌握一门编程语言的基本语法和常用数据结构
  • 学习深度：系统掌握 — 核心理论 + 工业实践 + 团队协作
  • 适用人群：有编程基础的开发者、初级技术负责人、准备转岗软件工程的同学
  • 主题风格：技术蓝（适合工程类教程）

版本：v1.0 | 更新日期：2026-07-03

适用环境：任何主流编程语言与开发平台

课程目录

基础

01 - 软件工程概述

什么是软件工程？为什么"写代码"不等于"做软件"。软件危机、工程化思维、软件生命周期模型。

基础

02 - 需求工程

需求获取、需求分析、需求规格说明书（SRS）、需求验证、需求管理。功能需求与非功能需求。

基础

03 - 软件开发过程模型

瀑布模型、增量模型、螺旋模型、敏捷开发、DevOps。每种模型的适用场景与局限性。

进阶

04 - 软件设计

架构设计、模块设计、接口设计。架构风格（分层、微服务、事件驱动）、设计原则（SOLID）、设计模式。

进阶

05 - 编码实践

编码规范、代码审查、重构技术、技术债务管理。从"能跑"到"好维护"的跨越。

进阶

06 - 软件测试

单元测试、集成测试、系统测试、验收测试。TDD/BDD、测试覆盖率、Mock、自动化测试框架。

高级

07 - 版本控制与协作

Git 工作流、分支策略（Git Flow / Trunk Based）、代码评审、协作规范。从个人开发到团队协作。

高级

08 - CI/CD 与持续交付

持续集成、持续交付、持续部署。Pipeline 设计、环境管理、灰度发布、回滚策略。

高级

09 - 项目管理与度量

估算与排期、风险管理、敏捷看板、代码度量（圈复杂度、耦合度、圈复杂度）。用数据驱动决策。

高级

10 - 工程趋势与前沿

AI 辅助开发、低代码/无代码、平台工程、SRE 文化、绿色软件工程。面向未来的工程实践。

学习路线建议

1

第一阶段：建立工程思维（第 1-3 章）

理解软件工程的全貌：需求 → 设计 → 实现 → 测试 → 部署。建立"工程化"而非"写代码"的思维。

2

第二阶段：掌握核心技能（第 4-6 章）

软件设计、编码实践、测试体系——这三章构成了日常开发的核心工作流。

3

第三阶段：团队协作与交付（第 7-9 章）

版本控制、CI/CD、项目管理——从"一个人写代码"到"一群人做产品"的跨越。

4

第四阶段：面向未来（第 10 章）

了解行业前沿趋势，为自己的职业成长规划方向。

推荐工具链

  • 版本控制：Git + GitHub / GitLab
  • 项目管理：Jira / Linear / GitHub Projects
  • CI/CD：GitHub Actions / GitLab CI / Jenkins
  • 代码质量：SonarQube / ESLint / Pylint
  • 测试：JUnit / pytest / Jest / Playwright
  • 文档：Markdown + MkDocs / Sphinx / JSDoc
  • 架构设计：Draw.io / Mermaid / C4 Model
