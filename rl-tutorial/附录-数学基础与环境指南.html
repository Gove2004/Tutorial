A. 数学基础速查

A.1 概率与期望

  • 随机变量与分布：离散分布用概率 P(X=x)，连续分布用概率密度。
  • 期望：离散 E[X]=Σ x·P(x)，是"大量重复下的平均值"。RL 的价值几乎都是期望。
  • 条件概率 P(A|B)：给定 B 时 A 的概率；MDP 的转移 P(s′|s,a) 即条件概率。

A.2 线性代数（够用）

  • 向量/矩阵：状态常表示为向量；权重是矩阵；y=Wx+b 是最常见的线性映射。
  • 点积、范数：范数衡量"长度/距离"（如到终点距离）；梯度裁剪用到范数。

A.3 梯度与链式法则

  • 梯度指向函数增大最快的方向；最小化损失时沿负梯度更新参数。
  • 链式法则让误差能从输出层层反传到每层参数——这正是 backward() 在做的事。

B. PyTorch 入门补充

import torch

# 1) 张量与形状
x = torch.zeros(2, 3)          # 2行3列全0
print(x.shape, x.dtype)
b = torch.tensor([[1.0, 2.0]])# 形状 (1,2)
print(b.view(2, 1))           # 改变形状为 (2,1)

# 2) 关键：batch 永远是第 0 维
states = torch.randn(10, 4)   # 10 个样本、每个 4 维
net_out = torch.nn.Linear(4, 2)(states)  # 输出 (10,2)

# 3) 梯度：默认不求和，需要时再开
w = torch.tensor(1.0, requires_grad=True)
loss = (w * 3 - 2) ** 2
loss.backward()
print(w.grad)                 # 损失对 w 的导数

# 4) 常见维度操作
q = torch.randn(5, 3)
print(q.max(dim=1).values)    # 每行最大值 -> 形状 (5,)
print(q.argmax(dim=1))        # 每行最大值的列索引 -> (5,)
最常见的 PyTorch 报错与原因
  • 形状不匹配 / mat1 and mat2 shapes cannot be multiplied：输入维度与网络第一层不一致；打印各张量 shape 排查。
  • Can't call numpy() on Tensor that requires grad：先 .detach() 再 .numpy()。
  • dtype 不匹配（Long vs Float）：索引用 LongTensor，喂网络的特征用 float32。
  • 设备不一致（CPU/CPU）：张量与模型要在同一设备上（.to(device)）。

C. 环境安装指南

先看 Python 版本：深度学习依赖（尤其 PyTorch）对最新版 Python 的支持往往滞后。如果你的 Python 非常新（如 3.14）而安装 PyTorch 报错，最稳妥的办法是另建一个 Python 3.11 或 3.12 的虚拟环境，而不是强行在最新版上安装。

C.1 用虚拟环境隔离（推荐）

# 创建并激活虚拟环境（在你的项目目录执行）
python -m venv .venv
# Windows PowerShell：
.venv\Scripts\Activate.ps1
# macOS/Linux：
source .venv/bin/activate

C.2 安装所需库（请在你确认后再执行）

pip install numpy matplotlib
pip install torch
pip install gymnasium
# CartPole 已含在 gymnasium 基础包；如需 LunarLander：
pip install "gymnasium[box2d]"

本教程不会替你执行安装；你可以自行运行，或让我在你明确同意后协助。

C.3 完全免安装：用浏览器里的云端环境

  • Google Colab（colab.research.google.com）：新建笔记本即可 pip install 并运行，免费 GPU。
  • Kaggle Notebooks（kaggle.com/code）：同样免配置、可联网安装。
  • Hugging Face Spaces：适合托管与展示你的项目。

D. 术语表

术语一句话解释
智能体 Agent / 环境 Environment做决策者 / 智能体之外、被动作影响的一切
策略 Policy状态到动作（或动作概率）的规则
奖励 Reward / 回报 Return单步得分 / 折扣后的累计未来得分
状态价值 V / 动作价值 Q身处状态的未来期望分 / 状态里做某动作的期望分
优势 Advantage动作比该状态平均水平好多少，A=Q−V
贝尔曼方程 / 备份用下一步价值递归表达当前价值 / 一次这样的回传
引导 Bootstrapping用估计去更新估计（只看有限步未来）
on-policy / off-policy评估当前在用策略 / 用行为策略数据学另一个目标策略
经验回放 Replay存历史转移并随机采样复用，去相关、提效率
探索-利用尝试新动作 vs 重复已知好动作的平衡
