Rain World 反编译源码深度导读

面向 Unity / C# 开发者与模组作者，系统拆解 Rain World（v1.11.6）的双层世界、自研物理、效用 AI、Futile 渲染与模组生态。所有结论均来自反编译源码的真实代码。

源码版本：Rain World v1.11.6（含 Downpour / More Slugcats 与 The Watcher 两大 DLC，及 Expedition、Jolly Coop 模式）
技术底座：Unity 引擎，C#，目标框架 .NET Framework 4.0，允许 unsafe 代码，输入采用 Rewired，钩子采用 MonoMod RuntimeDetour
工程规模：Assembly-CSharp 主程序约 1100+ 个 C# 文件，Assembly-CSharp-firstpass 86 个文件
关于本教程
  • 读者画像：具备 C# 与 Unity 基础，想读懂大型商业游戏源码、制作 Rain World 模组，或学习其架构设计的开发者
  • 学习深度：系统掌握级，覆盖核心机制、调用链、边界情况、生产陷阱与逆向方法
  • 视觉风格：tech 技术蓝——源码导读属工程类内容，需要清晰的类层次、调用链与代码高亮
  • 使用方式：双击本文件即可在浏览器离线学习，架构图使用 Mermaid 渲染，代码块支持一键复制

学习路径

本教程遵循「先全局、后分层、再专题」的递进路径：第 1–2 章建立认知与全局观；第 3–9 章自顶向下拆解主循环、双层世界、物理、生物骨架与 AI；第 10–14 章进入玩家、渲染、界面、音频与存档专题；第 15 章收束于模组生态与逆向实战。
