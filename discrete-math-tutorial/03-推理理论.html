03 - 推理理论

本章目标：理解"有效推理"与"结论为真"的区别；熟记 9 条推理定律；掌握直接证明、附加前提证明法（CP 规则）与归谬法三种证明套路，能独立构造推理证明。

3.1 什么是有效推理

定义 3.1（推理的有效性）

设 A1, …, Ak 为前提，B为结论。若 (A1 ∧ … ∧ Ak) → B 是重言式，则称推理有效，记作 A1, …, Ak ⇒ B。

必须想清楚的一点：有效性关心的是形式，不是事实。前提"所有人都会飞"（假）+ "苏格拉底是人"，有效推出"苏格拉底会飞"。前提全假但推理有效，完全合法。有效 = 只要前提真，结论就必真；前提本身真假不在逻辑管辖范围内。

3.2 九条推理定律

基本推理定律（P 规则的素材）

名称形式备注
附加A ⇒ A ∨ B"已知 A 真，则 A 或随便什么都真"
化简A ∧ B ⇒ A用掉一半前提
假言推理（MP）A → B, A ⇒ B最常用，肯前式
拒取式（MT）A → B, ¬B ⇒ ¬A否后式，第二常用
析取三段论A ∨ B, ¬A ⇒ B排除一个，剩另一个
假言三段论A → B, B → C ⇒ A → C推理链传递
等价三段论A ↔ B, B ↔ C ⇒ A ↔ C
构造性二难(A → B) ∧ (C → D), A ∨ C ⇒ B ∨ D
破坏性二难(A → B) ∧ (C → D), ¬B ∨ ¬D ⇒ ¬A ∨ ¬C
两大经典谬误（考试陷阱 + 日常吵架高发）
  • 肯定后件谬误：A → B, B ⇒ A。A → B 为真、B 为真时，A 可以是 0（后件为真的原因不止一个）。"下雨则地湿；地湿了；⇒ 下过雨？"未必——可能有人洒水。
  • 否定前件谬误：A → B, ¬A ⇒ ¬B。前件为假时蕴含式恒真，结论没有任何保障。"不下雨 ⇒ 地不湿？"显然错。
记住：只有 MP（肯前）和 MT（否后）是合法的，其余两种组合都是谬误。

3.3 构造证明：P 规则与 T 规则

形式化证明的书写格式：

  • P 规则（Premise）：前提可以随时引入。
  • T 规则（Theorem）：由前面已有的公式，经等值演算（⇔）或推理定律（⇒）得到新公式。

例 3.1 证明：¬p ∨ q, ¬q ∨ r, ¬r ⇒ ¬p

(1)  ¬q ∨ r           P（前提）
(2)  ¬r               P
(3)  ¬q               T (1)(2)，析取三段论
(4)  ¬p ∨ q           P
(5)  ¬p               T (3)(4)，析取三段论

每行末尾注明用了哪些行、哪条规则，这是考试的标准格式。整个证明就是一条链：从前提出发，每一步只走一小格，走到结论为止。

例 3.2 符号化并证明：如果小王努力，那么他能通过考试；如果他不努力，那么他会后悔。所以小王或者通过考试，或者后悔。

设 p：小王努力，q：通过考试，r：后悔。前提：(p → q) ∧ (¬p → r)，p ∨ ¬p；结论：q ∨ r。

(1)  (p → q) ∧ (¬p → r)    P
(2)  p ∨ ¬p                P（排中律）
(3)  q ∨ r                 T (1)(2)，构造性二难

这道题展示了"看起来没用的前提"（排中律）如何在关键时刻当桥用。构造性二难的本质就是：把 p ∨ ¬p 拆成两种情况，每种情况各推出一个分结论，再合起来。

3.4 附加前提证明法（CP 规则）

当结论形如 A → B 时，把 A 当作额外前提（附加前提）加入，改为证明 B。合法性来自等值式：

(A1 ∧ … ∧ Ak) → (A → B) ⇔ (A1 ∧ … ∧ Ak ∧ A) → B

例 3.3 蕴含式结论的两种证法对比：证明 p → (p → q), p ⇒ q

证法一：直接证明

(1)  p                 P
(2)  p → (p → q)       P
(3)  p → q             T (1)(2)，MP
(4)  q                 T (1)(3)，MP

证法二：CP 规则。结论 q 不是蕴含式，不能直接用 CP——但若把原题改成结论为 p → q 的版本："证明 p → (p → q) ⇒ p → q"，CP 就登场了：

(1)  p → (p → q)       P
(2)  p                 CP（附加前提）
(3)  p → q             T (1)(2)，MP
(4)  q                 T (2)(3)，MP
(5)  p → q             CP（收回附加前提）

教训：CP 规则只对"结论是蕴含式"的情形使用；使用前先确认推理本身有效（可回真值表或等值演算核查），否则会为无效推理"证明"出一个假结论。

例 3.4 CP 规则的标准示范：证明 p → (q → s), ¬r ∨ p, q ⇒ r → s

(1)  ¬r ∨ p            P
(2)  r                 CP（附加前提）
(3)  p                 T (1)(2)，析取三段论
(4)  p → (q → s)       P
(5)  q → s             T (3)(4)，MP
(6)  q                 P
(7)  s                 T (5)(6)，MP
(8)  r → s             CP（收回附加前提，得证）

3.5 归谬法（反证法）

原理

要证 A1, …, Ak ⇒ B，等价于证 A1, …, Ak, ¬B ⇒ 0（推出矛盾式）。依据：
(A1 ∧ … ∧ Ak) → B ⇔ ¬((A1 ∧ … ∧ Ak) ∧ ¬B)，即"前提 ∧ 结论的否定"必为矛盾式。

例 3.5 用归谬法证明：p → q, ¬r → ¬q, r ⇒ p

追加 ¬p 作为假设：

(1)  ¬p               归谬假设
(2)  p → q            P
(3)  ¬q               T (1)(2)，MT
(4)  ¬r → ¬q          P
(5)  r                T (3)(4)，MT
(6)  r ∧ ¬r           T (5) 与前提 r 合取，矛盾！
(7)  p                归谬法结论成立

有趣的是，第 (5) 步已经直接从前提推出了 r，与假设 ¬p 无关——当直接证明很顺时，归谬法照样能用，矛盾来自"前提自我冲突"或"与假设冲突"均可。

三种方法怎么选
  • 结论是原子命题 → 先试直接证明（MP / MT 链）。
  • 结论是 A → B → CP 规则几乎是首选。
  • 直接证明卡住、前提里有一堆否定式 → 试归谬法。

3.6 推理在真实世界中的样子

程序里的每个 if / assert / 类型检查器都在做形式推理；数据库的约束求解、硬件验证工具（如模型检测）把"程序在一切输入下不崩溃"表达成重言式来机械验证。人工智能早期的"专家系统"（如 MYCIN）就是活着的推理引擎：知识库 = 一堆 A → B，推理机 = MP 循环。本章手工做的证明，正是这些系统每秒做百万次的事情。

3.7 自测题

  1. 判断推理是否有效并说明：p → q, ¬p ⇒ ¬q。
  2. 证明：p ∨ q, p → r, q → s ⇒ r ∨ s。
  3. 用 CP 规则证明：¬p ∨ q, ¬q ∨ r ⇒ p → r。
  4. 符号化并证明：如果 6 是偶数，则 7 被 2 整除；或者 7 不被 2 整除，或者 5 是素数。但 7 不被 2 整除。所以 6 不是偶数，或者 5 是素数。
参考答案（先做再看）
  1. 无效。这是否定前件谬误：取 p=0, q=1，则 p→q=1, ¬p=1，但 ¬q=0。
  2. 直接用构造性二难：(1)(2)(3) P；(4) r ∨ s，T (1)(2)(3) 构造性二难。
  3. (1) ¬p ∨ q P；(2) ¬q ∨ r P；(3) p CP；(4) q T (1)(3) 析取三段论；(5) r T (2)(4) 析取三段论；(6) p → r CP。
  4. 设 p：6 是偶数，q：7 被 2 整除，r：5 是素数。前提：p → q，¬q ∨ r，¬q；结论：¬p ∨ r。证明：(4) r T (2)(3) 析取三段论；(5) ¬p T (1)(3) MT；(6) ¬p ∨ r T (4)(5) 附加+构造性二难（或直接两次附加）。
本章小结：有效推理 = 蕴含式是重言式；只许 MP 与 MT，禁用"肯后""否前"；证明三件套——直接证、CP（结论是蕴含式时）、归谬（卡住时）；书写格式 = 每行标来源与依据。命题逻辑到此闭环，但"所有人都会死，苏格拉底是人"这类推理还写不出来——需要谓词逻辑，见下一章。
