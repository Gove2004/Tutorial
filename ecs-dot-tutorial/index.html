ECS 与 Unity DOTS 入门到精通

从零构建对 ECS（Entity Component System）架构和 Unity DOTS 技术栈的深度理解。不只讲"怎么用"，更深入到 Archetype 内存布局、Burst 编译器后端、Job Scheduler 依赖图等底层机制。

关于本教程：
  • 前置知识：C# 基础、Unity Editor 基本使用、多线程编程概念
  • 学习深度：系统掌握 + 源码级剖析 + 性能调优
  • DOTS 版本：Entities 2.x（Unity 6 / 2023.3+）
  • 主题风格：技术蓝（适合编程/架构类教程）

版本：v1.0 | 更新日期：2026-07-02

适用环境：Unity 6 / Entities 2.2.0 / Burst 1.8 / Job System 3.3

课程目录

基础

01 - ECS 范式革命

为什么 OOP 在游戏开发中遇到瓶颈？ECS 的哲学起源、与 OOP/面向数据编程的对比、GameDev 中数据局部性的重要性。

基础

02 - ECS 三要素深度解剖

Entity 不是对象而是 ID、Component 不是类而是数据 POD、System 不是行为而是数据转换流水线。每个概念的每一个设计决策。

基础

03 - 数据导向设计（DDD）

Cache Line 原理、SoA vs AoS、Struct of Arrays 的内存布局艺术、数据预取、False Sharing 及其消除。

进阶

04 - Unity DOTS 架构全景

Entities 0.x → 2.x 的完整演进史。Hub 架构、Package 依赖关系、World/ECS/Hybrid/Rendering/Baking 六大支柱。

进阶

05 - Burst Compiler 深入

LLVM 后端、SIMD 自动向量化、Loop Unrolling、Function Inlining、JIT 编译时机、Burst 的限制条件与调试。

进阶

06 - Job System 深入

Dependency Graph、JobHandle、NativeArray 生命周期、Barrier、Scheduled vs Execute、Work Stealing。

进阶

07 - ECS 源码级实现

Archetype、Chunk、World 的内部结构。Component Type、Version、GUID 系统。Entity 的 Generation ID 防复用。

高级

08 - ChunkIterator 与并行 Job 模式

ForEach、IJobChunk、IJobEntity。Chunk 遍历的内部原理。Read/Write Group 依赖分析。

高级

09 - Hybrid ECS 与 GameObject 集成

Authoring + Baker 转换管线、GameObjectUtility、Hybrid Renderer V2、何时用 Hybrid、何时全 DOTS。

高级

10 - DOTS 实战：从零构建 Roguelike 地牢

综合应用：Tilemap 生成、实体 AI、战斗系统、渲染管线。从架构设计到性能调优的完整流程。

学习路线建议

1

第一阶段：理解为什么（第 1-3 章）

不写一行代码，彻底理解 ECS 的哲学基础和数据导向设计。这是大多数人跳过但最关键的部分。

2

第二阶段：理解架构（第 4-7 章）

深入 DOTS 的每一个核心子系统。理解 Archetype 内存布局、Burst 编译原理、Job Scheduler 工作机制。

3

第三阶段：实战与混合（第 8-10 章）

掌握并行 Job 模式、Hybrid ECS 转换管线，最终构建一个完整的小游戏项目。

开发环境

  • Unity 版本：Unity 6（2023.3+）推荐，Entities 2.x
  • 必要 Package：Entities、Burst、Jobs、Collections、Mathematics
  • 推荐 Package：Hybrid Renderer V2、Translation Generator、Building Blocks
  • IDE：Visual Studio 2022 / Rider（Rider 对 Burst 调试支持更好）
  • Profiling：Unity Profiler（CPU/Simulation tab）、Frame Debugger、Memory Profiler
