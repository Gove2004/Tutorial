03　数据管线与特征工程

神经网络的输入不是原始 BVH 文件，而是一套经过精心设计的特征向量。本章以 PFNN 建立、后续工作沿用的参数化为主线， 逐维度拆解输入输出，并讲清归一化与数据增强。这套特征设计本身就是仓库的核心贡献之一，重要性不亚于网络结构。

3.2 时间窗口与轨迹采样

用户控制通过一个以当前帧为中心的时间窗口表达。PFNN 的具体设置是：在窗口内每隔 10 帧取一个采样点， 共 t = 12 个点，覆盖过去 1 秒、未来 0.9 秒。每个采样点提取轨迹在水平面（2D）上相对当前帧根坐标的位置与方向。

不同项目的窗口参数

PFNN：t=12，约 1.9 秒窗口；NSM：t=13，覆盖 −1s 到 +1s 的 2 秒窗口；DeepPhase 训练 PAE 时使用 60 Hz 下 前后各 60 帧、共 N=121 个采样点。窗口长度直接决定特征维度，迁移代码时不能混用。

3.3 输入特征向量逐维拆解

PFNN 单帧输入为 x = { tp, td, th, tg, jp, jv }， 各部分维度如下（t=12，j=31）：

符号含义维度说明
tp轨迹位置2t = 24采样点在水平面相对根坐标的位置
td轨迹方向2t = 24采样点朝向相对根坐标的方向（2D）
th轨迹高度3t = 36中心线及左右各 25 cm 处三个点的地形高度
tg语义/步态变量5t = 605 维二值向量，见 3.5
jp上一帧关节位置3j = 93相对根坐标的关节局部位置
jv上一帧关节速度3j = 93相对根坐标的关节局部速度

按 PFNN 的 t=12、j=31 计算，输入向量合计 24+24+36+60+93+93 = 330 维。

3.4 输出特征向量逐维拆解

单帧输出 y 同时包含当前姿态、根运动、相位变化与接触标签：

符号含义维度说明
ti+1p, ti+1d下一帧轨迹位置/方向各 2t网络对未来轨迹的预测，运行时与手柄输入混合
jp, jv关节位置、速度各 3j当前帧相对根坐标的局部量
ja关节角度3j指数映射表示，用于重建关节旋转
rx, rz根平移速度各 1相对朝向的前后/侧向速度
ra根角速度1绕向上轴的转角速度
ṗ相位变化量1运行时累加到相位，自增循环
c足部接触标签4左右脚跟、脚尖是否着地，供 IK 使用

3.5 语义步态变量

tg 的 5 个二值分量分别在以下情形激活：① 站立 ② 行走 ③ 慢跑 ④ 跳跃 ⑤ 蹲伏 （第 5 维同时用于表达天花板高度）。它承担两个作用：消除"快走与慢跑轨迹相同"的歧义；让开发者能强制指定步态。 NSM 把动作类型扩展为 7 类（idle/walk/run/sit/open/carry/climb），并使用连续的 0→1 标签而非硬二值。

3.6 接触标签

接触通过脚关节（脚跟、脚尖）速度幅值低于阈值自动判定，再人工校验。接触标签有两个下游用途：运行时作为 IK 后处理的触发条件（着地时把脚固定到地面），以及在局部相位/码本工作中作为相位提取的原始信号。

3.7 归一化：均值、方差与维度权重

数据先按全量均值与标准差做标准化，再乘以维度权重 xw, yw 调整各维相对重要性。 PFNN 的一个经验性设置是：所有与关节相关的输入维度统一乘以 0.1，压低关节项的影响、抬高轨迹项的权重， 从而让角色对控制更灵敏。

x̃ = xw · (x − xμ) / xσ

AI4AnimationPy 用 RunningStats 实现在线归一化，训练过程中边统计均值方差边标准化，无需预先扫描全量数据：

from ai4animation.AI.Stats import RunningStats

input_stats = RunningStats(dim=input_dim)
input_stats.update(x_batch)
x_norm = input_stats.normalize(x_batch)

y_pred = network(x_norm)
y_out = output_stats.denormalize(y_pred)

3.8 镜像增强

所有动捕都会生成左右镜像版本，数据量直接翻倍，同时保证角色左右动作对称、避免偏向。PFNN 还有一层更重的增强： 把每个运动周期暴力匹配到独立地形数据库中的 10 个最佳地形块，再用 RBF 网格编辑让脚部在接触时精确贴合地面—— 这使最终数据集达到约 400 万个样本点。

3.9 Python 版的特征模块体系

AI4AnimationPy 把特征提取封装成可挂载到 Motion 上的模块，构建 Dataset 时按需组装：

模块职责
RootModule根轨迹：位置、方向、速度
ContactModule足部接触，按关节与速度阈值配置
MotionModule全身轨迹特征
GuidanceModule姿态引导特征
TrackingModule三点 VR 追踪特征
 
Dataset(npz_path, [
    lambda x: RootModule(x, hip_name, left_hip_name, right_hip_name,
                         left_shoulder_name, right_shoulder_name),
    lambda x: MotionModule(x),
    lambda x: ContactModule(x, [
        (left_ankle_name, 0.1, 0.25),
        (left_ball_name, 0.05, 0.25),
        (right_ankle_name, 0.1, 0.25),
        (right_ball_name, 0.05, 0.25),
    ]),
    lambda x: GuidanceModule(x),
])

本章小结

  • 输入由轨迹窗口（位置/方向/高度/语义）与上一帧关节状态构成，PFNN 单帧输入 330 维
  • 输出同时含当前姿态、根速度、相位变化与 4 个接触标签，接触标签驱动 IK 后处理
  • 归一化含均值方差与维度权重，关节项乘 0.1 以提升轨迹主导性；Python 版用 RunningStats 在线统计
  • 镜像翻倍是标配，PFNN 还通过地形拟合把样本扩到约 400 万；特征模块在 Python 版中可插拔组装
