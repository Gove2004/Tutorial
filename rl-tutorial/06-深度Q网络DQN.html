第 6 章 · 当表格装不下：深度 Q 网络（DQN）

Q-learning 很强大，但它用一张表格为每个"状态-动作"单独存一个值。一旦状态是连续的（位置、速度、角度取任意实数）或状态空间极其巨大（一帧游戏画面），表格根本无法枚举。本章用一个带参数的函数（神经网络）去近似 Q，这就是深度 Q 网络（DQN），并讲清让它训练稳定的两大关键设计。

6.1 从表格到函数逼近

不再为每个状态存 Q，而是定义一个由参数 θ 决定的函数 Q(s,a;θ)（一个神经网络），让它对没见过的状态也能根据相似性"泛化"出价值。我们仍沿用 Q-learning 的 TD 目标，只是把"查表更新"换成"调整 θ 让网络输出逼近 TD 目标"，即用梯度下降最小化：

L(θ) = E[ ( r + γ·max_{a′} Q(s′,a′; θ⁻) − Q(s,a; θ) )² ]

这里出现了两个 θ：θ 是正在训练的网络，θ⁻ 是一个"目标网络"的参数——为什么要分开，6.3 解释。

6.2 PyTorch 最小入门（够用即可）

你只需要理解三件事：张量（带梯度的多维数组）、网络（nn.Module，一层层可学习的映射）、自动求导与优化器（loss.backward() 自动算梯度，optimizer.step() 更新参数）。

import torch
import torch.nn as nn

# 一个最小网络：输入 4 维 -> 128 -> 2 个动作的 Q 值
net = nn.Sequential(nn.Linear(4, 128), nn.ReLU(), nn.Linear(128, 2))
x = torch.randn(3, 4)                  # 3 个样本、每个 4 维
q_values = net(x)                      # 输出 3x2：每个样本各动作的 Q
print(q_values.shape)

# 一次最小的梯度更新骨架
target = torch.randn(3, 2)
loss = ((q_values - target) ** 2).mean()
net.zero_grad()
loss.backward()                        # 自动计算每个参数的梯度
opt = torch.optim.Adam(net.parameters(), lr=1e-3)
opt.step()                             # 按梯度更新参数

附录有更完整的 PyTorch 入门（张量操作、维度、常见报错）。现在你只要能看懂"网络吃进状态、吐出各动作 Q 值，再用 loss 反传更新"即可。

6.3 DQN 的两大稳定器（为什么深度版本会"训不稳"）

直接把神经网络塞进 Q-learning 往往会发散，原因是：样本前后高度相关，且 TD 目标本身依赖正在被剧烈更新的网络（像"追一个不断移动的靶子"）。DQN 用两个设计解决：

① 经验回放（Experience Replay）

把每步的转移 (s,a,r,s′,done) 存进一个回放缓冲区，训练时随机采样一个 batch。作用：

  • 数据复用：一条经验可被多次学习（off-policy 的优势），提高样本效率；
  • 打破相关性：随机打散后样本不再是连续高度相关的时序，训练更稳；
  • 它把"采样"和"训练"自然解耦——第 9 章的分布式架构正基于此。

② 目标网络（Target Network）

用一个参数为 θ⁻ 的副本网络来计算 TD 目标 r+γ·max Q(s′;θ⁻)，θ⁻ 被冻结，每隔 N 步才从主网络 θ 复制一次（硬更新）。这样在一段时间内"靶子固定不动"，避免目标随主网络同步摆动导致的震荡。

和第 5 章对照：经验回放让 Q-learning 的 off-policy 特性在深度场景发挥到极致；目标网络就是把第 3 章"引导目标"暂时固定。两者合起来，DQN 才能稳定地从像素学会玩 Atari，开启了深度强化学习的浪潮。

6.4 完整 DQN 案例（CartPole，PyTorch）

下面是完整可运行的 DQN，解决经典的 CartPole（小车推杆，目标是让杆尽量久不倒）。它需要 torch 与 gymnasium：本机安装见附录（注意 Python 版本），也可直接在 Colab/Kaggle 浏览器环境运行，无需配置本机。

import random, numpy as np, torch
import torch.nn as nn
import gymnasium as gym

class QNet(nn.Module):
    def __init__(self, state_dim, n_actions):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, 128), nn.ReLU(),
            nn.Linear(128, 128), nn.ReLU(),
            nn.Linear(128, n_actions))
    def forward(self, x):
        return self.net(x)

class ReplayBuffer:
    def __init__(self, capacity=10000):
        self.buf, self.cap = [], capacity
    def push(self, s, a, r, s2, done):
        self.buf.append((s, a, r, s2, done))
        if len(self.buf) > self.cap: self.buf.pop(0)
    def sample(self, n):
        batch = random.sample(self.buf, n)
        s, a, r, s2, d = zip(*batch)
        return (torch.tensor(np.array(s), dtype=torch.float32),
                torch.tensor(a).view(-1, 1),
                torch.tensor(r, dtype=torch.float32).view(-1, 1),
                torch.tensor(np.array(s2), dtype=torch.float32),
                torch.tensor(d, dtype=torch.float32).view(-1, 1))

env = gym.make("CartPole-v1")
state_dim = env.observation_space.shape[0]
n_actions = env.action_space.n
net = QNet(state_dim, n_actions)
target_net = QNet(state_dim, n_actions)
target_net.load_state_dict(net.state_dict())
opt = torch.optim.Adam(net.parameters(), lr=1e-3)
buffer = ReplayBuffer()

gamma, batch_size, learn_start = 0.99, 64, 500
epsilon, eps_min, eps_decay = 1.0, 0.05, 0.995
reward_history = []

for episode in range(300):
    s, _ = env.reset()
    total, done = 0, False
    while not done:
        if random.random() < epsilon:
            a = env.action_space.sample()
        else:
            with torch.no_grad():
                a = net(torch.tensor(s, dtype=torch.float32)).argmax().item()
        s2, r, term, trunc, _ = env.step(a)
        done = term or trunc
        buffer.push(s, a, r, s2, done)
        s, total = s2, total + r

        if len(buffer.buf) >= learn_start:
            bs, ba, br, bs2, bd = buffer.sample(batch_size)
            with torch.no_grad():
                target = br + gamma * target_net(bs2).max(1, keepdim=True).values * (1 - bd)
            current = net(bs).gather(1, ba)
            loss = ((target - current) ** 2).mean()
            opt.zero_grad(); loss.backward(); opt.step()

    epsilon = max(eps_min, epsilon * eps_decay)
    reward_history.append(total)
    if (episode + 1) % 20 == 0:
        avg = np.mean(reward_history[-20:])
        print(f"第{episode+1}局  近20局平均 {avg:6.1f}  ε={epsilon:.3f}")
    if episode % 20 == 0:                          # 每 20 局硬同步目标网络
        target_net.load_state_dict(net.state_dict())
通关信号：CartPole 每多撑一步得 1 分、满分 500。近 20 局平均分持续上升并逼近 500，即说明 DQN 学会了推杆。和第 5 章一样——奖励曲线上升 = 学到了。

6.5 DQN 家族：针对它的缺陷逐一改进

优先回放 PER
变体解决的问题核心思想
Double DQNQ 值过估计（max 操作系统性偏高）用在线网络选动作、用目标网络估该动作价值，分解 max
Dueling DQN很多状态动作差异不大，不必逐动作估网络分两支：状态价值 V 与动作优势 A，Q=V+A
均匀采样浪费在简单经验上优先采样 TD 误差大的"意外"样本
N-step / Rainbow综合提速与稳定Rainbow 把 Double、Dueling、PER、n-step、分布式价值等组合
深度 RL 调试要点
  • 曲线不动：先缩小问题（少动作、短回合）确认能过拟合一个小场景，再放大。
  • 剧烈震荡：调小学习率、增大 batch、提高目标网络更新间隔、检查奖励是否归一化。
  • 过估计明显（Q 值远超实际回报）：换 Double DQN。
  • 务必保留独立评估（ε=0、固定随机种子），不要只看训练时的分数。

练习与实战

1

把目标网络去掉（直接用主网络算 target），对比训练曲线，直观体会"移动靶"导致的不稳定。

2

把经验回放容量、目标网络同步间隔分别调大调小，记录对收敛速度与稳定性的影响。

3

进阶：把 target 的计算改成 Double DQN 形式，观察估计 Q 值是否更接近真实回报。

本章小结

  • 状态连续或巨大时，用神经网络 Q(s,a;θ) 做函数逼近，并以梯度下降逼近 TD 目标。
  • DQN 两大稳定器：经验回放（复用数据、去相关）与目标网络（固定移动靶）。
  • 完整 DQN 能在 CartPole 上让奖励曲线稳定上升；Double/Dueling/PER/Rainbow 针对其缺陷演进。
