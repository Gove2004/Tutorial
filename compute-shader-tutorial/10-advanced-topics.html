进阶：Ray Tracing 与 Mesh Shader

最后一章不教新算法，而是带你站在更高的视角看 Compute Shader 在整个 GPU 编程生态中的位置。DXR（光线追踪）和 Mesh Shader 代表了现代可编程 GPU 的两大发展方向。

Compute Shader 在现代管线中的角色

传统渲染管线和 Compute Shader 曾经是两条平行线。现代 GPU 正在把它们融合：

传统 DX11 管线：
  Vertex → Geometry → Raster → Fragment → Framebuffer
  Compute Shader（独立通道）

DX12 Ultimate 管线：
  Mesh Shader → Amplification Shader → Ray Tracing Pipeline
  │
  ├─ 光线生成（Compute Shader）
  ├─ 场景更新（Compute Shader）
  ├─ 几何处理（Mesh Shader）
  ├─ 着色（Ray Tracing + Fragment）
  └─ 后处理（Compute Shader）

Compute Shader 不再是"独立通道"，而是现代管线的胶水——
它在每个阶段之间提供数据准备和转换。

DXR：Compute Shader 与光线追踪的结合

DXR（DirectX Ray Tracing）的核心是 BVH（层次包围盒）遍历和光线-三角形相交测试。这两个操作天然适合 Compute Shader：

光线生成（Ray Generation）

每个像素生成一条（或多条）光线，用 Compute Shader 实现：

// 光线生成 Shader（DXR 中的一种 Shader 类型）
// 类似 Compute Shader，但用 [shader("raygeneration")] 标注
[shader("raygeneration")]
void RayGenMain()
{
    uint2 pixelCoord = DispatchRaysIndex().xy;
    uint2 rayDescWidth, rayDescHeight;
    outputTexture.GetDimensions(rayDescWidth, rayDescHeight);

    if (pixelCoord.x < rayDescWidth && pixelCoord.y < rayDescHeight)
    {
        // 根据像素坐标生成光线
        float2 uv = (float2(pixelCoord) + 0.5) / float2(rayDescWidth, rayDescHeight);
        RayDesc ray;
        ray.Origin = cameraPosition;
        ray.Direction = UnpackHalf2x32(rayBuffer[pixelCoord.xy]);
        ray.TMin = 0.0f;
        ray.TMax = 1000.0f;

        // 发射光线
        TraceRay(
            sceneBVH,                          // Acceleration Structure
            RAY_FLAG_NONE,                     // 标志
            0xFF,                              // 掩码
            0, 0, 0,                           // 索引、实例掩码
            ray,                               // 光线描述
            payload                            // 输出载荷
        );

        // 写入颜色
        colorOutput[pixelCoord] = payload.color;
    }
}

Compute Shader 在 DXR 中的辅助角色

除了光线生成，Compute Shader 还负责：

  • BVH 构建：用 Compute Shader 在 GPU 上动态构建 BVH（如 NV 的 OptiX Denoiser 中的 AOVR）
  • 光线过滤：Post-ray-tracing 的 Compute Shader pass 过滤/去噪
  • 场景更新：动画场景的顶点变换用 Compute Shader 在 GPU 上完成
  • 全局光照迭代：光线追踪全局光照（RTGI）的多 bounce 传递

Mesh Shader：取代固定功能几何管线的可编程方案

Mesh Shader（SM 6.5）是 Compute Shader 的"近亲"——它们的语法几乎一样，只是入口点不同：

特性Compute ShaderMesh Shader
输出任意 UAV/SRV图元（三角形/线/点）
线程组织[numthreads(x, y, z)][numthreads(x, y, z)]（相同）
共享内存SharedMemorySharedMemory（相同）
用途通用计算几何处理（置换、细分、LOD）
标注[shader("compute")][shader("mesh")]

Mesh Shader 的入口：

// Mesh Shader 入口
[shader("mesh")]
void MainMesh(
    out Payload payload,
    uint blockThreadId : SV_DispatchThreadID)
{
    // 每个线程块处理一个 "Mesh Block"
    // 可以输出任意数量的顶点/图元

    // 设置输出顶点数
    SetOutputStreamTopology(primTopology);
    SetOutputVertexCount(vertexCount);
    SetOutputPrimitiveCount(primitiveCount);

    // 写入顶点流
    outputStream[positionSemantic].xyz = computeVertexPosition(blockThreadId);
    outputStream[colorSemantic].rgb = computeVertexColor(blockThreadId);

    // 写入索引（定义三角形）
    outputStream[SV_PrimitiveID] = computeTriangleIndices(blockThreadId);
}

Mesh Shader vs Compute Shader：何时用哪个？

如果你需要在 GPU 上生成几何体（比如置换贴图），两种方案都可以：

  • Compute Shader + Indirect Draw：Compute Shader 输出顶点到 Buffer，然后用 DrawIndexedInstancedIndirect 绘制。灵活但需要额外的 Buffer 管理和 Barrier。
  • Mesh Shader：直接在管线内生成几何体，无需中间 Buffer。更高效，但需要 DX12 Level 6.5 支持。
实际选择：如果你的项目只需要通用计算（图像处理、物理模拟、算法加速），Compute Shader 就够了。只有当你需要可编程的几何管线（动态 LOD、GPU 驱动的实例化、实时细分）时，才需要 Mesh Shader。

Compute Shader 的未来方向

Variable Rate Shading (VRS)

VRS 允许你用 Compute Shader 生成"阴影图"，告诉 GPU 哪些区域用高分辨率着色、哪些用低分辨率。这在 VR/AR 中特别有用（foveated rendering）。

Sampler Feedback

SM 6.2 引入的新特性：Compute Shader 可以查询"哪些 mip level 被采样了"，然后按需加载。大幅减少纹理带宽。

Shader Execution Reordering (SER)

NVIDIA RTX 40 系列引入：Compute Shader 可以重新排序后续 Shader 的执行顺序，以提高空间局部性。对光线追踪性能提升显著。

DirectML：Compute Shader 的机器学习方向

DirectML 基于 Compute Shader 构建，让你在 DX12 中运行深度学习推理和训练。这是 Compute Shader 最出人意料的应用方向之一：

  • Real-time Super Resolution：用 AI 将低分辨率图像放大到高分辨率（类似 DLSS）
  • Image Enhancement：去噪、色彩校正、风格迁移
  • Physics Simulation：用神经网络替代物理方程做流体/布料模拟

下一步：你自己的项目

学完这本教程后，你可以尝试以下项目来巩固所学：

1

入门项目：图像后处理管线

实现一个完整的 HDR 渲染管线：ACES 色调映射 → 高斯模糊（Bloom） → Sobel 边缘检测（Outline） → 最终合成。每个效果都是一个独立的 Compute Shader Pass。

2

中级项目：流体模拟

实现 Jos Stam 的 Stable Fluids 算法。用 Compute Shader 做 Advection + Diffusion + Pressure Solve（Pressure Solve 需要 Prefix Sum 或 Jacobi Iteration）。这是 GPU 计算最经典的应用之一。

3

高级项目：GPU 驱动的粒子世界

100 万粒子，每个粒子有位置、速度、颜色、生命周期。用 Spatial Hash 做碰撞检测，用 GPU Instancing 渲染，用 Compute Shader 做物理模拟和渲染的统一循环。这是 Chapter 6+7+8 的综合应用。

4

终极项目：实时光线追踪全局光照

用 DXR + Compute Shader 实现实时 RTGI。Compute Shader 生成光线、BVH 构建、Denoiser。这是现代游戏引擎（UE5、Unity HDRP）的核心技术栈。

结语

Compute Shader 是 GPU 编程中最基础、最通用的接口。学会了它，你就打开了 GPU 加速计算的大门——无论是图像处理、物理模拟、算法加速还是机器学习推理，底层都是 Compute Shader 的思想。

记住本章开头的优化方法论：先测量，再优化。GPU 的行为往往违反直觉，只有 Profiler 说的是真话。
