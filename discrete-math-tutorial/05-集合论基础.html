05 - 集合论基础

本章目标：分清 ∈ 与 ⊆；掌握集合运算及其运算律；会求幂集；熟练使用包含排斥原理（2 个和 3 个集合的情形）；理解笛卡尔积。

5.1 集合与隶属

定义 5.1（集合）

集合是由确定、互异、无序的对象构成的整体。记号：∈ 表示属于（元素与集合之间），⊆ 表示包含（集合与集合之间）。空集 ∅、全集 E（讨论范围内所有对象）是两个特殊集合。

第一组易错：∈ 与 ⊆
  • 1 ∈ {1, 2} ✓；{1} ∈ {1, 2} ✗；{1} ⊆ {1, 2} ✓。集合的元素可以是集合，层次要数清楚。
  • 空集悖论两连问：∅ ⊆ A 对任意 A 成立（子集定义用 ∀x∈∅… 空真）；∅ ∈ A 则不一定，只有 ∅ 是 A 的元素时才成立。
  • {∅} 不是 ∅：{∅} 有一个元素（就是 ∅），|{∅}| = 1 而 |∅| = 0。
  • 判断 A ⊆ B 的标准方法：∀x(x∈A → x∈B)。注意"⊆"允许相等；要表达真子集用 ⊂。

两个集合相等 ⇔ 互相包含（外延公理）。这是证明 A = B 的标准套路：分别证 A ⊆ B 与 B ⊆ A，每一步都是"任取 x∈A，推导 x∈B"。

5.2 集合运算与运算律

定义 5.2（基本运算）

  • 并 A ∪ B = {x | x∈A ∨ x∈B}
  • 交 A ∩ B = {x | x∈A ∧ x∈B}
  • 相对补 A − B = {x | x∈A ∧ x∉B}；绝对补 ~A = E − A
  • 对称差 A ⊕ B = (A − B) ∪ (B − A) = (A ∪ B) − (A ∩ B)

看到这些"或/且/非"了吗？集合运算和第 1 章的联结词是同一个东西的两种皮：∪↔∨，∩↔∧，~↔¬，⊆↔→，=↔↔。所以第 2 章的等值律全部平移过来成为集合运算律——德摩根律 ~(A∪B) = ~A∩~B、吸收律 A∪(A∩B) = A，等等。掌握这个对应，运算律不用重背。

例 5.1 证明 A ⊆ B ⇔ A ∪ B = B ⇔ A ∩ B = A

"⊆ 的三个等价说法"是集合论证明的常用跳板。以第一对为例：若 A ⊆ B，任取 x∈A∪B，则 x∈A 或 x∈B；前者由 ⊆ 推出 x∈B，两况都有 x∈B，故 A∪B ⊆ B；反方向显然。逆命题：由 A∪B = B，任取 x∈A，则 x∈A∪B = B，即 A ⊆ B。∎

5.3 幂集：集合的集合

定义 5.3（幂集）

A 的幂集 P(A) = { S | S ⊆ A }，即 A 的全部子集构成的集合。|P(A)| = 2|A|。

例 5.2 求 P({1, {2, 3}})

该集合有 2 个元素：1 和 {2, 3}，所以幂集有 2² = 4 个元素：
P = { ∅, {1}, {{2, 3}}, {1, {2, 3}} }。
注意 {2, 3} 是一个整体参与的子集构造——把 {2, 3} 当成 2 和 3 来处理是最常见的失分点。

幂集与二进制的对应：给 |A| = n 的元素编上 0 到 n−1 号，每个子集对应一个 n 位二进制串（第 i 位 = 1 表示第 i 号元素在子集中）。枚举 0 到 2n−1 的所有整数 = 枚举全部子集。这正是编程中"状态压缩"（bitmask DP）的数学基础，也是第 15 章计数原理的实例。

5.4 文氏图与包含排斥原理

两个/三个集合的运算关系可以画成文氏图：全集是方框，每个集合是一个圆，|A ∪ B| 拆成三个互不重叠的区域。数区域的思想就是包含排斥原理：

定理 5.1（包含排斥原理）

|A ∪ B| = |A| + |B| − |A ∩ B|

|A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|

直观理解：并起来数的时候，两两重叠的部分被数了两次，要减掉一次；但三个的重叠部分先被加 3 次、再被减 3 次，变成 0 次，所以最后要加回来。n 个集合的版本符号是 ± 交替的，n 个集合时符号为 (−1)k+1。

例 5.3 经典调查题

某班 40 人，喜欢数学的 25 人，喜欢物理的 20 人，两科都喜欢的 12 人。求：(1) 至少喜欢一科的人数；(2) 两科都不喜欢的人数。

(1) |M ∪ P| = 25 + 20 − 12 = 33。
(2) 全集 40，都不喜欢 = 40 − 33 = 7。

进阶版再加一科"英语 18 人，同时喜欢三门 6 人，同时喜欢数学和英语 8 人，物理和英语 7 人"：|M∪P∪E| = 25+20+18−12−8−7+6 = 42 > 40？矛盾——说明题目给的数据内部不一致（或有人数超了），这正是包含排斥原理的"校验"用法：算出负数或超过全集，就能断定数据有问题。

5.5 笛卡尔积

定义 5.4（有序对与笛卡尔积）

  • 有序对 <a, b>：顺序有意义，<a,b> = <c,d> ⇔ a=c 且 b=d。
  • 笛卡尔积 A × B = { <x, y> | x∈A ∧ y∈B }。
  • 一般不满足交换律：A × B ≠ B × A；|A × B| = |A|·|B|。

坐标平面 ℝ × ℝ = ℝ² 就是笛卡尔积最眼熟的例子。更重要的是它的"继任者"：A × B 的任何子集称为从 A 到 B 的二元关系——下一章的主角。

5.6 自测题

  1. 判断：∅ ⊆ {∅} 与 ∅ ∈ {∅} 哪个成立？P(P(∅)) 有几个元素？
  2. 求 {1, 2} × {1, 2, 3} 的元素个数，并写出其中 3 个元素。
  3. 用等值演算思想证明：( A ∪ B ) − C = (A − C) ∪ (B − C)。
  4. 100 名学生中，选 Java 的 45 人，选 Python 的 58 人，两门都选的 20 人，两门都没选的多少人？
  5. 证明：若 A ⊕ B = A ⊕ C，则 B = C（提示：两边同时 ⊕ A，利用 A ⊕ A = ∅ 与 ∅ 是对称差单位元）。
参考答案（先做再看）
  1. 两个都成立（{∅} 的唯一元素恰是 ∅）。P(∅) = {∅} 有 1 个元素，故 P(P(∅)) = P({∅}) = {∅, {∅}} 有 2 个元素。
  2. 2 × 3 = 6 个。如 <1,1>、<1,3>、<2,2>（顺序对在前集合）。
  3. ( A∪B ) − C = (A∪B) ∩ ~C = (A∩~C) ∪ (B∩~C) = (A−C) ∪ (B−C)。核心是"减法改交补 + 分配律"，与逻辑德摩根完全平行。
  4. |J ∪ P| = 45 + 58 − 20 = 83，都没选 = 100 − 83 = 17 人。
  5. 对称差满足结合律且 A⊕A = ∅、A⊕∅ = A。于是 B = ∅⊕B = (A⊕A)⊕B = A⊕(A⊕B) = A⊕(A⊕C) = C。这个"消去律"说明对称差让 P(全集) 成为一个群——为第 9、10 章埋下伏笔。
本章小结：∈ 管"是不是元素"，⊆ 管"是不是子集"；集合运算律 = 逻辑等值律换皮；幂集 2n 个元素，对应二进制枚举；包含排斥原理 = 数重叠区域的加减法；笛卡尔积是"有序版乘法"，其子集就是二元关系。下一章正式展开关系理论。
