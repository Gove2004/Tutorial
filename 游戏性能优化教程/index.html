游戏性能优化实战教程

从 15 个一线优化策略出发，理解引擎与业务模块的性能特征，最终建立“可量化、可分析、可复用”的持续性能优化工程体系。案例以移动端 MOBA（《王者荣耀》）为原型，代码示例基于 Unity / C#。

内容来源：本教程在腾讯《王者荣耀》客户端工程师陆泽西的技术分享《游戏性能分析与挖掘》基础上重构、扩写而成。原文是讲座纪要，本教程补充了原理推导、可运行代码、边界条件、排查流程与练习，章节结构按学习路径重新组织，而非照搬原文顺序。
关于本教程
  • 面向读者：有 Unity 或其他商业引擎使用经验、能阅读 C# 代码的客户端开发者；也适合需要与客户端协作的技术美术、QA 与性能专项工程师。
  • 学习目标：学完后能独立完成一次真机性能采集、定位瓶颈模块、给出并验证优化方案，而不是只会背“减少 Draw Call”这类口号。
  • 深度定位：系统掌握级。覆盖核心机制、常见场景、生产陷阱与权衡；不做源码级引擎逆向，也不是入门速成。
  • 视觉风格：tech 技术蓝，代码块支持一键复制，流程图使用 Mermaid 渲染。

课程目录

模块一：基础与度量

基础

01 - 导论：性能优化全景图

性能优化的真实目标与三层能力模型；性能问题的业务代价；本课程的知识地图与学习方法。

基础

02 - 核心指标与性能预算

为什么用帧时间而非平均 FPS；Draw Call、Overdraw、面数、内存等指标的准确含义；如何制定性能预算。

基础

03 - 渲染管线与线程模型

一帧之内 CPU 与 GPU 各自做了什么；主线程、渲染线程与 Worker 线程的协作；CPU 瓶颈与 GPU 瓶颈的判定。

模块二：优化策略实战

进阶

04 - 动静分离与 LOD 分级体系

动静分离的更新策略；LOD 从模型扩展到 UI、动画、特效与管线；设备分档与切换抖动的处理。

进阶

05 - Draw Call 与合批优化

Draw Call 贵在哪里；静态合批、动态合批、GPU Instancing、SRP Batcher 的适用边界；自定义动态合批的工程实现。

进阶

06 - UI 性能优化专题

UGUI Canvas 重建机制与 Canvas 拆分；3D UI、UI 渲染管线分离；字体描边、UI Overdraw 与图集治理。

进阶

07 - 动态自适应与特效分级

战斗强度驱动的质量自适应状态机；特效五级分类与裁剪；粒子离线裁剪与凸包算法。

进阶

08 - 寻路优化

A* 的成本结构；路径权重、区域分块、离线路径与跳点寻路（JPS）；动态障碍与路径平滑的陷阱。

高级

09 - 距离场碰撞优化

把碰撞计算搬到离线阶段：距离场的生成算法、运行时查询、角色半径与碰撞方向判定，以及适用边界。

进阶

10 - 场景加载、纹理与内存优化

异步加载与空间优先级；Mipmap 与纹理治理；Model 延迟加载；对象池、内存碎片与启动内存压力。

高级

11 - 阴影、动画与引擎管线定制

面片阴影替代实时 Shadow Map；动画 Job System 与距离分帧；“业务层关闭 ≠ 引擎层停止”与管线定制。

模块三：模块特征地图

进阶

12 - 业务与引擎模块特征地图

UI、网络同步、技能、地图与内存、渲染、动画、粒子、UI 内核八大模块的架构特征与各自的典型性能问题。

模块四：分析方法与体系

高级

13 - 微观分析四板斧与八大维度

标准分析、差异分析、相关性分析、排除法；渲染、动画、逻辑、线程、IO、内存、UI、特效八大维度检查表。

高级

14 - 持续优化体系与综合实战

性能标准、数据采集、自动化测试与 CI 接入；一次团战卡顿的完整排查案例；优化效果验证与深入学习路径。

推荐学习方式

  • 顺序学习：第 1–3 章是后续所有内容的语言基础，指标概念没建立时直接看策略容易误用。
  • 动手验证：每章代码尽量在自己的工程里跑一遍，用 Profiler 对照测量前后差异——没有测量的优化只是猜测。
  • 完成练习：每章末尾有基础练习、进阶挑战与思考题，建议至少完成其中一项再进入下一章。
