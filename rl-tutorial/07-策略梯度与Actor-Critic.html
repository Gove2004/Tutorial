第 7 章 · 策略梯度与 Actor-Critic

前两章走的是"价值函数"路线：先学每个动作值多少分，再间接触发最优动作。本章换一条更直接的主线——直接对策略本身做优化：好动作把它的概率调高，坏动作调低。这条路线天然支持随机策略和连续动作，最终与价值函数结合，形成强大的 Actor-Critic 框架。

7.1 为什么需要直接学策略

  • 连续动作空间：方向盘转角、机械臂关节角可取任意实数，无法对无穷多个动作做 max，价值函数路线难以直接选择。
  • 需要随机策略：石头剪刀布、博弈中，最优行为本身就是概率分布；确定性策略会被对手克制。
  • 更平滑的优化：直接朝"提高期望回报"的方向调整策略，有时比先拟合价值再间接推导更稳定、自然。

7.2 把策略参数化，并定义优化目标

设策略由参数 θ 决定，写成概率形式 πθ(a|s)。我们要最大化的是期望回报：

J(θ) = Eτ~πθ [ R(τ) ]

难点在于：奖励 R 不显式依赖 θ，θ 是通过改变动作分布、进而改变采样到的轨迹来影响回报的，无法直接求导。策略梯度定理给出了答案（这里只讲直觉）：

∇θ J(θ) = E[ ∇θ log πθ(aₜ|sₜ) · Gₜ ]

这条公式的直觉（务必理解）

  • ∇θ log πθ(a|s) 指向"让动作 a 在状态 s 下概率增大"的参数方向；
  • 乘以回报 Gₜ：若这个动作带来了高回报，就沿该方向增大其概率；若回报低/为负，就减小其概率；
  • 取期望（在大量样本上平均）保证方向无偏。这就是"试错 + 奖惩"在数学上的精确表达。

7.3 REINFORCE：最朴素的策略梯度

REINFORCE 直接落地上面的公式：用当前策略跑完一整个回合，然后对每个动作，按它之后的真实回报 Gₜ 更新：

θ ← θ + α · ∇θ log πθ(aₜ|sₜ) · Gₜ

它简单、无偏，但方差很大：回报受整条随机轨迹影响，波动剧烈，训练不稳定。如何降方差是接下来的主线。

7.4 用基线降方差：从回报到"优势"

关键观察：我们真正关心的不是"绝对回报"，而是"这个动作比该状态下的平均水平好多少"。引入一个与动作无关的基线 b(s)，用 Gₜ − b(s) 替代 Gₜ：

∇J = E[ ∇ log π(a|s) · (Gₜ − b(s)) ]

数学上可以证明，只要 b 不依赖动作，期望梯度不变（仍无偏），但方差显著降低。最自然的基线就是状态价值 V(s)。于是定义优势函数（advantage）：

A(s,a) = Q(s,a) − V(s)　（直觉：动作 a 比"平均发挥"好多少）

7.5 Actor-Critic：让价值网络当"评委"

REINFORCE 用完整回报（无偏但高方差、要等回合结束）。我们让一个评论家（Critic）网络实时估计价值 V(s)，用引导得到低方差的优势；演员（Actor）网络则按优势更新策略：

  • Critic：学 V(s)，最小化 TD 误差（r+γV(s′)−V(s)）²；
  • Actor：按优势更新，∇J ≈ ∇log π(a|s)·A(s,a)。

最简单的 TD 优势（一步）为 A = r + γV(s′) − V(s)。两个角色常共享同一个主干网络，一个头输出动作概率、一个头输出状态价值。

名字的由来：Actor（演员）负责"表演"即选动作，Critic（评论家）负责"打分"即评估好坏；演员根据评论家的意见改进。这把第 6 章的价值估计和本章的策略优化合二为一，是现代深度 RL 最主流的结构（PPO、SAC 等都是它的发展）。

7.6 GAE：在偏差与方差之间精细折中

一步 TD 优势方差小但有偏差（只看一步），完整回报无偏但方差大。广义优势估计（GAE）用参数 λ 在两者间做指数加权平滑。先定义 TD 残差 δₜ，再累加：

δₜ = rₜ + γV(sₜ₊₁) − V(sₜ)
A^GAEₜ = δₜ + (γλ)δₜ₊₁ + (γλ)²δₜ₊₂ + …

λ=0 退化为一步 TD（低方差、有偏），λ=1 接近蒙特卡洛回报（无偏、高方差）；常用 λ=0.95。这与第 2 章 γ、第 4 章 n-step 是同一套"看多远"的权衡思想。

7.7 完整案例：n-step Actor-Critic（CartPole，PyTorch）

下面是结构完整的 Actor-Critic：一个网络同时输出动作分布与状态价值；每次收集一段 rollout，用引导回报计算优势，同时更新演员与评论家，并加入熵正则鼓励探索。需要 torch 与 gymnasium（安装见附录，也可用 Colab）。

import numpy as np, torch
import torch.nn as nn
from torch.distributions import Categorical
import gymnasium as gym

class ActorCritic(nn.Module):
    def __init__(self, state_dim, n_actions):
        super().__init__()
        self.shared = nn.Sequential(
            nn.Linear(state_dim, 128), nn.Tanh())
        self.actor = nn.Linear(128, n_actions)   # 动作 logits
        self.critic = nn.Linear(128, 1)          # 状态价值 V
    def forward(self, x):
        h = self.shared(x)
        return Categorical(logits=self.actor(h)), self.critic(h)

env = gym.make("CartPole-v1")
model = ActorCritic(env.observation_space.shape[0], env.action_space.n)
opt = torch.optim.Adam(model.parameters(), lr=7e-4)
gamma, n_steps, vf_coef, ent_coef = 0.99, 20, 0.5, 0.01
history = []

for episode in range(200):
    s, _ = env.reset()
    done, total = False, 0
    while not done:
        S, LP, V, R = [], [], [], []
        for _ in range(n_steps):                 # 收集一段 rollout
            x = torch.tensor(s, dtype=torch.float32)
            dist, value = model(x)
            a = dist.sample()
            s2, r, term, trunc, _ = env.step(a.item())
            done = term or trunc
            S.append(s); LP.append(dist.log_prob(a)); V.append(value)
            R.append(r); total += r
            s = s2
            if done: break

        # 用最后状态的 V 作为引导起点，反向算 n-step 回报
        with torch.no_grad():
            last_v = 0 if done else model(
                torch.tensor(s, dtype=torch.float32))[1].item()
        returns, G = [], last_v
        for r in reversed(R):
            G = r + gamma * G
            returns.insert(0, G)
        returns = torch.tensor(returns).view(-1, 1)
        values = torch.cat(V).view(-1, 1)
        logps = torch.stack(LP)
        advantage = (returns - values).detach()

        policy_loss = -(logps * advantage).mean()
        value_loss = ((returns - values) ** 2).mean()
        # 重新前向以计算熵
        dist, _ = model(torch.tensor(np.array(S), dtype=torch.float32))
        entropy = dist.entropy().mean()
        loss = policy_loss + vf_coef * value_loss - ent_coef * entropy

        opt.zero_grad(); loss.backward()
        nn.utils.clip_grad_norm_(model.parameters(), 0.5)
        opt.step()

    history.append(total)
    if (episode + 1) % 20 == 0:
        print(f"第{episode+1}局  近20局平均 {np.mean(history[-20:]):6.1f}")
通关信号：近 20 局平均分稳定上升、逼近 500。注意这里动作是按概率采样（不再是 ε-greedy），探索来自策略本身的随机性与熵正则——这是策略梯度路线与 DQN 的显著区别。

练习与实战

1

去掉 Critic、改用完整回报 G 更新（退化为 REINFORCE），比较训练波动，体会基线降方差的作用。

2

把优势计算改为 GAE（λ=0.95），对比一步 TD 优势下的收敛稳定性。

3

调熵正则系数（0、0.01、0.05），观察策略过早"确定化"导致的表现下降。

本章小结

  • 策略梯度直接最大化期望回报：∇J=E[∇logπ(a|s)·G]，高回报动作概率调高。
  • REINFORCE 无偏但高方差；用与动作无关的基线（V）构造优势 A=Q−V，可无偏地降方差。
  • Actor-Critic 让 Critic 用引导估价值、Actor 按优势更新策略；GAE 用 λ 折中偏差与方差。
