第 9 章 字符串

字符串题的难点不在“处理字符”，而在“在长文本里快速找到某个模式”。哈希、字典树、KMP、AC 自动机、 后缀数组，这五个工具解决的是同一件事的不同层次：从“判断两个串是否相同”，到“一次扫描匹配多个模式”。

学完本章，你应该能做到

  • 用字符串哈希在 O(1) 内判断两个子串是否相等，并知道单哈希会被卡的原因；
  • 用数组实现字典树，统计前缀单词数量；
  • 独立写出 KMP 的 next 数组，并解释它为什么能避免回溯；
  • 说清 AC 自动机 = 字典树 + fail 指针，理解它相对多次 KMP 的优势；
  • 用倍增法求后缀数组，知道 height 数组能解决什么。

9.1 字符串基本操作

C++ 里用 std::string 就够了：size()、substr(pos, len)、find(s)、 + 拼接、reverse、== 比较。竞赛里需要留意的只有几个点：

  • find 返回的是 size_t，找不到时返回 string::npos，别和 -1 直接比较；
  • getline 前如果读过 cin >>，要 cin.ignore() 吃掉残留的换行；
  • 字符与数字互转用 '0' + d 与 c - '0'，不要用 atoi 这类带异常的接口。
string s = "hello";
cout << s.size() << endl;              // 5
cout << s.substr(1, 3) << endl;         // ell
if (s.find("ll") != string::npos) cout << "found" << endl;
reverse(s.begin(), s.end());           // olleh

典型入门题：HDU 5007（子串查找）、HDU 1238（多个字符串的最大公共子串）、 HDU 2055（字符与数字转换）、HDU 5938（字符串与数字转换）。

9.2 字符串哈希

问题：要在一堆字符串里快速查找某个字符串（HDU 2648 就是这类）。用 map 可以， 但字符串比较是 O(长度)。哈希的思路是：把字符串映射成一个整数，之后只比整数。

理想情况是“完美哈希”：不同字符串映射到不同整数，绝不冲突。但这要求值域不小于字符串总数， 实际上做不到。所以做法是取模到 [0, N)，冲突用额外结构解决（链地址法或开放寻址）。 

// BKDRHash：最常用的字符串哈希
unsigned int BKDRHash(char* str) {
    unsigned int seed = 131, hash = 0;
    while (*str) hash = hash * seed + (*str++);
    return hash & 0x7FFFFFFF;              // 去掉符号位
}

// 子串哈希（常用写法）：预处理前缀哈希与幂
const int BASE = 131;
unsigned long long h[MAXN], p[MAXN];

void init(string s) {
    int n = s.size();
    p[0] = 1;
    for (int i = 1; i <= n; i++) {
        h[i] = h[i - 1] * BASE + (s[i - 1] - 'a' + 1);
        p[i] = p[i - 1] * BASE;
    }
}
// 子串 [l, r]（1 下标）的哈希：
// h[r] - h[l-1] * p[r-l+1]
单哈希会被卡。Codeforces 上存在专门针对 BASE=131、模 264 的构造数据。 稳妥做法是双哈希：用两组不同的底数和模数（如 1e9+7 与 1e9+9），两个值都相等才认为相等。 代价是多一倍常数。

常见哈希函数有 BKDRHash、APHash、DJPHash、JSHash。竞赛里 BKDRHash 用得最多， 选一个奇数底数（131、13331）就能让冲突概率足够低。

9.3 字典树（Trie）

字典树把字符串按字符逐层挂到树上，公共前缀共享同一条路径。查询一个前缀对应的单词数量，就是走到那个节点、 返回它的计数。插入与查询都是 O(长度)。 

int trie[MAXN][26];      // 下标是节点编号，第二维是字符
int num[MAXN];           // 以该节点结尾的单词数量
int pos = 1;             // 当前新分配的节点

void Insert(char str[]) {
    int p = 0;
    for (int i = 0; str[i]; i++) {
        int n = str[i] - 'a';
        if (trie[p][n] == 0) trie[p][n] = pos++;    // 没有这条边就新建节点
        p = trie[p][n];
        num[p]++;                                   // 经过该节点的单词 +1
    }
}

int Find(char str[]) {                              // 返回以该串为前缀的单词数
    int p = 0;
    for (int i = 0; str[i]; i++) {
        int n = str[i] - 'a';
        if (trie[p][n] == 0) return 0;               // 断了，说明没有这个前缀
        p = trie[p][n];
    }
    return num[p];
}
空间是硬约束。trie[MAXN][26] 是 int，节点数 × 26 × 4 字节。 106 个节点就要 100MB 以上，会 MLE。节点多时改用 map<int,int> 存边或压缩成邻接表。

9.4 KMP：单模式匹配

在长度 n 的文本串中找一个长度 m 的模式串。朴素做法是逐位比较，最坏 O(nm)——例如文本是 aaaa…a、模式是 aaa…ab，每次都要比到最后一个字符才发现不对。

KMP 的核心是 next 数组（也叫前缀函数）：next[i] 表示“模式串前 i 个字符中， 最长的既是前缀又是后缀的长度”。失配时不用回退文本指针，而是把模式指针跳到 next[j]， 从而复用已经匹配的部分。总复杂度 O(n+m)。 

// 求 next 数组（模式串 pat，长度 m，下标从 0 开始）
void getNext(char* pat, int m, int* nxt) {
    nxt[0] = -1;
    int j = 0, k = -1;
    while (j < m) {
        if (k == -1 || pat[j] == pat[k]) {
            j++; k++;
            nxt[j] = k;
        } else {
            k = nxt[k];                  // 回退到更短的前后缀
        }
    }
}

int kmp(char* txt, char* pat) {          // 返回第一次出现的位置，找不到返回 -1
    int n = strlen(txt), m = strlen(pat);
    int nxt[MAXM];
    getNext(pat, m, nxt);
    int i = 0, j = 0, cnt = 0;
    while (i < n) {
        if (j == -1 || txt[i] == pat[j]) { i++; j++; }
        else j = nxt[j];                 // 失配：模式串右滑，文本指针不动
        if (j == m) { cnt++; j = nxt[j]; }   // 找到一个匹配，继续找下一个
    }
    return cnt;
}
next 的直观含义：模式串 ababaca 的 next 是 [-1,0,0,1,2,3,0,1]。当在第 6 位失配时，说明前 5 位 ababa 已经匹配， 而它的最长公共前后缀是 aba，所以可以直接把模式串滑到第 3 位继续比，不必从头来。

KMP 的常见扩展：求所有出现位置（每次匹配成功后 j = nxt[j]）、 求最小循环节（m − nxt[m]）、HDU 2594 那种“原串每个后缀与模式串的最长公共前缀”的变形。

9.5 AC 自动机：多模式匹配

有 k 个模式串、一个长文本，要找出所有模式串出现的位置。对每个模式串跑一次 KMP 是 O((n+m)k)， k 大时不可接受。AC 自动机（Aho–Corasick）的思路是：把所有模式串建成一棵字典树， 再在树上加“失配指针”，使得扫描文本时只走一遍。

结构

字典树负责存所有模式串；fail 指针负责在失配时跳到“最长的、仍是某个模式串前缀的后缀”。 fail 指针的求法本质是把 KMP 的 next 思想放到树上做 BFS。

int trie[MAXN][26], fail[MAXN], cnt[MAXN], tot;

void insert(char* s) {                       // 建字典树
    int p = 0;
    for (int i = 0; s[i]; i++) {
        int c = s[i] - 'a';
        if (!trie[p][c]) trie[p][c] = ++tot;
        p = trie[p][c];
    }
    cnt[p]++;                                // 该节点是一个模式串的结尾
}

void build() {                               // BFS 求 fail 指针
    queue<int> q;
    for (int c = 0; c < 26; c++)
        if (trie[0][c]) { fail[trie[0][c]] = 0; q.push(trie[0][c]); }
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int c = 0; c < 26; c++) {
            int v = trie[u][c];
            if (v) {
                fail[v] = trie[fail[u]][c];   // 沿着父亲的 fail 走一步
                q.push(v);
            } else {
                trie[u][c] = trie[fail[u]][c]; // 路径压缩：直接连到 fail 的对应儿子
            }
        }
    }
}

int query(char* s) {                         // 扫描文本，统计匹配的模式串数
    int p = 0, ans = 0;
    for (int i = 0; s[i]; i++) {
        p = trie[p][s[i] - 'a'];
        for (int t = p; t && cnt[t] != -1; t = fail[t]) {
            ans += cnt[t];
            cnt[t] = -1;                     // 同一个模式串只统计一次
        }
    }
    return ans;
}

复杂度：建 trie O(km)，建 fail 指针 O(km)，匹配 O(nm)——乘 m 是因为统计时要沿着 fail 链回溯。 相比 k 次 KMP 的 O((n+m)k)，当 m ≪ k 时优势明显。模板题是 HDU 2222 “Keywords Search”。

两个细节： ① trie[u][c] = trie[fail[u]][c] 这一步会“改写”原本为空的边，让匹配时不用反复跳 fail， 但会破坏原始 trie 结构，插入必须在 build 之前全部完成； ② 统计时把 cnt[t] 置为 -1 是为了去重，题目要求“重复关键词只统计一次”时必要。

9.6 后缀数组

后缀数组（Suffix Array）把字符串的所有后缀按字典序排序，记录排名。配合 height 数组（相邻后缀的 LCP）， 能在 O(n log n) 预处理后回答大量子串问题。

构造用倍增法：先按长度为 1 的子串排序，再按长度 2、4、8… 合并排序， 每轮用上一轮的排名作为关键字。总复杂度 O(n log2 n)（用 sort）或 O(n log n)（用基数排序）。 

int sa[MAXN], rk[MAXN], oldrk[MAXN], n;

bool cmp(int i, int j, int w) {
    if (oldrk[i] != oldrk[j]) return oldrk[i] < oldrk[j];
    return oldrk[i + w] < oldrk[j + w];
}

void buildSA(string s) {
    n = s.size();
    for (int i = 0; i < n; i++) { sa[i] = i; rk[i] = s[i]; }
    for (int w = 1; w < n; w <<= 1) {
        for (int i = 0; i < n; i++) oldrk[i] = rk[i];
        sort(sa, sa + n, [w](int i, int j) { return cmp(i, j, w); });
        int p = 0;
        rk[sa[0]] = 0;
        for (int i = 1; i < n; i++)
            rk[sa[i]] = cmp(sa[i], sa[i - 1], w) ? p : ++p;   // 相同则排名不变
        if (p == n - 1) break;                                // 已经全部区分开
    }
}

height[i] = LCP(sa[i-1], sa[i]) 可以用一个性质线性求出： height[rank[i]] ≥ height[rank[i-1]] − 1。有了它，任意两个后缀的 LCP 就是区间最小值， 再配一个 RMQ（第 5 章的线段树或 ST 表）就能 O(1) 查询。

后缀数组的典型应用：最长重复子串、不同子串个数（n(n+1)/2 − Σheight）、 最长公共子串（把两个串拼起来中间加分隔符）。

后缀数组的 height 数组有什么用？相邻后缀的 LCP，配合 RMQ 求任意两后缀的 LCP
