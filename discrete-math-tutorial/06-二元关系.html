06 - 二元关系

本章目标：用集合、矩阵、关系图三种方式表示关系；掌握复合与逆运算；熟练判定五大性质（自反、反自反、对称、反对称、传递）；会求闭包，理解 Warshall 算法。

6.1 关系：笛卡尔积的子集

定义 6.1（二元关系）

设 A、B 为集合，A × B 的任何子集称为从 A 到 B 的二元关系；当 A = B 时称为 A 上的关系。记 <x, y> ∈ R 为 xRy。

关系是离散数学的"万能连接件"：数据库的表（两列的序偶集合）、函数（特殊关系）、等价关系（分类）、偏序（排序）、图（边集就是关系）全是关系。|A × A| = n²，因此 n 元集合上共有 2n² 个不同的关系——关系也是一种"布尔状态"，每个序偶要么在要么不在。

例 6.1 一个具体关系的三种表示

设 A = {1, 2, 3, 4}，R = 整除关系（xRy ⇔ x | y）。展开：R = {<1,1>, <1,2>, <1,3>, <1,4>, <2,2>, <2,4>, <3,3>, <4,4>}。

关系矩阵 MR（行 = 左元，列 = 右元，1 表示相关）：

6.2 复合与逆

定义 6.2（复合与逆关系）

  • 复合 R∘S = { <x, z> | ∃y(<x,y>∈R ∧ <y,z>∈S) }——先走 R 再走 S。
  • 逆关系 R−1 = { <y, x> | <x, y> ∈ R }——矩阵转置、关系图反向。
注意记号顺序：不同教材记号不同，屈婉玲教材中 R∘S 表示"左关系先作用"。做题前先看清楚教材约定，方向搞反复合题必错。复合满足结合律：(R∘S)∘T = R∘(S∘T)，所以可以谈 R 的幂 Rn。

定理 6.1（矩阵视角的复合）

MR∘S = MR · MS（布尔乘法：乘 = ∧，加 = ∨）。MRn 的 (i, j) 元 = 1 ⇔ 从 i 到 j 存在长度恰为 n 的通路。这个事实把"关系幂"和"图上走 n 步"焊在了一起，第 12 章的邻接矩阵定理是它的重演。

6.3 五大性质：判定方法汇总

定义 6.3（关系性质）

性质定义（∀x,y,z∈A）关系图特征矩阵特征实例
自反<x,x>∈R每点都有自环主对角线全 1≤、⊆、整除
反自反<x,x>∉R每点都无自环主对角线全 0<、⊂
对称xRy ⇒ yRx边全双向（无向图式）矩阵对称 M = MT=、同乡
反对称xRy ∧ yRx ⇒ x=y异点间无双向边对M ∘ MT 非对角处全 0≤、整除
传递xRy ∧ yRz ⇒ xRz有 x→y→z 必有 x→z（捷径必补）M² ≤ M（逐位）≤、⊆、整除
性质判定的四个高频误区
  • 对称与反对称可以同时成立：相等关系（或只有自环的关系）既对称又反对称——它们不是对立面！对立的是"对称"与"严格不对称"。
  • 既非自反也非反自反：关系 {<1,2>} 在 {1,2} 上有的点有自环吗？没有——反自反成立；但 {<1,1>,<1,2>} 既非自反（缺 <2,2>）也非反自反（有 <1,1>）。判据是"全 1 / 全 0 / 其他"三种主对角线状态。
  • 传递的判定靠枚举反例：不存在 x→y→z 缺捷径才算传递。空关系、只有自环的关系都是传递的（前提不发生时蕴含式为真——又是第 1 章的善意推定！）。
  • 性质是"相对于论域"的：{<1,1>,<2,2>} 在论域 {1,2} 上自反，把论域改成 {1,2,3} 就不自反了。

6.4 闭包：把性质"补"出来

定义 6.4（闭包）

含 R 的、具有性质 P 的最小关系称为 R 关于 P 的闭包。"最小"意味着每补一条边都非补不可。

定理 6.2（三种闭包的构造）

r(R) = R ∪ IA　　（补上所有自环）
s(R) = R ∪ R−1　　（补上反向边）
t(R) = R ∪ R2 ∪ R3 ∪ …　　（补上所有长度的间接通路）

例 6.2 求 {<1,2>, <2,3>, <3,1>} 在 {1,2,3} 上的传递闭包

R² = {<1,3>, <2,1>, <3,2>}（每个二元环走两步），R³ = {<1,1>, <2,2>, <3,3>}，R⁴ = R（三步回到原地，开始循环）。
t(R) = R ∪ R² ∪ R³ = {<x,y> | x,y ∈ {1,2,3} 全体}，即全域关系——三条单向边把三个点串成一个环，环上的任意两点都互相可达。

实际计算传递闭包不用真的算无穷个幂：n 个点的传递闭包 = R ∪ R² ∪ … ∪ Rn（长通路必含环，可截短）。逐个算矩阵乘法是 O(n⁴)，而 Warshall 算法用动态规划把它压到 O(n³)：

# Warshall 算法：求传递闭包
# M[i][j] = 1 表示 i 可达 j；k 为"允许中转的中间点"逐个放开
for k in range(n):           # 允许经过 {0..k} 中转
    for i in range(n):
        for j in range(n):
            M[i][j] = M[i][j] or (M[i][k] and M[k][j])
# 结束后 M 即传递闭包的矩阵

核心思想：第 k 轮回答"如果允许借道第 k 号点，哪些新通路出现了"。i→k 可达且 k→j 可达，则 i→j 可达。这个三重循环也是图算法课里 Floyd 最短路径算法的骨架（把"能否到达"换成"距离取 min"）。顺带一提，闭包的英文 closure 与第 10 章子群"封闭性"同源——都是"补到满足某条规则为止"。

性质的闭包保持性：自反、对称的闭包好办；传递闭包可能破坏反对称（例 6.2 里原来的反对称关系补成了全域关系）。所以不存在"反对称闭包"的一般构造——这一点常考判断题。

6.5 覆盖：关系的"原材料"

若集合族 {A1, …, Am} 满足每个 Ai ⊆ A 且并集为 A，则称它为 A 的一个覆盖；若还要求两两不交且都非空，则称为划分。划分是"把集合切成不相交的块"。它与等价关系是同一枚硬币的两面——下一章的主角。

6.6 自测题

  1. {1,2,3} 上的关系 R = {<1,1>, <1,2>, <2,1>, <2,2>, <3,3>}，判定五条性质各是否成立。
  2. 证明：R 对称 ⇒ R² 对称？错在哪里还是正确？（提示：若 <x,y>∈R²，存在 z 使 xRz 且 zRy，由对称得 yRz 且 zRx，故 <y,x>∈R²。）
  3. 求 {<1,2>, <2,3>} 在 {1,2,3} 上的 r(R)、s(R)、t(R)。
  4. 实数集上的关系 < 依次判断五大性质（自反？反自反？对称？反对称？传递？）。
  5. 用 Warshall 思想解释：为什么传递闭包最多只需算到 R 的 n 次幂？
参考答案（先做再看）
  1. 自反 ✓（三对自环齐）、反自反 ✗、对称 ✓（<1,2><2,1> 成对）、反对称 ✗（<1,2> 与 <2,1> 同时在而 1≠2）、传递 ✓（唯一需要检验的链 1R2R1 要求 <1,1>∈R ✓；3 只与自己相关）。
  2. 结论正确。如提示中的三行即为完整证明：xRz ⇒ zRx，zRy ⇒ yRz，于是存在通路 y→z→x，即 <y,x>∈R²。对称性经复合保持。
  3. r(R) = R ∪ {<1,1>,<2,2>,<3,3>}；s(R) = {<1,2>,<2,1>,<2,3>,<3,2>}；t(R) = {<1,2>,<2,3>,<1,3>}（三元素链，长度 ≤ 3 的通路全覆盖）。
  4. 自反 ✗、反自反 ✓、对称 ✗（1<2 但 ¬(2<1)）、反对称 ✓、传递 ✓。
  5. 长为 n+1 的通路有 n+1 个顶点，由鸽笼原理必有重复顶点，去掉回路段得到更短的同类通路——任何"可补的间接关系"都已被 ≤ n 次幂覆盖。
本章小结：关系 = 序偶集合，三种表示可互相翻译；五大性质各有"图特征 + 矩阵特征"速判法；对称与反对称不互斥；闭包三件套 r/s/t，传递闭包可用 Warshall 在 O(n³) 求出。什么样的关系最值得研究？自反 + 对称 + 传递的——等价关系；自反 + 反对称 + 传递的——偏序。下一章分解。
