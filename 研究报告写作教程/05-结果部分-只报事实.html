第 5 章

结果部分：只报事实，把解释留给讨论

结果部分最难的地方不是算统计，而是忍住不说。你必须把「发现了什么」和「这意味着什么」彻底拆开，前者留在这里，后者走向讨论。

读完本章你应该能

  • 一眼识别结果段落里越权的「评论句」，并准确迁移到讨论；
  • 按数据类型选择合适的描述统计（M ± SD 还是百分数 + 频次）；
  • 完整报告推论统计：方法、精确值、自由度、显著水平、效应量；
  • 按六条规范安排图表，并写对符号、小数位与单位。

5.1 一条分界线：事实与评论

首先要区分「事实」与「评论」。结果部分要客观、如实报告自己发现了哪些事实，不做评论。写作基本原则可以压成六个字：如实汇报，不加解释和评论。

反面 · 混入评论

经过分析发现，实验组的成绩明显好于对照组，说明本实验的干预措施非常有效。另外，男生的得分普遍比女生高，这可能是因为男生的空间能力天生更强。相关分析显示两者存在关系，因此可以确定假设成立。

三句评论藏在一段事实里：「说明干预非常有效」是解释，「因为男生空间能力天生更强」是机制猜测，「假设成立」是结论。三者都属于讨论，甚至其中第二句属于既无数据也无文献支撑的臆断。

下面把同一批结果按规范重写。注意它只说「有差异、差多少、差异有多显著」，不说「为什么」。它还额外补了一个原段落根本没报的东西：统计量。

正面 · 规范报告

独立样本 t 检验显示，实验组后测得分显著高于对照组，t(118) = 4.31，p < 0.001，d = 0.79（见表 5-1）。性别差异方面，男生得分（M = 41.02，SD = 7.15）高于女生（M = 38.44，SD = 6.88），t(118) = 1.98，p = 0.050。空间能力与后测得分的 Pearson 相关为 r(116) = 0.34，p < 0.001。

对照原段落：原段落三句话里只有第一句是事实，而且没有统计量；改写后每句都给出了方法、精确值、自由度与显著水平，把「评论」全部留在原处没搬过来。

5.2 描述统计：先让读者看见数据的形状

对实证研究，通常要报告数据结果，包括描述统计与推论统计。描述统计负责让人看见「数据长什么样」。

要提供数据集中趋势（平均数、众数、中数等）与离散趋势（方差、标准差、全距等）的统计量。但不需要把所有指标都堆上去，按数据类型选择：

数据情形报告什么理由
连续变量且近似正态分布 平均数 + 标准差 两个数就够刻画位置与离散；四分位距是分布明显偏斜时的替代
计数数据 百分数 + 相应频次 只有百分数，读者无法还原样本量；只有频次，读者无法比较不同子样本
分布形态可疑（偏态、峰态明显） 补报偏度、峰度，或改用中数 + 四分位距 此时均值的代表性下降，只报 M ± SD 会误导
两变量关系 相关矩阵，或散点图 散点图能显示线性假设是否成立——相关系数看不见这一点
样本量是必报项 包括每种实验条件下的被试数量。理由有两层：一是读者要判断检验力，二是条件间的 n 不等会让均值比较的可靠性下降（尤其在被试间设计中）。只报总数 N = 120，读者不知道六个格子各有多少人，这是常见硬伤。

三线表示范

结果表格要用三线表：只有顶线、栏目线、底线，无竖线。下表同时示范了「表标题在上方」与「均值 ± 标准差」的写法。

表 5-1　两组后测得分与空间能力的描述统计

组别n后测得分（M ± SD）空间能力（M ± SD）

5.3 推论统计：让读者相信差异不是巧合

推论统计比描述统计更重要。它用于判断观测到的差异是否达到统计显著水平——只有差异「足够大」、不太可能由随机因素导致时，才能说明样本所代表的总体确有差异，结果才可能有科学意义。

无论用哪种统计方法，都要完整报告推论统计的方法和结果，让读者明白研究者如何分析数据、获得什么结果、结果含义是什么。四个要点：

1

准确介绍统计方法，并与设计对应

t 检验有相关样本检验与独立样本检验之分：单因素被试内设计用「相关样本 t 检验」，考察被试间差异用「独立样本 t 检验」。同时说明自变量、因变量分别是什么。

这一步常错在「方法与设计不匹配」：被试内设计却报了独立样本 t，或反过来。审稿人核对设计后一眼就能发现。

2

报告统计量的精确值及附加信息

t 值、F 值、χ² 值等（非希腊字母表示的统计量需斜体）。F 值还需报告分子自由度与分母自由度（df₁, df₂）。

「F 值显著」这种写法不可接受：没有自由度，读者无法复核，也无法判断检验力的量级。

3

报告显著水平，并附效应量

p < 0.001 时写 p < 0.001；p ≥ 0.001 时直接写精确概率值（如 p = 0.032）。并说明是单尾还是双尾检验。

同时报告反映得分差异程度与变量关系强度的效应量（如 d、r²、η²）。

4

把「统计含义」与「专业含义」分开说

统计含义只回答「是否达到显著水平」；专业含义回答「这在心理学上意味着什么」。例如「实验组空间认知能力后测得分显著高于对照组」说明差异存在及方向——这只是统计结果；若补一句「这表明某实验干预措施能有效提高空间认知能力」，读者更易理解其心理学含义。

注意：这一句本身已经滑向讨论了。在严格意义上的结果部分，只写「显著高于」即可；是否加这句专业含义，取决于期刊风格与你所在专业的惯例。稳妥做法是：结果部分只点方向，把因果性说法留给讨论。

为什么效应量不能省

显著性同时受效应大小与样本量影响。d = 0.10 这种几乎无实际意义的差异，在每组 1000 人的样本里也能得到 p < 0.05。反过来，健康行为研究里真实有用的效应，可能因为样本只有 40 人而「不显著」。

只报 p 值，读者无法区分「效应小但样本大」与「效应大但样本小」。效应量正是用来区分这两者的唯一信息。

一份完整的结果段落模板

把上面四点合起来，一段合格的结果陈述包含六个要素：检验名称 → 比较对象 → 均值与标准差 → 统计量与自由度 → 显著性 → 效应量。

模板（可作为写作支架）

「［检验名称］显示，［组别 A］（M = ［ ］，SD = ［ ］）在［因变量］上的得分［高于／低于］［组别 B］（M = ［ ］，SD = ［ ］），［统计量］(［df］) = ［ ］，p = ［ ］，［效应量］ = ［ ］（见表 X）。」

方差分析版本需补充分子／分母自由度与偏 η²：「F(2, 117) = 5.82，p = 0.004，η² = 0.09」。相关版本：「r(116) = −0.34，p = 0.002」。

括号里留空的每一格，都是一个必须给出具体数字的位置。留空的模板比不写模板更有威慑力。

5.4 结果之间的顺序

结果呈现不是罗列，要重点突出、层次分明、组织清晰。三条排序原则：

  • 按重要性排列：最先呈现与核心假设直接相关的结果，人口学变量的差异放在后面或作为前置背景。
  • 按逻辑关系排列：描述统计在推论统计之前；相关分析在回归分析之前；单变量描述统计在多变量关系描述统计之前。
  • 与问题提出和讨论的顺序相协调：读者读结果时期待的是「你承诺的那几条假设逐条接受审判」。如果你的假设是 H1、H2、H3，结果最好也按 H1、H2、H3 排，讨论再按同一顺序展开。
一个低成本的对齐检查 把假设编号写在引言旁，把结果小标题按顺序列出来。两列并排放，如果对不上号，说明你的结果组织是「按 SPSS 输出顺序」而不是「按论证顺序」。

5.5 图表规范

六条，每条都有明确的错误对应：

#规范违反时的样子
1 呈现顺序：先文字后数字或图表；每段行文尽量不要以统计数据开头；图表紧跟第一次提及相应结果的段落之后 段落第一句就是「F(2, 117) = 5.82，p = 0.004」，读者在不知比较对象前先看到一串符号
2 内容：图表内容不要与正文完全重复；图表不能单独使用而不在正文做文字叙述 正文复制整张表的内容，或正文只有一句「结果见表 X」，读者要自己读表下结论
3 经济节省：凡能正文说明的问题，尽量不要表和图；表能说明问题就不用图 只有两个均值也画柱状图；或一张表只有两行数据
4 编号：图、表分别编号；表格标题在表格上方，图标题一般在其下方 表标题放在表下、图标题放在图上，或全文图与表共用一套编号
5 形式：简洁美观，使用三线表 从 SPSS／Excel 直接截一张满屏网格线的表贴进去
6 类型：注意不同类型图表的要求（柱状图用于分类比较、折线图用于趋势、散点图用于关系） 用饼图表示连续变量的分布，或用品类图表示交互作用
补充一条硬性要求 不要直接使用统计软件生成的图。软件默认的字体、配色、图例位置与期刊排版规范几乎不可能一致，且常带默认标题与网格线。自己重新绘制，或至少重设样式后再导出。

关于第 4 条的记忆口诀：表上图下。原因很实际——读者看表的顺序是先知道「这张表是什么」，再看内容，所以标题在上；看图时先看到图形，再需要解释，所以标题在下。

5.6 符号、数据与术语的规范

  • 严格使用法定计量单位、符号，以及标准化、规范化的名词术语。
  • 统计符号按下表统一书写；注意大小写（t、p 为小写）。
  • 数据一般保留到小数点后两位；小数点前、点后的 0 均不可随意省略。
  • p 值等特殊情况保留 3 位小数，或按期刊要求安排。
  • 注意标注必要的数据单位（如「毫秒」「次／分钟」「分」）。
符号含义书写要点
N样本总数大写，斜体
n样本数（子组、条件内）小写，斜体；不要与 N 混用
M平均数大写，斜体（有的期刊用 Mean，按目标期刊统一）
SD标准差两个字母均为斜体
tt 检验统计量小写，斜体
FF 检验统计量大写，斜体；附（df₁, df₂）
χ²卡方检验统计量希腊字母，通常不斜体
r相关系数小写，斜体
p显著性概率小写，斜体；p < 0.001 时不写具体值
排版惯例说明：课程讲义里把上述符号统称为「均用斜体」。严格按 APA 的排版惯例，拉丁字母统计符号斜体，希腊字母（χ²、η²、β、α）本身即符号，不斜体。两者在小数位、大小写上不冲突，差异只在希腊字母。投稿时以目标期刊的模板为准；课程作业按老师要求执行即可。

小数位与前导零

规则是「两位小数，零不可省」，但有一个例外：APA 格式下，理论取值小于 1 的统计量（如 p 值、相关系数）可省略小数点前的 0，写成 p = .03、r = −.34。而不可能超过 1 的量（如描述性均值、标准差）必须保留前导零，写成 0.79，不能写 .79。

这条规则的意义在于避免歧义：一个既可能是 0.5 也可能是 1.5 的数，写成 .5 会让读者误判量级；而 p 永远在 0 与 1 之间，省略后不会引起误解。

不规范的写法规范写法
α=0.05水平上显著在 α = .05 水平上显著（或写作 0.05，全文统一）
P<0.05p < .05
t=4.31,p<0.001t(118) = 4.31，p < .001（逗号后有空格，符号斜体）

练习与思考

  1. 揪评论。拿你自己的结果段落，把每一句标成「事实」或「评论」。所有「评论」句移到讨论草稿里，不要删——它们往往是你讨论的第一段。
  2. 补全统计。找出本章 5.1 的反例，把它需要的统计量补全（检验名称、df、p、效应量），并说明你为什么选这个检验。
  3. 格式校对。把自己的一张结果表按三线表重排，标题移到表上方，并检查 M、SD、n 是否斜体、小数位是否一致。
  4. 算一算。若 d = 0.10、每组 n = 1000，独立样本 t 检验大约会得到什么 p 值？这个结果说明「显著」等于「有效」吗？
  5. 思考题。如果一项研究只报告了显著的结果，未报告不显著的结果，读者对它的结论应该打几折？这与「如实汇报」是什么关系？

本章小结

  • 结果部分只报事实，不做解释与评论；解释属于讨论。
  • 描述统计按数据类型选：连续正态用 M ± SD，计数用百分数 + 频次；样本量与各条件 n 必报。
  • 推论统计四要点：方法要与设计匹配、给精确值与自由度、给显著水平与效应量、区分统计含义与专业含义。
  • 效应量是区分「效应小样本大」与「效应大样本小」的唯一信息，不可省。
  • 结果顺序按重要性、逻辑关系，并与假设及讨论的顺序对齐。
  • 图表六条规范，核心是「表上图下、三线表、先文字后图表、不重复不缺席」。
  • 符号斜体、大小写、两位小数、前导零与单位，都要统一。
