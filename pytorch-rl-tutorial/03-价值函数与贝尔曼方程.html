第 3 章：价值函数与贝尔曼方程

3.1 为什么要学习价值函数

在上一章我们定义了 V(s) 和 Q(s,a)，但还没有解释如何计算它们。价值函数是整个强化学习算法的理论基石——几乎所有主流算法都在以某种方式估计或利用价值函数。

想象你在玩一个迷宫游戏，目标是找到出口。你可以：

  • 试错走完全程：每次从起点走到出口，记录路径长度（蒙特卡罗方法）
  • 从出口倒推：知道出口值为 0，那么出口邻居的值为 1，邻居的邻居为 2……（动态规划）
  • 边走边更新：每走一步，根据"这步值多少"就地更新（时序差分）

这三种方法对应了强化学习的三大学习路线。

3.2 贝尔曼方程：价值函数的递归定义

贝尔曼期望方程

价值函数的递归定义是强化学习最核心的方程：

状态价值函数：V^π(s) = E_π[R_t + γV^π(s_{t+1}) | s_t = s]

动作价值函数：Q^π(s,a) = E_π[R_t + γQ^π(s_{t+1}, a_{t+1}) | s_t = s, a_t = a]

直觉：当前价值 = 即时奖励 + 折扣后的未来价值

贝尔曼方程的妙处在于它把"无限未来的期望"递归地表达成了"一步奖励 + 下一步的价值"。这意味着我们不需要枚��所有可能的未来路径，只需知道下一步的值即可。

"""
贝尔曼方程的直觉推导
假设我们有两个状态：A（安全）和 B（危险）
从 A 出发：
  - 以概率 0.9 留在 A，获得奖励 +1
  - 以概率 0.1 进入 B，获得奖励 0

从 B 出发：
  - 以概率 1.0 进入终态，获得奖励 -10

根据贝尔曼方程：
V(A) = 0.9 * (1 + γ*V(A)) + 0.1 * (0 + γ*V(B))
V(B) = 1.0 * (-10 + γ*V(terminal))
V(terminal) = 0

代入 γ = 0.9：
V(B) = -10
V(A) = 0.9 * (1 + 0.9*V(A)) + 0.1 * (0.9*(-10))
     = 0.9 + 0.81*V(A) - 0.9
     = 0.81*V(A)

解得：V(A) = 0 / 0.19 = 0  (有趣的结果！)

这说明了什么？长期来看，进入 B 的代价 (-10) 被高折扣完全抵消了。
如果 γ = 0.99，则 V(A) = 0.9/(1-0.81) ≈ 4.74，说明长期规划者更看重安全。
"""

def bellman_value_iteration(transitions, rewards, gamma=0.9, iterations=100):
    """
    用动态规划（值迭代）求解最优价值函数
    transitions: dict, transitions[s][a] = [(s', prob), ...]
    rewards: dict, rewards[s][a] = reward_value
    """
    V = {s: 0.0 for s in transitions}

    for i in range(iterations):
        V_new = {}
        for s in transitions:
            # 计算每个动作的 Q 值
            q_values = []
            for a in transitions[s]:
                q = rewards[s][a]
                for s_prime, prob in transitions[s][a]:
                    q += gamma * prob * V[s_prime]
                q_values.append(q)
            # 取最大值（最优策略）
            V_new[s] = max(q_values) if q_values else 0

        # 检查收敛
        max_delta = max(abs(V_new[s] - V[s]) for s in V)
        V = V_new
        if max_delta < 1e-6:
            print(f"收敛于第 {i+1} 次迭代")
            break

    return V

# 示例：简单迷宫
transitions = {
    'A': {'up': [('A', 0.9), ('B', 0.1)], 'down': [('A', 1.0)]},
    'B': {'up': [('A', 0.1), ('B', 0.9)], 'down': [('terminal', 1.0)]},
}
rewards = {'A': {'up': 1.0, 'down': 0.5}, 'B': {'up': 0.0, 'down': -10.0}}

V_opt = bellman_value_iteration(transitions, rewards, gamma=0.9)
print(f"最优价值函数: {V_opt}")

3.3 贝尔曼最优方程

上面我们计算的是遵循某个固定策略的价值。但如果 Agent 可以选择最优策略呢？贝尔曼最优方程给出了答案：

贝尔曼最优方程

最优状态价值函数：V*(s) = max_a E[R_t + γV*(s_{t+1}) | s_t = s, a_t = a]

最优动作价值函数：Q*(s,a) = E[R_t + γ max_{a'} Q*(s_{t+1}, a') | s_t = s, a_t = a]

关键区别：右端出现了 max 操作符——Agent 总是选择能让未来价值最大化的动作。

最优值函数 ≠ 最优策略：知道 V*(s) 只是第一步，从 V* 提取最优策略还需要：π*(s) = argmax_a Q*(s,a)。在连续动作空间中，这个最大化操作本身就是一个优化问题。

3.4 三大学习路线对比

如何计算价值函数？三种方法各有优劣：

方法原理优点缺点对应算法
蒙特卡罗 (MC) 跑完整 episode，用实际回报估计价值 无偏估计，实现简单 需要 episode 结束，方差大，不能在线学习 REINFORCE
动态规划 (DP) 利用已知的 MDP 模型，迭代求解贝尔曼方程 收敛保证，无方差 需要完整的转移模型 P 和 R，状态空间大时计算不可行 值迭代、策略迭代
时序差分 (TD) 用一步 TD 目标 R + γV(s') 作为价值目标的估计 在线学习，有偏但低方差，无需完整模型 引入偏差，需要合适的学习率 Q-Learning、DQN、A2C、PPO

3.5 TD 误差：学习的核心信号

时序差分方法的核心是 TD 误差（Temporal Difference Error），它衡量了"预测"和"实际"之间的差距：

"""
TD 误差：δ = R + γV(s') - V(s)

物理直觉：
- δ > 0：实际比预期好，应该提高 V(s)
- δ < 0：实际比预期差，应该降低 V(s)
- δ = 0：预测准确，不需要更新
"""

import torch
import torch.nn as nn

class ValueNetwork(nn.Module):
    """简单的状态价值网络"""
    def __init__(self, state_dim, hidden_dim=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )

    def forward(self, state):
        return self.net(state)

# 模拟一个 TD 更新
state_dim = 4
gamma = 0.99
lr = 0.001

value_net = ValueNetwork(state_dim)
optimizer = torch.optim.Adam(value_net.parameters(), lr=lr)

# 假设从某个状态 s 执行动作后到达 s'，获得奖励 r
state = torch.randn(1, state_dim)
action = 0  # 假设
next_state = torch.randn(1, state_dim)
reward = 1.0

# 计算当前价值预测
current_q = value_net(state).squeeze()  # V(s)

# 计算 TD 目标（使用 next_state 的价值）
with torch.no_grad():
    target = reward + gamma * value_net(next_state).squeeze()  # R + γV(s')

# TD 误差
td_error = target - current_q

# 计算损失并更新
loss = td_error.pow(2)
optimizer.zero_grad()
loss.backward()
optimizer.step()

print(f"V(s)  = {current_q.item():.4f}")
print(f"目标  = {target.item():.4f}")
print(f"TD误差 = {td_error.item():.4f}")

3.6 优势函数：从 Q 和 V 中提炼

在策略梯度算法中，我们常用优势函数（Advantage Function）来衡量某个动作比平均好多少：

"""
优势函数：A(s,a) = Q(s,a) - V(s)

解释：
- A(s,a) > 0：动作 a 比平均好，应该增加其概率
- A(s,a) < 0：动作 a 比平均差，应该减少其概率
- A(s,a) = 0：动作 a 就是平均水平
"""

def compute_advantage(rewards, values, gamma=0.99):
    """
    从轨迹数据计算优势函数
    使用广义优势估计 (GAE) 的简化版：TD(lambda)
    """
    advantages = []
    gae = 0
    for t in reversed(range(len(rewards))):
        if t == len(rewards) - 1:
            next_value = 0
        else:
            next_value = values[t + 1]

        td_delta = rewards[t] + gamma * next_value - values[t]
        gae = td_delta + gamma * 0.95 * gae  # lambda=0.95 的 GAE
        advantages.insert(0, gae)

    return advantages

3.7 本章小结

  • 贝尔曼方程将无限未来价值递归为"即时奖励 + 折扣后未来价值"
  • 蒙特卡罗需要完整 episode，动态规划需要完整模型，时序差分折中两者
  • TD 误差是时序差分学习的最基本信号
  • 优势函数 A(s,a) = Q(s,a) - V(s) 衡量动作的相对优劣
  • GAE（广义优势估计）是连接 TD 和蒙特卡罗的桥梁
